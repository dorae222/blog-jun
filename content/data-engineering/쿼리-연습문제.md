# 쿼리 연습문제

### 문제1

> **tip:**
> 이름(문자열), 나이(정수), 주소(내장문서로 - 시, 구, 동 3개의 필드), 취미(배열로 3개의 문자열), 특기(배열로 1개의 문자열)를 encore 컬렉션으로 저장하는 쿼리문 작성
>
> - 키 이름 : name, age, address(si, goo, dong), hobby, talent, phone
> - "_id" 키에 해당하는 값은 몽고디비 자동입력을 이용

```sql
db.encore.insertOne({
"name":"Hyeong jun -Do",
"age":25,
"address":{"si":"Seoul","goo":"Seongdong","dong":"HengDang"},
"hobby":["music","game","sleep"],
"talent":["focus"]
})
########################################################
db.encore.find().pretty()
```

### 문제2

> **tip:**
> 핸드폰번호의 키와 값을 추가 입력(갱신)하는 쿼리문(문자열로 ex) 010-9999-9999)을 작성
>
> - 키 이름 : phone(문자열)

```sql
db.encore.find().pretty()
########################################################
db.encore.updateOne(
{"_id":ObjectId("63e5e818b407327b2695378e")},
{$set:{phone:"010-9999-9999"}}
)
########################################################
db.encore.find().pretty()
```

### 문제3

> **tip:**
> 주소의 내장문서로 이루어진 3개의 필드를 하나의 스트링으로 변환하는 쿼리문 작성
>
> - 변환은 $set 제한자를 통해 3개의 값들을 하나의 문자열로 수정

```sql
db.encore.find().pretty()
########################################################

db.encore.updateOne(
{"name":"Hyeong jun -Do"},
{$set:{address:"Seoul Seongdong HengDang"}}
)
########################################################

db.encore.find().pretty()
```

### 문제4

> **tip:**
> 취미의 마지막 값을 제거하는 쿼리문을 작성

```sql
db.encore.find().pretty()
########################################################
db.encore.update(
{"name":"Hyeong jun -Do"},
{$pop:{hobby:1}}
)
########################################################
db.encore.find().pretty()
```

![](/media/posts/imported/ai/DL-Lv1_Untitled-3.png)

### 문제5

> **tip:**
> 특기에 배열의 형태로 중복값을 제거하면서 2개의 요소를 추가하는 쿼리문을 작성

```sql
db.encore.updateOne(
{"name":"Hyeong jun -Do"},
{$addToSet:{talent:{$each:["focus","leadership"]}}}
)
```
