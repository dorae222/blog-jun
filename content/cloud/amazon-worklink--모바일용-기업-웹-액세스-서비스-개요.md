## 🧩 Quick Overview

| 항목        | 설명                                                       |
| --------- | -------------------------------------------------------- |
| **서비스명**  | Amazon WorkLink                                          |
| **유형**    | **모바일 기기용 기업 웹 액세스 서비스**                                 |
| **주요 목적** | **모바일 브라우저에서 기업 내부 웹사이트와 애플리케이션**에 **안전하게 접근**할 수 있도록 지원 |

---

## 🔧 주요 특징

|항목|설명|
|---|---|
|**보안 웹 액세스 제공**|내부 사이트 데이터를 기기 로컬에 저장하지 않고, 브라우저를 통해서만 접근하도록 제공|
|**서버사이드 렌더링**|웹 콘텐츠를 클라우드에서 렌더링한 뒤 이미지 형태로 전송하여 클라이언트에서 랜더링을 최소화|
|**데이터 로컬 저장 금지**|기기에 데이터·캐시·쿠키를 남기지 않음으로써 정보 유출 위험을 낮춤|
|**ID 관리 연계**|SAML 2.0 기반 SSO 등 기존 기업 인증 체계와 연동 가능|
|**모바일 중심 설계**|iOS, Android 기본 브라우저에서 사용 가능하도록 설계됨|

---

## 🧪 활용 시나리오

- **모바일 기기에서 사내 인트라넷 접근**
  - VPN 없이 기업 포털이나 사내 웹 애플리케이션에 접근 가능

- **BYOD 환경 보안 강화**
  - 직원 개인 스마트폰에서 데이터 유출을 방지

- **원격 근무·출장 환경**
  - 이동 중에도 내부 웹 애플리케이션을 안전하게 사용

---

## ✅ 장점

- **VPN 불필요** → 보다 단순하고 빠른 보안 접속 제공
- **데이터 보안 강화** → 기기에 로컬 저장이나 스크린샷 등 민감 데이터 저장을 최소화
- **관리 편의성** → 별도 애플리케이션 설치 없이 브라우저 기반으로 접근 가능
- **SSO 지원** → 기업 인증 체계와의 연계가 용이

## ⚠️ 유의사항

|항목|설명|
|---|---|
|**모바일 웹 전용**|네이티브 앱 접근은 별도의 솔루션이 필요함|
|**렌더링 성능 의존**|서버사이드 렌더링에 의존하므로 복잡한 웹 페이지에서는 지연이 발생할 수 있음|
|**서비스 상태**|현재 **서비스 종료(EOL)** 상태로 신규 사용은 불가함|
