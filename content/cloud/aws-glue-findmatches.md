## 🧩 Quick Overview

| 항목              | 설명 |
|-------------------|------|
| **기능명**         | AWS Glue FindMatches |
| **서비스 위치**     | AWS Glue DataBrew / AWS Glue ML Transform |
| **기능 종류**      | **기계학습 기반의 데이터 중복 탐지(Deduplication)** 기능 |
| **작동 방식**      | 지도학습 기반 ML 모델을 통해 **중복 가능성이 높은 레코드를 자동 식별** |

> 🧠 **목적**: 데이터셋 내에서 **동일하거나 유사한 레코드(예: 이름 철자 차이, 주소 포맷 차이)**를 **자동으로 탐지하고 정제**할 수 있도록 지원

---

## 🔍 작동 방식

1. **매칭 기준 레이블링**
   - 소규모 샘플 데이터에 대해 “매치”, “비매치” 레이블 지정
2. **ML Transform 학습**
   - Glue가 AutoML 방식으로 유사성 추정 모델을 생성
3. **전체 데이터셋에 적용**
   - 학습된 모델을 사용해 레코드 페어별 유사도 점수 산출 및 매칭 수행
4. **유사 레코드 그룹화**
   - 설정한 Threshold(임계값)를 기반으로 중복 가능성이 높은 레코드를 그룹화하여 출력
