## 🧩 Quick Overview

| 항목              | 설명 |
|-------------------|------|
| **기능명**         | Amazon QuickSight ML Insights |
| **제공 위치**      | Amazon QuickSight (BI 대시보드 도구) 내 기능 |
| **기반 기술**      | 내장된 머신러닝(ML) 모델 + 이상 탐지 알고리즘 |

> 📊 **목적**: QuickSight에서 **자동으로 비즈니스 데이터의 이상점, 추세, 영향 요인 등을 분석하여 인사이트 도출**

---

## 🧠 주요 기능

| 기능 | 설명 |
|------|------|
| **Anomaly Detection** | 지표의 급격한 변화나 이상치(Outlier)를 자동으로 탐지 |
| **Contribution Analysis** | 값 변화에 영향을 준 주요 요인(필드)을 자동으로 분해 및 식별 |
| **Forecasting** | 시계열 데이터를 기반으로 미래 값을 예측 |
| **Narrative Insight (자동 설명)** | 인사이트를 **자연어 텍스트**로 자동 생성 |

---

## 🧪 예시 시나리오

- 매출이 급격히 줄어든 원인을 지역/제품/캠페인별로 분석
- 일일 사용자 수의 이상 급증 감지
- 다음 달 예상 매출 예측

## ✅ 장점

| 항목 | 설명 |
|------|------|
| **비개발자도 ML 인사이트 활용 가능** | 드래그 앤 드롭만으로 설정하여 사용 가능 |
| **자동화된 분석 결과 제공** | 이상 원인과 변화 요인을 자동으로 탐지하고 제공 |
| **데이터 기반 예측 및 설명 가능** | 설명 가능한 AI 기능이 내장되어 있어 결과 해석에 도움을 줌 |
| **대시보드 내 통합** | ML 인사이트를 대시보드의 시각 요소로 바로 표현 가능 |
