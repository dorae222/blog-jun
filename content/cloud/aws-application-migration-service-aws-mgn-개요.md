## 🧩 Quick Overview

| 항목              | 설명 |
|-------------------|------|
| **서비스명**       | AWS Application Migration Service (AWS MGN) |
| **유형**           | **워크로드 마이그레이션 서비스 (Lift-and-Shift)** |
| **주요 목적**       | 온프레미스, 클라우드, 기타 환경의 서버·애플리케이션을  
                       **최소 다운타임으로 AWS로 마이그레이션**하도록 지원

> 🚀 **AWS MGN**은 서버를 재설계·재구축하지 않고  
> **거의 실시간 복제 + 테스트 + 최종 전환**을 통해 **쉽고 안전한 마이그레이션**을 가능하게 합니다.

---

## 🔧 동작 방식

1. **소스 서버 에이전트 설치**  
   - 온프레미스 또는 타 클라우드 VM에 AWS MGN 에이전트 배포
2. **데이터 복제(Replication)**  
   - AWS MGN이 EC2 기반의 스테이징 영역으로 지속적 복제(CDP, Continuous Data Protection)
3. **테스트 마이그레이션 실행**  
   - 실제 서비스에 영향 없이 사전 검증
4. **최종 전환(Cutover)**  
   - 복제 완료 후 EC2 인스턴스 생성 → DNS 전환 → 운영 전환

---

## 📦 주요 기능

| 기능 | 설명 |
|------|------|
| **지속적 복제** | 거의 실시간으로 변경 사항을 AWS로 동기화 |
| **자동화된 서버 변환** | 물리/가상 서버를 AWS EC2 인스턴스로 자동 변환 |
| **테스트 모드 제공** | 마이그레이션 전 검증 환경 실행 가능 |
| **규모 확장** | 수백~수천 대 서버 동시 마이그레이션 지원 |
| **최소 다운타임** | 실제 전환 시 몇 분~수십 분 이내로 서비스 복구 가능 |

---

## 🧪 활용 시나리오

- **온프레미스 데이터센터 → AWS**
- **타 클라우드 → AWS** (예: Azure, GCP)
- **재해 복구(DR) 환경 구축**
- **Lift-and-Shift 방식 마이그레이션** (리호스트)

---

## ✅ 장점

| 항목 | 설명 |
|------|------|
| **단순화된 마이그레이션** | 재설계 없이 신속하게 이전 가능 |
| **중단 최소화** | 지속적 복제와 테스트 모드로 다운타임을 단축 |
| **대규모 확장 지원** | 수백~수천 서버 동시 이전 가능 |
| **비용 효율** | 스테이징 환경의 EC2·EBS 요금만 지불 |

## ⚠️ 유의사항

| 항목 | 설명 |
|------|------|
| **서버 사양 조정 필요** | 마이그레이션 후 EC2 타입·스토리지 최적화 필요 |
| **네트워크/보안 설계 필수** | VPC, IAM, 방화벽 정책을 사전에 설계해야 함 |
| **애플리케이션 종속성 고려** | 복제 후 애플리케이션의 정상 동작 여부를 반드시 테스트해야 함 |
