Amazon SageMaker AI는 완전 관리형 기계 학습(ML) 서비스입니다. SageMaker AI를 사용하면 데이터 과학자와 개발자가 ML 모델을 빠르고 자신 있게 구축, 훈련 및 프로덕션 지원 호스팅 환경에 배포할 수 있습니다. 여러 통합 개발 환경(IDE)에서 SageMaker AI의 ML 도구를 사용할 수 있도록 ML 워크플로를 실행하기 위한 UI 환경을 제공합니다.

SageMaker AI를 사용하면 자체 서버를 구축하고 관리할 필요 없이 데이터를 저장하고 공유할 수 있습니다. 이를 통해 개인이나 조직이 ML 워크플로를 공동으로 설계·개발하고 작업을 더 빠르게 진행할 수 있습니다. SageMaker AI는 분산 환경에서 대규모 데이터셋을 효율적으로 처리할 수 있는 관리형 ML 알고리즘을 제공합니다.

bring-your-own-algorithms을 기본적으로 지원하는 SageMaker AI는 특정 워크플로에 맞게 조정 가능한 유연한 분산 훈련 옵션을 제공합니다. 또한 몇 단계 내에 SageMaker AI 콘솔에서 모델을 안전하고 확장 가능한 환경에 배포할 수 있습니다.
