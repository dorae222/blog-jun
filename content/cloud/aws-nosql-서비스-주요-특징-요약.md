다음은 AWS의 NoSQL 데이터베이스 서비스에서 자주 강조되는 주요 특징들입니다:

- TTL(Time to Live) 기능으로 오래된 데이터를 자동 삭제할 수 있음.
- NoSQL 데이터베이스 서비스임.
- 키-값 및 문서 데이터 모델을 지원함.
- 서버리스 서비스로 운영됨.
- 용량에 맞게 자동으로 확장 및 축소(Auto Scaling)되어 관리·운영 오버헤드가 최소화됨.
- 10밀리초 미만의 빠른 응답을 제공함.
- 초당 수백만 개 이상의 요청을 처리할 수 있음.
- 지연 시간이 짧고 빠른 응답이 필요한 애플리케이션에 적합함.
- 쇼핑몰 장바구니, 은행 트랜잭션, 게임 플레이어 기록 저장 등과 같은 사례에 사용됨.
