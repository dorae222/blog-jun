## 🧩 Quick Overview

| 항목        | 설명                                                                 |
| --------- | ------------------------------------------------------------------ |
| **서비스명**  | AWS IAM Access Analyzer                                            |
| **유형**    | **IAM 보안·접근 분석 서비스**                                               |
| **주요 목적** | AWS 계정 및 리소스에서 **외부 접근 권한을 자동 감지**하고 **잠재적 보안 위험을 식별**하여 권장 조치를 제공 |

> 🔍 **IAM Access Analyzer**는 S3, KMS, IAM 역할, SQS, Lambda 등  
> AWS 리소스가 **외부 계정·퍼블릭에 노출되었는지 여부를 분석**하는 서비스입니다.

---

## 🔧 주요 특징

| 항목 | 설명 |
|------|------|
| **외부 액세스 분석** | 리소스 정책을 평가해 외부 계정·퍼블릭 접근 여부를 식별합니다. |
| **정책 생성 시뮬레이션** | 권한을 부여하기 전에 실제로 접근이 가능한지 사전 시뮬레이션합니다. |
| **분석 대상 리소스** | S3, KMS, IAM Role, SQS, Lambda, Secrets Manager 등입니다. |
| **자동 경고 생성** | 의도치 않은 외부 공유가 발견되면 Security Hub·CloudWatch Event로 알림을 보냅니다. |
| **AWS Organizations 통합** | 조직 단위로 리소스의 외부 노출을 모니터링할 수 있습니다. |

---

## 🧪 활용 시나리오

- **S3 퍼블릭 접근 점검**
  - 잘못된 버킷 정책·ACL로 인한 외부 노출 여부를 확인합니다.
- **KMS 키 외부 공유 확인**
  - 타 계정이나 외부 사용자에게 권한이 부여되었는지 점검합니다.
- **IAM Role 검증**
  - 교차 계정 액세스 권한의 부여 여부를 모니터링합니다.
- **보안 감사 및 규정 준수**
  - 리소스의 외부 공유 현황을 리포트로 생성합니다.

---

## ✅ 장점

- **자동화된 보안 점검** → 수동 리뷰 없이도 외부 노출을 감지합니다.
- **정책 검증 및 시뮬레이션** → 잠재적 위험을 사전에 예방할 수 있습니다.
- **Security Hub 통합** → 중앙화된 보안 모니터링이 가능합니다.
- **조직 단위 지원** → 멀티계정 환경에서 보안을 강화합니다.
