### Types of Data (데이터 유형)

- Structured Data (구조화된 데이터)
	- Definition: 사전에 정의된 구조나 스키마를 가진 데이터로서, 보통 관계형 데이터베이스에서 찾아볼 수 있습니다.
	- Characteristics:
		- 쿼리가 용이함
		- 행과 열로 조직화됨
		- 구조가 일관됨
	- Examples:
		- 데이터베이스 테이블
		- 일관된 열을 가진 CSV 파일
		- 엑셀 및 스프레드시트
- Unstructured Data (비구조화된 데이터)
	- Definition: 미리 정의된 구조나 스키마가 없는 데이터입니다.
	- Characteristics:
		- 전처리 없이는 쿼리하기 어려움
		- 다양한 형식으로 존재할 수 있음
	- Examples:
		- 고정된 형식이 없는 텍스트 파일
		- 비디오 및 오디오 파일
		- 이미지
		- 이메일 및 워드 프로세싱 문서
- Semi-Structured Data (반구조화된 데이터)
	- Definition: 구조화된 데이터만큼 조직화되어 있지는 않지만 태그, 계층 구조 또는 기타 패턴 형태로 어느 정도 구조를 가진 데이터입니다.
	- Characteristics:
		- 요소들이 태그되거나 분류되는 경우가 있음
		- 구조화된 데이터보다 유연하고, 비구조화된 데이터보다는 규칙성이 있음
	- Examples:
		- XML 및 JSON 파일
		- 이메일 헤더(날짜, 제목 등 구조화된 필드와 본문의 비구조화된 데이터 혼합)
		- 형식이 다양한 로그 파일

### Properties of Data (데이터의 속성)
- Volume (볼륨)
	- Definition: 조직이 특정 시점에 다루는 데이터의 양 또는 크기를 의미합니다.
	- Characteristics:
		- 기가바이트에서 페타바이트 이상까지 다양할 수 있음
		- 대용량 데이터의 저장, 처리, 분석에 대한 도전 과제가 존재함
	- Examples:
		- 인기 있는 소셜 미디어 플랫폼이 사용자 게시물, 이미지, 비디오로부터 매일 테라바이트 단위의 데이터를 처리하는 경우
		- 소매업체가 여러 해에 걸친 거래 데이터를 수집하여 수 페타바이트에 달하는 경우
- Velocity (속도)
	- Definition: 새로운 데이터가 생성, 수집, 처리되는 속도를 의미합니다.
	- Characteristics:
		- 높은 속도는 실시간 또는 거의 실시간에 가까운 처리 능력을 요구함
		- 빠른 수집 및 처리가 특정 애플리케이션에서 중요할 수 있음
	- Examples:
		- IoT 기기에서 밀리초 단위로 측정값을 스트리밍하는 센서 데이터
		- 밀리초 단위의 의사결정이 중요한 고빈도 거래 시스템
- Variety (다양성)
	- Definition: 데이터의 종류, 구조, 출처가 얼마나 다양한지를 나타냅니다.
	- Characteristics:
		- 데이터는 구조화, 반구조화, 비구조화 형태로 존재할 수 있음
		- 여러 출처에서 다양한 형식으로 데이터가 유입될 수 있음
	- Examples:
		- 관계형 데이터베이스(구조화), 이메일(비구조화), JSON 로그(반구조화)로부터 데이터를 분석하는 비즈니스
		- 전자의무기록, 웨어러블 기기, 환자 피드백 폼으로부터 데이터를 수집하는 헬스케어 시스템
