## 🧩 Quick Overview

| 항목        | 설명                                                                                 |
| --------- | ---------------------------------------------------------------------------------- |
| **서비스명**  | AWS IQ                                                                             |
| **유형**    | **AWS 전문가 온디맨드 컨설팅·프리랜서 연결 플랫폼**                                                   |
| **주요 목적** | 기업·개인이 **AWS 공인 전문가(AWS Certified Expert)**와 **프로젝트 단위로 협업·자문·구현 지원**을 받을 수 있도록 지원 |

> 👨‍💻 **AWS IQ**는 AWS 환경에서의 **컨설팅, 아키텍처 설계, 마이그레이션, 개발 작업**을
> **공식 인증 전문가와 매칭**해주는 온디맨드 서비스입니다.

---

## 🔧 주요 특징

| 항목 | 설명 |
|------|------|
| **전문가 매칭** | AWS 공인 전문가(AWS Certification 보유자)와 프로젝트 단위 연결 |
| **프로젝트 범위 유연성** | 짧은 자문부터 실제 구현까지 지원 |
| **온라인 계약·결제** | AWS 계정을 통해 작업 승인·결제 가능 |
| **AWS 관리형** | 보안·신뢰성 보장 (AWS 계정 기반 권한 위임) |
| **원격 협업 중심** | 대부분의 작업은 원격으로 수행 |

---

## 🧪 활용 예시

- **클라우드 아키텍처 설계**
  - 예: Well-Architected Framework 검토 및 최적화
- **마이그레이션 지원**
  - 온프레미스 → AWS 이전 설계 및 실행
- **DevOps/CI/CD 구축**
  - CodePipeline, CodeBuild, ECS/EKS 세팅
- **보안·비용 최적화 컨설팅**
  - IAM, VPC, 비용 분석 및 절감 방안 제시

---

## ✅ 장점

- **AWS 공식 인증 전문가 활용** → 신뢰도 높은 지원
- **신속한 온디맨드 컨설팅** → 필요 시 바로 전문가 요청 가능
- **결제·계약 간소화** → AWS 계정 내에서 승인·결제
- **다양한 분야 지원** → 아키텍처, 마이그레이션, DevOps, 보안 등
