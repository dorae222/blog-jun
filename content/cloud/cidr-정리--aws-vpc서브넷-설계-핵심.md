> **NOTE:**
> 
> - **IP 주소 범위를 표현하는 표기법**
>     
> - **네트워크 클래스(Class A/B/C) 개념을 제거**
>     
> - **IP 주소 + 프리픽스 길이(/n)** 형태
>     
> - AWS VPC, 서브넷 설계의 **핵심 개념**
>     
> - IPv4 / IPv6 모두 사용
>     

**CIDR**는  
**IP 주소 범위를 유연하게 나누고(Subnetting) 묶기(Supernetting) 위한 표준 주소 표기 방식**이다.

---

## 🌐 CIDR란?

> **CIDR (Classless Inter-Domain Routing)**는  
> IP 주소를 **고정된 클래스 대신 비트 단위(prefix)** 로 관리하여  
> **주소 낭비를 줄이고 네트워크 설계를 유연하게 만드는 방식**이다.

```text
예: 10.0.0.0/16
```

- `10.0.0.0` → 네트워크 주소
    
- `/16` → 네트워크 비트 수 (앞의 16비트)
    

---

## 🧠 CIDR 표기법 구조

```text
IP 주소 / Prefix Length
```

### 예시

|CIDR|의미|
|---|---|
|`192.168.1.0/24`|앞 24비트 = 네트워크|
|`10.0.0.0/16`|앞 16비트 = 네트워크|
|`0.0.0.0/0`|모든 IP 범위|

---

## 🧮 Prefix Length와 IP 개수

> **IPv4 주소 개수 = 2^(32 − Prefix)**

|CIDR|총 IP 개수|사용 가능 IP*|
|---|--:|--:|
|/32|1|1|
|/30|4|2|
|/28|16|11|
|/24|256|251|
|/16|65,536|65,531|

*AWS 서브넷에서는 **5개 IP 예약**  
(네트워크, 브로드캐스트, 라우터, DNS 2개)

---

## 🧩 CIDR의 핵심 개념 2가지

### 1️⃣ Subnetting (쪼개기)

큰 네트워크를 더 작은 서브넷으로 분할하는 것

```text
10.0.0.0/16
 ├─ 10.0.1.0/24
 ├─ 10.0.2.0/24
 └─ 10.0.3.0/24
```

📌 목적: **보안, 관리, 가용성 분리**

---

### 2️⃣ Supernetting (묶기)

여러 개의 인접한 네트워크 블록을 하나의 요약된 블록으로 합치는 것

```text
192.168.0.0/24
192.168.1.0/24
→ 192.168.0.0/23
```

📌 목적: **라우팅 테이블 단순화**

---

## ☁️ AWS에서의 CIDR (시험 단골)

### VPC

- CIDR 범위 필수 지정
    
- 예: `10.0.0.0/16`
    
- 생성 후 **변경 불가** (추가만 가능)
    

### Subnet

- VPC CIDR의 **부분 집합**
    
- AZ 단위로 생성
    
- 예: `10.0.1.0/24`
    

📌 시험 키워드

> _“서브넷은 VPC CIDR 범위 내에서만 생성 가능”_

---

## 🚦 특수 CIDR 범위 (암기)

|CIDR|의미|
|---|---|
|`0.0.0.0/0`|모든 IP (인터넷 전체)|
|`10.0.0.0/8`|Private IP|
|`172.16.0.0/12`|Private IP|
|`192.168.0.0/16`|Private IP|
|`127.0.0.0/8`|Loopback|

---

## 🆚 Classful Addressing vs CIDR

|항목|Classful|CIDR|
|---|---|---|
|네트워크 크기|고정|가변|
|주소 낭비|많음|적음|
|확장성|낮음|높음|
|현대 네트워크|❌|✅|

## 🧪 시험에 자주 나오는 질문 유형

### ❓ 문제 1

> VPC CIDR가 `10.0.0.0/16`일 때  
> 생성 가능한 서브넷 CIDR는?

✅ 정답

- `10.0.1.0/24`, `10.0.2.0/24` 등  
    ❌ `10.1.0.0/16` (범위 초과)
    

---

### ❓ 문제 2

> 모든 트래픽을 허용하는 라우팅 규칙은?

✅ 정답

- `0.0.0.0/0`

## ⚠️ 시험 포인트 요약

- CIDR = **IP 범위 표현**
    
- `/n` = 네트워크 비트 수
    
- AWS 서브넷은 **5개 IP 예약**
    
- VPC CIDR은 **축소 불가**
