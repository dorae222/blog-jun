## 🧩 Quick Overview

| 항목        | 설명                                                         |
| --------- | ---------------------------------------------------------- |
| **서비스명**  | AWS Health Dashboard                                       |
| **유형**    | **AWS 계정·서비스 상태 모니터링 서비스**                                 |
| **주요 목적** | AWS 서비스와 계정 리소스에 영향을 주는 **이벤트·알림·문제 현황**을 실시간으로 확인하여 대응을 지원 |

> 📊 **AWS Health Dashboard**는
> **계정별·리전별 서비스 상태, 유지보수 알림, 장애 이벤트**를 한눈에 확인할 수 있는
> **AWS 공식 모니터링 포털**입니다.

---

## 🔧 주요 특징

| 항목 | 설명 |
|------|------|
| **서비스 상태 확인** | 계정에 영향을 주는 서비스 이벤트를 실시간으로 표시 |
| **이벤트 유형 제공** | 운영 이벤트, 유지보수, 보안·규정 준수 알림 등을 제공 |
| **계정 맞춤형 뷰** | AWS Personal Health Dashboard(PHD) 기반의 계정별 영향 분석 제공 |
| **알림 연동** | CloudWatch Events, SNS 등으로 이벤트 알림 전송 가능 |
| **콘솔/모바일 접근** | AWS Management Console 및 모바일 앱에서 확인 가능 |

---

## 📦 주요 이벤트 유형

1. **서비스 이벤트(Service Events)**
   - 서비스 장애, 성능 저하, 리전별 가용성 문제
2. **계정 이벤트(Account-specific Events)**
   - 계정 리소스에 대한 유지보수·보안 패치·구성 변경
3. **예방적 알림(Proactive Notifications)**
   - 예정된 유지보수, 인증서 갱신, 한도 초과 위험 등

---

## 🧪 활용 시나리오

- **장애 상황 신속 대응**
  - 예: EC2 인스턴스가 호스팅된 AZ 장애 발생 알림 수신
- **예방적 유지보수 관리**
  - 예: RDS의 예정 패치 스케줄 확인 및 대비
- **보안·규정 준수 대응**
  - 예: SSL 인증서 만료, IAM 정책 권장 변경 안내

---

## ✅ 장점

- **실시간 서비스 상태 파악** → 장애 발생 시 즉각 대응 가능
- **계정별 맞춤 알림** → 내 리소스에 실제 영향을 주는 이벤트만 확인
- **자동 알림 연계** → SNS·Lambda 등과 연결해 대응을 자동화 가능
- **규정·보안 준비 지원** → 유지보수·보안 이벤트에 대한 사전 대응 지원

|------|------|
