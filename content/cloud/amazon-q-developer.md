## 🧩 Quick Overview

| 항목              | 설명 |
|-------------------|------|
| **서비스명**       | Amazon Q Developer |
| **형태**           | 생성형 AI 기반 개발 도우미 (Chatbot + IDE 통합 도구) |
| **제공 방식**      | 콘솔, Amazon Q IDE 플러그인 (VS Code, JetBrains 등) |
| **기능 핵심**      | 코드 생성, 설명, 디버깅, 테스트, AWS 리소스 분석

> 🤖 **목적**: AWS 및 일반 개발 작업을 **생성형 AI 기반으로 빠르게 지원**하여 **개발자 생산성 향상**을 돕는 도구

## 🔧 주요 기능

- **코드 생성 및 자동완성**
  - Python, JavaScript, Java, TypeScript 등 다수 언어 지원
- **코드 설명 / 리팩토링**
  - 선택한 코드 블록에 대해 자연어로 설명하거나 최적화 제안 제공
- **버그 수정 및 테스트 생성**
  - 함수 단위의 유닛 테스트 자동 생성 가능
- **AWS 리소스 이해**
  - CloudFormation, CDK, IAM 정책 등 구조 설명
  - S3, Lambda, API Gateway 설정 요약 및 권한 분석
- **콘솔 + IDE 플러그인 통합**
  - VS Code, JetBrains IDE에 통합되어 코드 작성 중 자연어 질의 지원

- Amazon Bedrock 기반: Amazon Q Developer는 Amazon Bedrock을 기반으로 하며 안전, 보안 및 책임감 있는 AI 사용을 시행하기 위해 Amazon Bedrock에 구현된 [자동 침해 탐지](https://docs.aws.amazon.com/bedrock/latest/userguide/abuse-detection.html)를 포함합니다.
- Amazon Q Developer는 AWS 애플리케이션을 이해, 구축, 확장 및 운영하는 데 도움이 되는 생성형 인공 지능(AI) 기반 대화형 어시스턴트입니다. AWS 아키텍처, AWS 리소스, 모범 사례, 설명서, 지원 등에 대해 질문할 수 있습니다. Amazon Q는 질문을 통해 상황별로 관련성 높고 실행 가능한 답변을 제공하도록 기능을 지속적으로 업데이트하고 있습니다.
- 통합 개발 환경(IDE)에서 사용하는 경우 Amazon Q는 소프트웨어 개발 지원 기능을 제공합니다. Amazon Q는 코드와 채팅하고, 인라인 코드 완성을 제공하며, 새 코드를 생성하고, 코드에서 보안 취약성을 스캔하며, 언어 업데이트, 디버깅 및 최적화 같은 코드 개선 작업을 수행할 수 있습니다.
