## 🧩 Quick Overview

| 항목        | 설명                                                        |
| --------- | --------------------------------------------------------- |
| **서비스명**  | Amazon Elastic Transcoder                                 |
| **유형**    | **클라우드 기반 미디어 트랜스코딩(비디오/오디오 변환) 서비스**                     |
| **주요 목적** | 원본 미디어 파일을 **다양한 디바이스·플랫폼에 맞게 변환**하여 **스트리밍 및 다운로드**에 최적화 |

> 🎬 **Elastic Transcoder**는 S3에 저장된 **동영상·오디오 파일을 여러 해상도·코덱·포맷으로 변환**해주는 완전관리형 AWS 서비스입니다.

---

## 🔧 주요 특징

| 항목 | 설명 |
|------|------|
| **멀티 포맷 변환** | MP4, HLS, WebM 등 다양한 출력 포맷 지원 |
| **다양한 디바이스 최적화** | 모바일, 태블릿, 웹, 스마트TV 등 타겟별 프리셋 제공 |
| **확장성** | AWS에서 자동 스케일링 처리, 대량 파일도 병렬 변환 |
| **S3·SNS 통합** | 입력·출력 파일은 S3, 상태 알림은 SNS로 제공 |
| **Pay-as-you-go 과금** | 처리된 분량(분/해상도)에 따라 과금 |

---

## 🧪 활용 시나리오

- **동영상 스트리밍 준비**
  - 예: HLS 세그먼트 변환 후 CloudFront 배포
- **멀티 디바이스 호환**
  - 한 원본에서 모바일·데스크톱용 변환 파일 생성
- **VOD(Video on Demand) 플랫폼**
  - 대규모 미디어 라이브러리 자동 변환
- **썸네일·미리보기 생성**
  - 트랜스코딩 과정에서 썸네일 이미지 자동 추출

---

## ✅ 장점

- **완전관리형 서비스** → 서버 관리 불필요
- **프리셋 기반 간편 변환** → 복잡한 인코딩 설정 없이 사용 가능
- **AWS 서비스 연계 용이** → S3, CloudFront, SNS와 자연스러운 통합
- **자동 확장** → 대량 변환 시에도 병렬 처리 지원

---

## ⚠️ 유의사항

| 항목 | 설명 |
|------|------|
| **기능 업데이트 제한** | 현재는 **AWS Elemental MediaConvert**로 점진적 대체 권장 |
| **라이브 스트리밍 미지원** | VOD 중심, 실시간 스트리밍은 MediaLive 사용 |
| **고급 코덱 제한** | 최신 코덱·HDR 처리 등은 MediaConvert 활용 필요 |
