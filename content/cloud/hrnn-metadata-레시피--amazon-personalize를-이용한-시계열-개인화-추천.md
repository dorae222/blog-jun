## 🧩 Quick Overview

| 항목        | 설명                                                                  |
| --------- | ------------------------------------------------------------------- |
| **레시피명**  | HRNN-Metadata (Hierarchical Recurrent Neural Network with Metadata) |
| **서비스**   | **Amazon Personalize**                                              |
| **주요 목적** | **시계열 기반 추천**에 **사용자·아이템 메타데이터를 추가**하여  **개인화 정확도 향상**              |

---

## 🔧 주요 특징

|항목|설명|
|---|---|
|**모델 유형**|**순환 신경망(RNN)** 기반의 **시계열 추천 알고리즘**|
|**계층적 구조(HRNN)**|사용자 단위의 세션과 이벤트를 계층적으로 학습|
|**메타데이터 활용**|사용자 속성(예: 나이, 지역) 및 아이템 속성(예: 장르, 카테고리) 포함 가능|
|**시간 의존성 반영**|최근 행동과 세션 정보를 반영하여 추천 성능 강화|
|**자동 하이퍼파라미터 최적화**|Personalize가 내부적으로 하이퍼파라미터 튜닝을 수행|

---

## 🧪 활용 시나리오

- **개인화 추천 강화**
  - 예: 이커머스 상품 추천, 동영상·음악 스트리밍 추천

- **메타데이터 기반 추천**
  - 유사한 사용자·아이템 속성을 활용해 콜드스타트 문제 완화

- **세션 기반 시계열 분석**
  - 최근 사용자 행동과 선호도를 반영한 추천

---

## ✅ 장점

- **시계열 패턴 학습** → 최근 행동을 반영해 추천 정확도 향상
- **메타데이터 활용** → 신규 아이템 및 신규 사용자에 대한 콜드스타트 완화
- **관리형 서비스로의 자동화된 학습** → SageMaker 없이도 Personalize에서 바로 사용 가능
