Elastic Network Adapter (ENA)는 AWS에서 제공하는 고성능 네트워크 인터페이스입니다.

ENA는 Amazon EC2 인스턴스에 높은 throughput과 낮은 대기 시간의 네트워킹 기능을 제공합니다.

ENA는 가상화된 네트워킹을 통해 인스턴스가 빠르고 안정적인 네트워크 연결을 유지하도록 지원하며, 특히 고성능 컴퓨팅 애플리케이션에 적합합니다. EC2 인스턴스가 ENA를 사용하면 최대 100Gbps까지의 네트워크 대역폭을 지원할 수 있습니다.
