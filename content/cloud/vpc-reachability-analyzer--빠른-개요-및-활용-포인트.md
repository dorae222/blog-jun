## 🧩 Quick Overview

| 항목        | 설명                                                             |
| --------- | -------------------------------------------------------------- |
| **서비스명**  | VPC Reachability Analyzer                                      |
| **유형**    | **VPC 네트워크 연결 분석·진단 도구**                                       |
| **주요 목적** | **두 리소스 간 네트워크 연결 가능 여부를 시뮬레이션**하고 **차단 원인·경로를 분석**하여 문제 해결을 지원 |

---

## 🔧 주요 특징

|항목|설명|
|---|---|
|**엔드투엔드 연결 확인**|VPC 내/간, Direct Connect, Transit Gateway 포함한 연결 경로를 분석|
|**차단 지점 식별**|보안 그룹, NACL, 라우팅 테이블, 게이트웨이 설정 등에서 차단 지점을 찾아냄|
|**시뮬레이션 기반**|실제 패킷을 전송하지 않고 구성 정보를 기반으로 연결을 분석|
|**AWS 콘솔 통합**|VPC 콘솔의 Reachability Analyzer 메뉴에서 실행 가능|
|**보안 문제 진단**|예상치 못한 네트워크 차단 원인을 시각적으로 제공하여 원인 파악을 지원|

## ✅ 장점

- **실제 트래픽 필요 없음** → 운영 환경에 영향을 주지 않고 분석 가능

- **빠른 네트워크 문제 해결** → 차단 지점과 원인을 명확히 파악 가능

- **보안·규정 준수 지원** → 네트워크 설계 검증에 유용

- **시각화 제공** → 경로와 차단 요소를 직관적으로 확인 가능
