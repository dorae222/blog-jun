## 🧩 Quick Overview

| 항목              | 설명 |
|-------------------|------|
| **이름**           | Amazon S3 Object Lambda |
| **기능 유형**       | **S3 객체를 반환하기 전에 사용자 정의 Lambda 함수로 동적으로 변환** |
| **주요 목적**       | S3에 저장된 원본 데이터를 수정하지 않고 **사용자 요청에 따라 객체를 변형해서 반환** |

> 🧠 **S3 Object Lambda**는 **기존 S3 버킷의 객체를 직접 수정하거나 복사하지 않고도,  
> 응답 시점에 사용자 정의 로직을 통해 가공된 데이터를 제공**할 수 있게 해줍니다.

---

## 🔧 작동 방식

1. 사용자가 S3 객체에 접근을 시도합니다.
2. 요청은 S3 Object Lambda Access Point로 전달됩니다.
3. 지정된 **Lambda 함수가 요청된 객체를 읽어 가공/변형**합니다.
4. 변형된 결과를 응답으로 반환합니다.

---

## ✅ 주요 사용 사례

| 사례 | 설명 |
|------|------|
| **민감 정보 마스킹** | PII 정보가 포함된 객체에서 이름/전화번호 등을 마스킹하여 반환합니다. |
| **CSV → JSON 변환** | S3에 저장된 CSV를 실시간으로 JSON으로 변환해 응답합니다. |
| **이미지 워터마크 추가** | 원본 이미지는 그대로 두고 요청 시 워터마크를 삽입해 반환합니다. |
| **동적 필터링** | 요청자 권한에 따라 필드를 제거하거나 데이터량을 줄이는 등 동적으로 처리합니다. |

## 📎 주요 구성 요소

|항목|설명|
|---|---|
|**Object Lambda Access Point**|기존 S3 버킷 앞단에 위치해 변형 요청을 처리하는 진입점입니다.|
|**Lambda 함수**|`GetObject` 요청을 가로채 가공·필터링 로직을 실행합니다.|
|**IAM 정책**|요청자 권한과 Lambda 역할을 분리해 적절한 접근 제어를 구성해야 합니다.|

## ✅ 장점

|항목|설명|
|---|---|
|**원본 데이터 불변**|S3 내 객체를 직접 수정하지 않고도 다양한 사용자 요구에 대응할 수 있습니다.|
|**스토리지 비용 절감**|사용자별 데이터 복제본을 저장할 필요가 없습니다.|
|**온디맨드 처리**|필요할 때마다 즉시 데이터 변형이 가능합니다.|
|**보안성 강화**|사용자 권한에 따라 다른 데이터를 보여주는 기능을 쉽게 구현할 수 있습니다.|
