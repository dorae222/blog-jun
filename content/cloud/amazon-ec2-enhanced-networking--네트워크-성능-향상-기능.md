Amazon EC2 인스턴스의 **네트워크 성능을 향상**시키는 기능입니다.

이 기능은 **인스턴스 간의 높은 처리량과 낮은 레이턴시(지연시간), 낮은 CPU 사용률**을 실현하므로 실시간 처리가 요구되는 애플리케이션에 적합합니다.

또한, Enhanced Networking는 **추가 요금이 발생하지 않습니다**.

#### EC2 Enhanced Networking을 사용하는 경우

✅ 고성능 애플리케이션 (예: HPC, 빅데이터, 머신러닝, 금융 서비스)  
✅ EC2 인스턴스 간 저지연 통신이 필요한 경우  
✅ 고속 데이터 처리(수백만 PPS)가 필요한 경우
