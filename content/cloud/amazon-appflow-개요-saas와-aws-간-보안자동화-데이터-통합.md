## 🧩 Quick Overview

| 항목        | 설명                                                                                               |
| --------- | ------------------------------------------------------------------------------------------------ |
| **서비스명**  | Amazon AppFlow                                                                                   |
| **유형**    | **SaaS 애플리케이션과 AWS 간 데이터 통합·전송 서비스**                                                             |
| **주요 목적** | **Salesforce, Slack, Google Analytics 등 SaaS 데이터**를 **AWS 서비스(S3, Redshift 등)와 안전하게 양방향 전송·동기화** |

---

## 🔧 주요 특징

|항목|설명|
|---|---|
|**코드 없는 데이터 통합**|GUI 기반으로 SaaS ↔ AWS 간 데이터 흐름(Flow)을 구성할 수 있습니다.|
|**양방향 전송 지원**|SaaS → AWS 또는 AWS → SaaS 방향 모두 지원합니다.|
|**실시간·스케줄링 지원**|이벤트 기반 처리, 배치 처리 및 정기 동기화 등 다양한 실행 방식을 제공합니다.|
|**데이터 변환·필터링**|전송 과정에서 필터링·매핑·변환을 적용할 수 있습니다.|
|**보안 전송**|TLS와 KMS 암호화를 지원하며 VPC 엔드포인트를 통해 프라이빗 연결을 구성할 수 있습니다.|

---

## 🧪 활용 시나리오

- **마케팅·영업 데이터 통합**
  - Salesforce·Marketo의 데이터를 S3·Redshift로 전송해 분석에 활용

- **협업 도구 로그 수집**
  - Slack 메시지 이벤트를 S3에 저장한 뒤 Athena로 분석

- **양방향 워크플로우**
  - AWS에서 처리한 데이터를 SaaS CRM으로 다시 전송하는 워크플로우 구성

- **데이터 레이크·BI 통합**
  - 다양한 SaaS 데이터를 Glue나 QuickSight와 연계하여 데이터 레이크 및 BI 파이프라인 구축

---

## ✅ 장점

- **코드 없는 통합** → 개발 없이 데이터 이동을 자동화할 수 있습니다.
- **다양한 SaaS 지원** → Salesforce, Zendesk, ServiceNow 등 여러 SaaS 커넥터를 제공합니다.
- **보안·규정 준수 용이** → 암호화와 프라이빗 연결 옵션으로 보안 요구사항을 충족하기 쉽습니다.
- **유연한 스케줄링** → 실시간 이벤트 기반 처리와 배치 처리를 모두 지원합니다.

## ⚠️ 유의사항

|항목|설명|
|---|---|
|**지원 SaaS 한정**|지원하지 않는 SaaS의 경우 커스텀 API 연동이 필요할 수 있습니다.|
|**실시간 처리 제한**|완전한 스트리밍 처리보다는 이벤트 중심이나 배치 중심의 동작에 적합합니다.|
|**전송량 과금**|데이터 전송량 및 Flow 실행 횟수에 따라 비용이 발생합니다.|
