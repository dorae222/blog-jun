**CIDR**은 **Classless Inter-Domain Routing**의 약자로,
IP 주소를 **더 유연하고 효율적으로 할당하고 라우팅**할 수 있도록 도와주는 IP 주소 표기법입니다.

---

## 🔍 CIDR이란?

> CIDR은 IP 주소 뒤에 **슬래시(/)** 와 함께 **서브넷 마스크 비트 수를 표기**하여
> IP 주소의 **네트워크 범위를 정의**하는 방식입니다.

예시:

```
192.168.0.0/24
```

- `192.168.0.0`: 네트워크 주소
    
- `/24`: 처음 24비트가 네트워크 부분이라는 의미 (서브넷 마스크: 255.255.255.0)
    
---

## 📦 CIDR의 목적

|목적|설명|
|---|---|
|✅ IP 주소 절약|필요에 따라 다양한 크기의 네트워크를 할당 가능|
|✅ 유연한 서브넷팅|기존 클래스 A/B/C에 얽매이지 않고 원하는 크기만큼 네트워크 분할 가능|
|✅ 라우팅 효율성|더 적은 수의 라우팅 테이블 엔트리로 네트워크 요약 가능|

---

## 🧠 CIDR 표기 예시

|CIDR 표기|서브넷 마스크|IP 개수 (호스트 수)|설명|
|---|---|---|---|
|`10.0.0.0/8`|255.0.0.0|약 1,677만 개|매우 큰 네트워크|
|`10.0.0.0/16`|255.255.0.0|65,536개|중간 규모|
|`10.0.0.0/24`|255.255.255.0|256개|일반 소규모 서브넷|
|`10.0.0.0/32`|255.255.255.255|1개|단일 IP 주소 (예: 보안 규칙에서)|

---

## 🏗️ CIDR in AWS

CIDR은 AWS에서 다음과 같이 광범위하게 사용됩니다:

|서비스|사용 예|
|---|---|
|**VPC**|`10.0.0.0/16` 같은 CIDR 범위 지정|
|**서브넷**|VPC CIDR을 `10.0.1.0/24`, `10.0.2.0/24` 등으로 분할|
|**보안 그룹 / NACL**|특정 IP 대역 허용 또는 차단 (`203.0.113.0/24` 등)|
|**Route Table**|경로 지정 시 대상 CIDR로 라우팅 (`0.0.0.0/0`, `10.0.0.0/16`)|
