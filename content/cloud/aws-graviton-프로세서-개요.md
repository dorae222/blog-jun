## 🧩 빠른 개요

| 항목 | 설명 |
| ---- | ---- |
| **서비스명** | AWS Graviton 프로세서 |
| **유형** | AWS가 설계한 Arm 기반 프로세서 |
| **주요 목적** | 고성능·저비용·에너지 효율적인 EC2 인스턴스 제공 |

---

## 🔧 주요 특징

| 항목 | 설명 |
| --- | --- |
| **Arm 기반 아키텍처** | 64비트 Arm Neoverse 코어 설계 |
| **고성능·저비용** | 동급 x86 대비 최대 40% 비용 절감 |
| **세대별 제품** | Graviton → Graviton2 → Graviton3 (세대별 성능·효율 향상) |
| **다양한 워크로드 지원** | 웹 서버, 컨테이너, 마이크로서비스, 고성능 컴퓨팅(HPC) |
| **AWS 최적화** | Nitro System 기반 EC2 인스턴스에서 제공 (예: M6g, C7g, R7g) |

---

## 🧪 활용 시나리오

- 웹/앱 서버 및 API 백엔드
- 컨테이너 및 마이크로서비스
- 데이터 분석·HPC 워크로드
- 게임 서버 및 실시간 처리
- ARM 기반으로 최적화된 ML·서버리스 워크로드

---

## ✅ 장점

- **비용 효율성** → 동일 성능 대비 최대 40% 비용 절감
- **고성능/저전력** → 에너지 효율 개선으로 탄소 발자국 감소
- **AWS 최적화 생태계** → 주요 운영체제, 컨테이너, 데이터베이스의 지원
- **확장성** → 범용, 컴퓨팅 최적화, 메모리 최적화 인스턴스 제공

---

## ⚠️ 유의사항

| 항목 | 설명 |
| --- | --- |
| **x86 호환성 제한** | 일부 x86 전용 소프트웨어나 라이브러리가 지원되지 않을 수 있음 |
| **이식 작업 필요** | Arm 아키텍처용 빌드 및 테스트 작업 필요 |
| **워크로드 검증 필요** | 고성능 DB나 ML 워크로드는 사전 벤치마크 권장 |
