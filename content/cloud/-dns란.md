## 🌐 DNS란?

> **DNS (Domain Name System)** 는 인터넷 상에서 도메인 이름과 IP 주소를 서로 매핑해주는 시스템입니다.  
> 예를 들어, 사용자가 `www.example.com`에 접속하면, DNS는 이 도메인을 **실제 서버의 IP 주소로 변환**해 브라우저가 해당 서버에 연결할 수 있도록 도와줍니다.

---

## 📌 예시

| 도메인 이름            | DNS가 변환한 IP 주소   |
| ----------------- | ---------------- |
| `www.amazon.com`  | `176.32.98.166`  |
| `chat.openai.com` | `104.22.66.76` 등 |
