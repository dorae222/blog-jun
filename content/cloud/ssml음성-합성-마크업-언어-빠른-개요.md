## 🧩 Quick Overview

| 항목        | 설명                                                       |
| --------- | -------------------------------------------------------- |
| **표준명**   | SSML (Speech Synthesis Markup Language)                  |
| **유형**    | **음성 합성(Speech Synthesis)용 마크업 언어**                      |
| **주요 목적** | **텍스트를 음성으로 변환할 때 발음·억양·속도·강세를 제어**하여 **자연스러운 음성 출력 제공** |

---

## 🔧 주요 특징

|항목|설명|
|---|---|
|**발음 제어**|특정 단어의 발음, 음절 강조, 철자 읽기 방식 등을 지정할 수 있음|
|**억양·속도 조정**|`<prosody>` 태그로 말하기 속도·음정(톤)·볼륨을 제어할 수 있음|
|**일시정지 삽입**|`<break>` 태그로 문장 사이의 간격(휴지)을 조정할 수 있음|
|**언어·목소리 지정**|`<voice>` 태그로 언어, 화자(voice), 성별 등을 설정할 수 있음|
|**특수 효과**|볼륨·피치·속도 변화를 이용해 감정이나 뉘앙스를 표현할 수 있음|

---

## 🧪 활용 시나리오

- **TTS(Text-to-Speech) 서비스**
    - Amazon Polly, Google Cloud TTS, Azure TTS 등에서 활용 가능
- **내비게이션/안내 시스템**
    - 억양과 속도 조절로 자연스러운 음성 안내 제공
- **교육·오디오북 제작**
    - 단어 발음, 강세·휴지 설정으로 청취자의 이해도 향상
- **챗봇·가상 비서**
    - 자연스러운 대화형 음성 인터페이스 구현

---

## ✅ 장점

- **자연스러운 음성 생성** → 강세·억양을 세밀하게 제어 가능
- **다국어 지원 용이** → 언어별 발음과 화자 지정이 가능
- **표준화된 W3C 규격** → 다양한 TTS 엔진 간 호환성 제공

---

## ⚠️ 유의사항

|항목|설명|
|---|---|
|**TTS 엔진 의존**|모든 SSML 태그를 모든 엔진이 지원하는 것은 아님|
|**세밀한 튜닝 필요**|억양·휴지 등 미세한 설정은 반복 테스트를 통해 튜닝 필요|
|**긴 텍스트 한계**|일부 엔진은 입력 텍스트 길이에 제한이 있음|
