## 🧩 Quick Overview

| 항목 | 설명 |
| --- | --- |
| **서비스명** | Amazon WorkSpaces |
| **유형** | **클라우드 기반 가상 데스크톱 인프라(VDI) 서비스** |
| **주요 목적** | 사용자가 **어디서나 안전하게 가상 데스크톱에 접속**해 **Windows·Linux 환경에서 업무**를 수행할 수 있도록 지원 |

---

## 🔧 주요 특징

| 항목 | 설명 |
| --- | --- |
| **클라우드 VDI 제공** | 온프레미스 장비 없이 가상 데스크톱을 실행할 수 있음 |
| **다양한 OS 지원** | Windows, Amazon Linux 2 지원 |
| **보안 접속** | TLS 기반 통신 및 EBS 기반 데이터 암호화 등 기본 보안 적용 |
| **확장성** | 사용량에 따라 데스크톱 수를 유연하게 확장·축소 가능 |
| **요금제 유연성** | 시간 단위 요금제와 월 정액 요금제 선택 가능 |

---

## 🧪 활용 시나리오

- **원격 근무 환경 구축**
  - 재택·하이브리드 근무 시 안전한 가상 데스크톱을 제공
- **BYOD(Bring Your Own Device)**
  - 개인 기기로 접속하더라도 기업 데이터는 클라우드에만 저장되어 보안 유지
- **교육·훈련 환경**
  - 수백 명이 동시에 접속 가능한 실습 및 교육 환경 제공
- **보안 환경 격리**
  - 금융·공공 등 민감 데이터 처리 환경에서 로컬 저장을 방지하여 격리 환경 구성

---

## ✅ 장점

- **관리 부담 감소** → 온프레미스 VDI 인프라를 운영할 필요가 없음
- **보안 강화** → 데이터의 로컬 저장 방지 및 기본 암호화 적용
- **글로벌 확장성** → AWS 리전을 통해 전 세계적으로 배포 가능
- **유연한 과금제** → 시간제와 월 정액 중 사용 패턴에 맞는 요금제 선택으로 비용 최적화

---

## ⚠️ 유의사항

| 항목 | 설명 |
| --- | --- |
| **지연 시간 영향** | 네트워크 품질에 따라 체감 성능이 달라질 수 있음 |
| **그래픽 성능 제한** | 고사양 GPU가 필요한 워크로드는 WorkSpaces의 Graphics Bundle이 필요함 |
| **로컬 장치 사용 제한** | 일부 USB 장치나 프린터 등은 정책상 제한될 수 있음 |
