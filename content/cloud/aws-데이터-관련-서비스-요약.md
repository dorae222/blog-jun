AWS의 데이터 관련 주요 서비스를 간단히 정리한 표입니다.

| 개념                                        | 설명                                 | 키워드 및 예제 상황        |
| ----------------------------------------- | ---------------------------------- | ---------------------- |
| Amazon Athena                             | S3에 저장된 데이터를 SQL로 쿼리하여 분석       | S3 쿼리, 분석 용이         |
| AWS Data Exchange                         | 타사 데이터셋을 구독하고 다운로드할 수 있는 서비스 | 데이터 제공자와 소비자 연결    |
| AWS Data Pipeline                         | ETL 작업을 자동화하는 서비스               | 주기적 데이터 이동          |
| Amazon EMR                                | Hadoop/Spark 기반의 빅데이터 처리 플랫폼     | 대규모 데이터 분석         |
| AWS Glue                                  | 서버리스 ETL 서비스                      | 다양한 소스에서 변환 및 적재   |
| Amazon Kinesis                            | 스트리밍 데이터 수집 및 처리               | 실시간 분석               |
| AWS Lake Formation                        | 데이터 레이크 생성 및 관리                  | 권한 설정, 카탈로그 관리     |
| Amazon Managed Streaming for Apache Kafka | Kafka의 완전관리형 서비스                 | Kafka 활용               |
| Amazon OpenSearch Service                 | Elasticsearch 기반의 검색 및 분석 서비스     | 로그 분석, 검색            |
| Amazon QuickSight                         | BI 도구로서 대시보드와 시각화 제공           | 시각적 리포트 작성         |
| Amazon Redshift                           | 대규모 데이터 웨어하우스                   | SQL 기반 분석, BI 도구 통합   |
