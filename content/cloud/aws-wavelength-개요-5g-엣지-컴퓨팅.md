## 🧩 Quick Overview

| 항목              | 설명 |
|-------------------|------|
| **서비스명**       | AWS Wavelength |
| **유형**           | **5G 엣지 컴퓨팅 서비스** |
| **주요 목적**       | **통신사 5G 네트워크 엣지에 AWS 인프라를 배치**하여  
                       초저지연(ultra-low latency) 애플리케이션 실행 지원 |

> 📡 **AWS Wavelength**는 AWS의 컴퓨팅·스토리지 리소스를
> **통신사 5G 네트워크 엣지 로케이션에 배치**하여
> 모바일·IoT·AR/VR 등에서 **밀리초 수준의 지연**을 제공하는 서비스입니다.

---

## 🔧 주요 특징

| 항목 | 설명 |
|------|------|
| **초저지연 제공** | 사용자가 5G 기지국 근처에서 요청하면 통신망 내부에서 바로 처리되어 지연을 최소화합니다. |
| **AWS 환경 그대로 사용** | EC2, VPC, EBS, Auto Scaling 등 기존 AWS 서비스와 통합되어 익숙한 개발·운영 환경을 유지할 수 있습니다. |
| **통신사 인프라 통합** | Verizon, KDDI, SKT 등 글로벌 통신사들의 5G 엣지에 리소스를 배치합니다. |
| **하이브리드 아키텍처** | Wavelength Zone과 AWS 리전 리소스를 조합해 엣지 처리와 리전 처리를 분리하며 확장 가능합니다. |

---

## 🧪 활용 시나리오

- **AR/VR·게임 스트리밍**
  - 5G 기반 실시간 렌더링 및 스트리밍에 적합합니다.
- **자율주행 차량/드론 제어**
  - 밀리세컨드 단위 응답이 필요한 제어 로직은 로컬 엣지에서 처리합니다.
- **스마트 팩토리/IoT**
  - 대규모 센서 데이터를 실시간으로 수집·분석하여 지연에 민감한 처리를 엣지에서 수행합니다.
- **영상 분석·보안 모니터링**
  - 카메라 데이터를 로컬에서 전처리·분석한 뒤 요약 결과만 리전으로 전송합니다.

---

## ✅ 장점

- **밀리초 단위 지연** → 5G 기반 MEC(Mobile Edge Computing)에 최적화되어 실시간성 요구를 충족합니다.
- **AWS와 동일한 개발 경험** → VPC, EC2, Auto Scaling, IAM 등 기존 AWS 서비스와 동일한 방식으로 개발·운영할 수 있습니다.
- **트래픽 오프로드** → 엣지에서 데이터 전처리를 수행해 리전으로 전송되는 트래픽을 줄입니다.
- **글로벌 통신사 연계** → 기존 통신망과의 통합이 보장되어 서비스 배포 범위를 확장할 수 있습니다.

## ⚠️ 유의사항

| 항목 | 설명 |
|------|------|
| **특정 통신사/리전 한정** | Wavelength Zone은 일부 국가와 통신사에 한해서만 제공됩니다. |
| **리소스 제한** | 모든 AWS 서비스가 제공되는 것은 아니며, 주로 컴퓨팅·스토리지 중심의 리소스가 배치됩니다. |
| **애플리케이션 설계 필요** | 엣지 처리와 리전 처리를 분리하는 아키텍처 설계가 필요합니다. |
