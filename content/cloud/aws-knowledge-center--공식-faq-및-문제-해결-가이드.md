## 🔧 주요 특징

| 항목 | 설명 |
|------|------|
| **FAQ 및 문제 해결 가이드** | S3, EC2, RDS 등 서비스별 자주 발생 문제 해결 방법 제공 |

| **Support와 연계** | Knowledge Center에서 해결책 찾기 실패 시 Support Case 생성 가능

## 🧪 활용 예시

- **오류 코드 검색**
  - 예: `"AccessDenied" S3 업로드 오류` 검색 → 권한 정책 수정 방법 제공
- **서비스 제한/제한 해제 방법 확인**
  - 예: `"EC2 service quota increase"` 가이드
- **베스트 프랙티스 확인**
  - 예: `"RDS snapshot 공유 방법"`

## ✅ 장점

- **공식성**: AWS Support 팀 작성으로 신뢰도 높음
- **셀프 서비스 문제 해결**: Support Case 생성 전 스스로 해결 가능
- **빠른 검색**: 서비스·오류코드 기반 탐색 가능
- **지속 업데이트**: 신규 서비스/기능 출시 시 관련 문서 갱신

## ⚠️ 유의사항

| 항목 | 설명 |
|------|------|
| **심층 지원은 불가** | 일반적인 문제 해결 가이드 위주이며, 환경별 맞춤 솔루션은 필요 시 Support Case를 활용해야 함 |
| **영문 자료 중심** | 한글 번역이 일부 제공되나 최신 정보는 영어 문서가 우선임 |
