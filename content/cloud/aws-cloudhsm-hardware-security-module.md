**AWS CloudHSM (Hardware Security Module)**은 고객이 자신의 암호화 키를 직접 생성·관리·제어할 수 있도록 물리적 전용 HSM(하드웨어 보안 모듈)을 제공하는 서비스입니다. FIPS 140-2 Level 3 인증을 충족하며, 규제 준수나 높은 보안 수준이 요구되는 금융·정부·헬스케어 등 산업에 적합합니다.

---

## 🔐 CloudHSM 핵심 개념

| 항목                | 설명                                                       |
| ----------------- | -------------------------------------------------------- |
| **HSM**           | Hardware Security Module, **암호화 키를 생성/저장/관리**하는 보안 전용 장치 |
| **CloudHSM**      | AWS가 제공하는 **클라우드 기반 HSM 서비스**로, 고객에게 전용 HSM을 프로비저닝함        |
| **완전한 키 소유권**     | AWS는 고객 키에 접근할 수 없으며, **고객만이 키를 소유하고 제어**함                   |
| **FIPS 140-2 인증** | Level 3 인증을 받았으며, **정부 및 금융 산업의 규제 요건**을 충족할 수 있음            |

---

## 🎯 주요 기능

|기능|설명|
|---|---|
|✅ **전용 HSM 장비**|고객 전용 장치로 프로비저닝되어 멀티테넌트 환경이 아님|
|✅ **자체 키 생성 및 저장**|키를 고객이 직접 생성하고 CloudHSM 내부에만 저장 가능|
|✅ **AWS와 연동 가능**|KMS, ACM, Redshift, RDS 등 AWS 서비스와 연계 가능|
|✅ **표준 암호화 API 제공**|PKCS#11, JCE(Java), OpenSSL 등 표준 API 지원|
|✅ **고가용성 구성**|다중 AZ(가용 영역)에 클러스터 구성으로 고가용성 지원|
|✅ **규정 준수 지원**|FIPS 140-2 Level 3, PCI DSS, HIPAA 등 규제 요구사항 충족 지원|

## 🧩 활용 사례

|분야|설명|
|---|---|
|🔐 **고급 암호화 키 저장**|고객 소유의 암호화 키를 안전하게 보관하고, KMS 등과 연동하여 사용|
|🏦 **규제 준수 산업 (금융, 헬스케어 등)**|키의 완전한 통제권이 요구되는 환경에서 활용|
|📄 **디지털 서명 및 인증서 발급**|PKI 구축, SSL/TLS 인증서 발급 및 서명 작업 수행|
|📦 **S3 객체, RDS 데이터 암호화**|CloudHSM을 KMS와 결합해 대칭/비대칭 암호화 작업에 사용|

---

## 🔧 동작 방식 요약

1. CloudHSM 클러스터 생성 (하나 이상의 HSM 노드 포함)
2. 클라이언트 애플리케이션에 HSM 클라이언트 설치
3. 애플리케이션이 표준 API(PKCS#11 등)를 통해 HSM에 요청
4. HSM 내부에서 암호화/복호화/서명 등을 수행하며, 키는 HSM 외부로 유출되지 않음

## 🆚 AWS KMS vs CloudHSM

|항목|**AWS KMS**|**AWS CloudHSM**|
|---|---|---|
|키 소유|AWS가 키를 관리|고객이 키를 완전 소유| 
|사용 편의성|매우 쉬움 (완전 관리형)|설정이 복잡하며 전문가 수준의 관리 필요|
|확장성|완전 관리형으로 용이|직접 클러스터를 관리하고 확장해야 함|
|규제 수준|FIPS 140-2 Level 2|FIPS 140-2 **Level 3**|
|사용 예|일반 암호화(예: S3, EBS)|**고급 보안 요구, 규제 산업, PKI, 커스텀 암호화 로직**|
