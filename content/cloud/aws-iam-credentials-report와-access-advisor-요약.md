> - IAM Credentials Report (Account-level)
>   - 계정의 모든 사용자와 각 사용자의 자격 증명 상태를 나열하는 보고서입니다.
> - IAM Access Advisor (User-level)
>   - Access Advisor는 사용자에게 부여된 서비스 권한과 해당 서비스들이 마지막으로 접근된 시점을 보여줍니다.
