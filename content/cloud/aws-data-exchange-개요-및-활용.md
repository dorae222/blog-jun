## 🧩 Quick Overview

|항목|설명|
|---|---|
|**서비스명**|AWS Data Exchange|
|**유형**|**데이터 구독·배포 플랫폼**|
|**주요 목적**|AWS 환경에서 **서드파티 데이터 세트**를 안전하게 **찾기, 구독, 사용, 배포**할 수 있도록 지원|

---

## 🔧 주요 특징

|항목|설명|
|---|---|
|**데이터 마켓플레이스**|수천 개의 서드파티 데이터 제품(금융, 날씨, 산업, 의료 등)을 제공|
|**S3·Redshift 통합**|구독한 데이터셋을 바로 S3 또는 Redshift에 로드할 수 있음|
|**자동 업데이트**|데이터 제공자가 새 데이터를 게시하면 구독자에게 자동으로 반영됨|
|**배포 지원**|자체 데이터 제품을 패키징해 AWS Marketplace에서 배포할 수 있음|
|**보안·결제 통합**|IAM 권한과 AWS Marketplace 결제·정산과 연계되어 관리 가능|

---

## 🧪 활용 시나리오

- **외부 데이터 기반 ML 모델 학습**
  - 날씨, 금융, 소셜 트렌드 데이터 등으로 예측 모델 성능 강화

- **데이터 분석 및 BI**
  - Redshift·Athena와 연계해 분석 및 시각화 수행

- **기업 간 데이터 공유**
  - 공급망·파트너사와의 데이터 교환을 자동화

- **데이터 수익화**
  - 사내 데이터를 데이터 제품으로 포장해 AWS Marketplace에서 판매

---

## ✅ 장점

- **데이터 탐색·구독 간소화** → AWS 환경 내에서 바로 사용 가능

- **자동 업데이트** → 데이터의 최신 상태 유지 용이

- **보안·결제 통합** → IAM 및 Marketplace 연계로 관리가 편리함

- **데이터 수익화 가능** → 자체 데이터 판매 채널 제공

## ⚠️ 유의사항

|항목|설명|
|---|---|
|**AWS 계정 필요**|데이터 구독·배포 모두 AWS 계정 및 환경에서 수행해야 함|
|**유료 데이터 다수**|데이터 사용량과 구독료에 따라 비용이 발생할 수 있음|
|**데이터 품질 의존**|데이터의 품질은 제공자에 따라 달라지므로 검증 필요|
