## 🧩 Quick Overview

| 항목        | 설명                                                              |
| --------- | --------------------------------------------------------------- |
| **서비스명**  | AWS CodeDeploy                                                  |
| **유형**    | **애플리케이션 자동 배포 서비스(CI/CD)**                                     |
| **주요 목적** | 애플리케이션을 **EC2, Lambda, 온프레미스 서버**로 **자동 배포**하고 **다운타임을 최소화**하는 데에 목적이 있음 |

---

## 🔧 주요 특징

|항목|설명|
|---|---|
|**멀티 환경 배포 지원**|EC2, Lambda, ECS, 온프레미스 서버에 배포 가능|
|**배포 방식 다양**|인플레이스(In-Place) 및 블루/그린(Blue/Green) 배포 방식 지원|
|**자동 롤백**|배포 실패 시 이전 버전으로 자동 복구 가능|
|**CI/CD 통합**|CodePipeline, GitHub, Jenkins 등과 연계하여 파이프라인에 통합 가능|
|**배포 상태 모니터링**|CloudWatch, EventBridge, SNS 등과 연계해 배포 상태 모니터링 및 알림 지원|

---

## 🧪 활용 시나리오

- **웹 애플리케이션 업데이트**
    - EC2 또는 온프레미스 서버에 무중단 배포

- **서버리스 함수 배포**
    - Lambda 버전별 배포 및 Canary/Linear 방식으로 트래픽 전환

- **컨테이너 워크로드 배포**
    - ECS 또는 하이브리드 환경에서 배포 자동화

- **DevOps CI/CD 파이프라인**
    - CodeCommit → CodeBuild → CodeDeploy → 운영 배포 흐름에 통합

---

## ✅ 장점

- **배포 자동화** → 수동 배포로 인한 오류 및 다운타임 최소화
- **유연한 배포 전략** → 블루/그린, 카나리아, 선형 트래픽 전환 지원으로 다양한 배포 요구 충족
- **롤백 기능 내장** → 배포 실패 시 신속한 서비스 복원 가능
- **다양한 환경 지원** → 클라우드, 온프레미스, 서버리스 환경을 아우르는 통합 배포 지원

## ⚠️ 유의사항

|항목|설명|
|---|---|
|**초기 설정 필요**|AppSpec 파일 작성 및 적절한 IAM 권한 구성 필요|
|**모니터링 필수**|배포 중 오류 감지 및 자동 롤백을 위해 CloudWatch 등과 연계한 모니터링 권장|
|**네트워크 접근 필요**|온프레미스 대상에 배포할 경우 인터넷 또는 VPC 연결 등 네트워크 접근이 필요|
