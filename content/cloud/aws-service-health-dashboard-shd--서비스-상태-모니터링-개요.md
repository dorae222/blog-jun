## 🧩 Quick Overview

| 항목        | 설명                                                           |
| --------- | ------------------------------------------------------------ |
| **서비스명**  | AWS Service Health Dashboard (SHD)                           |
| **유형**    | **AWS 서비스 상태 모니터링 대시보드**                                     |
| **주요 목적** | **전 세계 AWS 리전·서비스 상태를 실시간으로 확인**하고 **장애·유지보수·가용성 정보를 공개** 제공 |

> 🌐 **Service Health Dashboard**는 **모든 AWS 사용자에게**
> **AWS 서비스별/리전별 상태**를 조회할 수 있는
> **공식 공개 상태 페이지**입니다.

---

## 🔧 주요 특징

| 항목 | 설명 |
|------|------|
| **공개 서비스 상태 제공** | AWS 전 서비스·리전별 가용성, 장애, 성능 저하 현황 표시 |
| **이벤트 유형 분류** | 서비스 중단, 성능 저하, 예정 유지보수 등 |
| **글로벌 커버리지** | 전 세계 리전(AZ 포함) 상태 확인 가능 |
| **역사적 이벤트 확인** | 과거 서비스 이벤트 기록 열람 가능 |
| **로그인 불필요** | 모든 사용자에게 공개 제공 |

---

## 🧪 활용 시나리오

- **AWS 서비스 장애 여부 확인**
  - 예: `us-east-1` S3 서비스 지연 발생 여부 확인
- **리전 선택 후 상태 확인**
  - 특정 리전에 배포된 워크로드 영향 여부 판단
- **장애·유지보수 이력 확인**
  - 과거 이벤트 분석으로 가용성 관리 및 SLA 참고

---

## ✅ 장점

- **공식 상태 정보 제공** → 장애 발생 시 즉시 근거 확인 가능
- **글로벌 서비스 모니터링** → 멀티리전 아키텍처 운영 시 필수 도구
- **로그인 필요 없음** → 누구나 접근 가능
- **이력 데이터 제공** → 장애 분석 및 SLA 준수 검증에 활용

---

## ⚠️ 유의사항

| 항목 | 설명 |
|------|------|
| **계정 맞춤 알림 없음** | 내 리소스 영향 여부는 **Personal Health Dashboard**에서 확인 필요 |
| **실제 복구는 고객 책임** | 상태 확인만 제공하며 자동 복구 기능은 없음 |
| **실시간 알림 제한** | 이메일·SNS 알림은 지원하지 않음 (EventBridge 불가) |
