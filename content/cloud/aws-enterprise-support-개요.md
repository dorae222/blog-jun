## 🧩 Quick Overview

| 항목              | 설명 |
|-------------------|------|
| **서비스명**       | AWS Enterprise Support |
| **유형**           | **프리미엄 등급 클라우드 기술 지원 서비스** |
| **주요 목적**       | 대규모·비즈니스 크리티컬 워크로드를 운영하는 고객에게  
                       **24/7 기술 지원, 운영 가이드, 아키텍처 최적화** 제공 |

> 🏢 **AWS Enterprise Support**는 기업 고객이  
> **안정적·안전한 클라우드 운영과 최적화된 비용·아키텍처 설계**를 수행할 수 있도록  
> **전문가와 도구 기반의 엔터프라이즈급 지원**을 제공합니다.

---

## 🔧 주요 특징

| 항목 | 설명 |
|------|------|
| **24/7 기술 지원** | 전화·채팅·콘솔 Case로 연중무휴 지원 |
| **Technical Account Manager(TAM)** | 전담 기술 계정 관리자 배정 |
| **Well-Architected Review** | 아키텍처 점검 및 모범 사례 제공 |
| **Proactive Guidance** | 운영 최적화, 비용 절감, 보안 개선 제안 |
| **AWS Infrastructure Event Management(IEM)** | 중요 이벤트/배포 전 사전 점검 지원 |
| **지원 채널 통합** | Trusted Advisor, Health Dashboard 연계 |

---

## 📦 지원 범위

| 지원 영역 | 예시 |
|----------|------|
| **운영 지원** | 장애 트러블슈팅, 성능 문제 해결 |
| **아키텍처 검토** | 고가용성, 확장성, 보안 설계 검토 |
| **비용 최적화** | 리소스 사용 분석 및 절감 전략 제시 |
| **보안·컴플라이언스** | IAM, VPC 설계, 규제 대응 가이드 |

---

## 🧪 활용 시나리오

- 미션 크리티컬 서비스 운영 (금융, 게임, 커머스 등)
- 신규 서비스 대규모 런칭 전 사전 검토
- DR(재해 복구), 멀티 리전/멀티 AZ 아키텍처 설계
- 비용 효율화 및 보안 감사 대응

---

## ✅ 장점

- **전담 TAM 배정** → 전략적 운영 지원 및 사전 예방적 가이드 제공
- **24/7 대응** → 장애·성능 문제에 대한 즉각 대응 가능
- **아키텍처 최적화** → 비용·성능·보안 전반에 대한 검토 제공
- **엔터프라이즈 전용 서비스 연계** → IEM, Operations Reviews 등 엔터프라이즈 전용 서비스 이용 가능

## ⚠️ 유의사항

| 항목 | 설명 |
|------|------|
| **비용 부담 높음** | 월 사용료 또는 월 사용량의 일정 비율(10만 USD 이상 고객 기준) |
| **운영 역량 필요** | 권고 사항을 반영할 내부 운영팀 필요 |
| **서비스 범위 인지 필요** | 애플리케이션 코드 디버깅은 직접 수행해야 함 |
