## 🧩 Quick Overview

| 항목              | 설명 |
|-------------------|------|
| **서비스명**       | AWS re:Post |
| **유형**           | **커뮤니티 기반 Q&A 및 기술 지원 플랫폼** |
| **주요 목적**       | AWS 사용자가 **질문·답변·베스트 프랙티스 공유**를 통해  
                       **문제 해결 및 지식 교류**를 할 수 있도록 지원 |

> 💬 **AWS re:Post**는 AWS 포럼의 차세대 버전으로,  
> **AWS 전문가·사용자·파트너**가 참여하는 **공식 기술 Q&A 커뮤니티**입니다.

---

## 🔧 주요 특징

| 항목 | 설명 |
|------|------|
| **Q&A 기반 커뮤니티** | AWS 서비스 관련 질문 작성 및 답변 공유 |
| **AWS 전문가 참여** | AWS 직원·커뮤니티 전문가의 공식 답변 제공 |
| **태그·검색 기능** | 서비스·주제별 태그로 질문 탐색 가능 |
| **Best Practice 공유** | 모범 사례, 아키텍처 팁, 운영 경험 제공 |
| **기술 지원 연계** | AWS Support와 연계하여 공식 답변 가능 (Business/Enterprise 계정) |
| **퍼스널라이즈 피드** | 사용자의 관심 서비스·태그 기반 질문 추천 |

---

## 🧪 활용 예시

1. **문제 해결**
   - "S3 Event Notification이 Lambda에서 작동하지 않습니다. 원인?"  
   - 전문가·사용자 답변을 통해 트러블슈팅
2. **아키텍처 설계 조언**
   - "Aurora MySQL과 DynamoDB를 함께 사용할 경우 베스트 프랙티스?"
3. **서비스 업데이트 학습**
   - 신규 서비스/기능 관련 Q&A 및 사례 공유

---

## ✅ 장점

- **AWS 공식 커뮤니티** → 신뢰성 있는 답변 확보
- **전 세계 전문가 참여** → 다양한 관점의 문제 해결 가능
- **무료 기술 지원** → 기본적인 Q&A는 Support 플랜 없이도 가능
- **검색 기반 학습** → 과거 유사 사례 참고 가능

| **보안 정보 주의** | 계정 정보, 키 등 민감한 데이터는 게시 금지 |
