> **NOTE:** 간단히 말해 웹 프레임워크를 위한 Wrapper
> - WSGI는 “Web Server Gateway Interface”의 약자로, 파이썬 애플리케이션과 웹 서버 간의 통신을 위한 **표준 인터페이스**입니다.
> - WSGI를 통해 웹 서버(예: Nginx, Apache)와 Flask나 Django 같은 파이썬 웹 프레임워크가 동일한 방법으로 요청과 응답을 주고받을 수 있게 됩니다.
