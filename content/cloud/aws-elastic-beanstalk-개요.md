- 웹 및 앱 배포 자동화 서비스
- PaaS(Platform as a Service) 환경 제공
- 웹 애플리케이션 및 서비스를 배포하고 운영하는 서비스
- 사용자가 직접 인프라 리소스를 구성할 필요 없이 애플리케이션 코드에만 집중 가능
- AWS 인프라에 대한 상세한 지식이 없어도 애플리케이션 배포 가능
- 코드를 업로드하면 Elastic Beanstalk이 용량 프로비저닝, 로드 밸런싱, Auto Scaling, 애플리케이션 상태 모니터링 등 배포 관련 작업을 AWS에서 자동으로 처리
- Java, .NET, PHP, Node.js, Python, Ruby, Go 및 Docker 기반 웹 애플리케이션을 지원
