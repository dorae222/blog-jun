## 🧩 Quick Overview

| 항목        | 설명                                                          |
| --------- | ----------------------------------------------------------- |
| **서비스명**  | Amazon Redshift                                             |
| **유형**    | **클라우드 기반 완전관리형 데이터 웨어하우스(DWH) 서비스**                        |
| **주요 목적** | 대규모 구조화·반구조화 데이터를 **빠르게 저장·쿼리·분석**하여 **BI, 분석, ML 워크로드**를 지원 |

---

## 🔧 주요 특징

| 항목                    | 설명                                                   |
| --------------------- | ---------------------------------------------------- |
| **MPP 아키텍처**          | 다중 병렬 처리(Massively Parallel Processing) 기반으로 대규모 쿼리 처리에 최적화 |
| **완전관리형**             | 인프라 관리, 백업, 패치, 확장을 자동화하여 운영 부담을 최소화                               |
| **Redshift Spectrum** | S3에 저장된 데이터 레이크를 직접 쿼리할 수 있는 기능(서버리스 분석 지원)                        |
| **컬럼 기반 저장**          | 컬럼 압축과 고속 스캔을 통해 쿼리 성능을 최적화                            |
| **자동 확장**             | RA3 인스턴스 및 AQUA(쿼리 가속)를 활용한 확장성 제공                       |
| **BI·ML 통합**          | QuickSight, SageMaker, Athena 등 AWS 서비스와의 연동을 통해 BI·ML 워크플로우 통합 가능               |

---

## 🧪 활용 시나리오

- **데이터 웨어하우스 구축**
    - 수 TB ~ PB 규모의 분석 데이터를 저장·처리

- **BI·대시보드 분석**
    - QuickSight, Tableau 등과 연결해 실시간 또는 근실시간 분석 수행

- **데이터 레이크 통합**
    - S3의 데이터와 결합해 레이크하우스(Lakehouse) 패턴 구현

- **ML/예측 분석**
    - SageMaker 또는 Redshift ML을 활용한 모델 학습 및 예측 수행

---

## ✅ 장점

- **대규모 데이터 고속 처리** → MPP 아키텍처와 컬럼형 저장 구조로 대용량 쿼리 처리에 강점

- **관리 부담 최소화** → 완전관리형 서비스로 자동 백업·패치 등 운영 작업 간소화

- **비용 효율성** → 스토리지와 컴퓨팅의 분리로 사용량 기반 비용 최적화 가능

- **AWS 생태계 통합** → S3, Glue, Athena, SageMaker 등과의 연계가 용이

---

## ⚠️ 유의사항

|항목|설명|
|---|---|
|**실시간 트랜잭션엔 부적합**|데이터 웨어하우스(DW)/OLAP 중심 설계로 OLTP(실시간 트랜잭션 처리) 용도에는 적합하지 않음|
|**스키마 설계 중요**|성능 최적화를 위해 분산키(distribution key)와 정렬키(sort key) 설계가 필요|
|**데이터 로딩 전략 필요**|COPY, Glue, DMS 등 도구를 활용한 배치 기반 로딩 전략 설계가 필수|
