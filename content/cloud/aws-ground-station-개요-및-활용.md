## 🧩 Quick Overview

| 항목        | 설명                                                              |
| --------- | --------------------------------------------------------------- |
| **서비스명**  | AWS Ground Station                                              |
| **유형**    | **위성 통신·데이터 수집 서비스 (Satellite Ground Station as a Service)**    |
| **주요 목적** | **위성과 직접 통신**하여 데이터를 수집하고, 이를 **AWS 클라우드로 실시간 전송·처리**할 수 있도록 지원 |

> 🛰 **AWS Ground Station**은 물리적인 지상국을 직접 구축하지 않고도  
> **AWS 인프라 기반의 전 세계 지상국 네트워크**를 활용해  
> **위성 데이터를 수집·처리·분석**할 수 있는 서비스입니다.

---

## 🔧 주요 특징

| 항목 | 설명 |
|------|------|
| **지상국 인프라 관리 불필요** | AWS가 전 세계 지상국을 운영하므로 고객은 지상국 운영 대신 세션 예약만 하면 됩니다. |
| **실시간 데이터 수집** | 위성과의 통신을 통해 이미지·영상·센서 데이터를 실시간으로 수집할 수 있습니다. |
| **AWS 서비스 통합** | 수집한 데이터를 S3, EC2, SageMaker, Kinesis, Lambda 등 AWS 서비스로 바로 연계해 처리할 수 있습니다. |
| **글로벌 네트워크** | 전 세계 다수 지상국 위치에서 위성 신호를 수신할 수 있어 지리적 커버리지가 넓습니다. |
| **시간 단위 과금** | 실제 지상국 사용 시간만큼 과금되는 온디맨드(시간 단위) 과금 모델을 제공합니다. |

---

## 🧪 활용 시나리오

- **지구 관측/원격 탐사 (EO/RS)**  
  - 기상 데이터, 산불/홍수 감시, 농업·해양 모니터링 등에서 사용
- **위성 통신/데이터 중계**  
  - 저궤도(LEO) 위성 네트워크의 데이터 수집
- **재난 감시 및 응급 대응**  
  - 재난 상황 발생 시 위성 이미지를 실시간으로 전송하여 대응 지원
- **군사/보안/환경 모니터링**  
  - 민감 지역이나 환경 데이터의 수집 및 분석

---

## ✅ 장점

- **지상국 구축 비용 절감** → 대규모 초기 투자(CapEx) 없이 운영비(OPEX) 기반으로 사용 가능
- **데이터 처리 속도 향상** → S3/Kinesis/SageMaker 등과 연계해 실시간 또는 거의 실시간으로 처리 가능
- **확장성** → 여러 위성을 동시에 관리·수집할 수 있음
- **글로벌 커버리지** → 다양한 지리적 위치에서 위성 신호를 수신할 수 있음

## ⚠️ 유의사항

| 항목 | 설명 |
|------|------|
| **사용권 허가 필요** | 위성 주파수 및 통신은 각국 규제 기관의 승인(라이선스)이 필요할 수 있습니다. |
| **예약형 사용 모델** | 위성이 관측 가능할 때(Pass)에 맞춰 세션을 예약해야 합니다. |
| **데이터 전송 비용 고려** | 지상국에서 AWS 리전으로 데이터를 전송할 경우 데이터 전송 요금이 발생할 수 있습니다. |
