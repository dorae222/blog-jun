> **NOTE:**
> - AWS에서 **사전 정의하고 유지 관리**하는 IAM 정책입니다.
> - 일반적인 사용 사례(예: AmazonEC2ReadOnlyAccess, AmazonS3FullAccess, AmazonSSMManagedInstanceCore 등)에 대해 **즉시 사용 가능**합니다.
> - 보안 또는 기능 변경이 있을 때 AWS가 정책을 자동으로 업데이트하고 유지 보수합니다.

### 📝 용어 정리

| 한국어 용어         | 영어 표현                             |
| -------------- | --------------------------------- |
| AWS 관리형 IAM 정책 | **AWS managed policy**            |
| 고객 관리형 IAM 정책  | **Customer managed policy**       |
| IAM 정책(정책 문서)  | **IAM policy**                    |
| IAM 역할에 연결된 정책 | **IAM policy attached to a role** |
