## 🧩 Quick Overview

| 항목        | 설명                                                  |
| --------- | --------------------------------------------------- |
| **서비스명**  | AWS Cloud9                                          |
| **유형**    | **클라우드 기반 통합 개발 환경(IDE)**                           |
| **주요 목적** | 브라우저에서 **코드 작성·실행·디버깅**을 할 수 있는 **관리형 클라우드 IDE 제공** |

---

## 🔧 주요 특징

|항목|설명|
|---|---|
|**브라우저 기반 IDE**|로컬에 별도 설치하지 않고 브라우저에서 코드 작성, 편집, 디버깅 가능|
|**여러 언어 지원**|Python, Node.js, JavaScript, PHP 등 주요 프로그래밍 언어 지원|
|**터미널·CLI 통합**|AWS CLI·SDK가 사전 설치되어 있어 서버 관리 및 빌드 작업 가능|
|**실시간 협업**|팀원이 동시에 동일한 환경에서 코드 편집 가능|
|**EC2 또는 Cloud9 환경**|사용자가 EC2 인스턴스를 사용하거나 Cloud9의 관리형 환경을 선택 가능|

---

## 🧪 활용 시나리오

- **클라우드 네이티브 개발**
  - 로컬 환경 없이 Lambda, EC2, S3를 연계한 개발 수행

- **서버리스 애플리케이션 빌드**
  - SAM, Lambda 함수 작성 및 테스트에 활용

- **팀 실습·교육 환경**
  - 브라우저 기반의 협업 IDE를 통해 실습 환경 제공

- **보안 제한 환경 개발**
  - 로컬 소프트웨어 설치가 불가한 환경에서 브라우저로 개발 수행

---

## ✅ 장점

- **로컬 환경 불필요** — 브라우저만으로 개발 가능
- **AWS 서비스 통합** — Lambda, S3, EC2 등과 직접 연계 가능
- **협업 개발 지원** — 실시간 동시 코드 편집 지원
- **보안·유연성 강화** — 코드와 데이터가 클라우드에 저장되어 관리 용이

---

## ⚠️ 유의사항

|항목|설명|
|---|---|
|**인터넷 의존성**|네트워크 연결이 필요하여 오프라인 개발 불가|
|**리소스 제한**|관리형 환경은 CPU와 메모리 등 리소스에 제한이 있음|
|**비용 발생**|EC2, 스토리지, 네트워크 전송량 등에 따른 과금이 발생할 수 있음|
