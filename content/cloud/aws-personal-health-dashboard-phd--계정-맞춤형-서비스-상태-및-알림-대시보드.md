## 🧩 Quick Overview

| 항목        | 설명                                                       |
| --------- | -------------------------------------------------------- |
| **서비스명**  | AWS Personal Health Dashboard (PHD)                      |
| **유형**    | **계정 맞춤형 서비스 상태 및 알림 대시보드**                              |
| **주요 목적** | AWS 계정과 리소스에 **직접적인 영향을 주는 이벤트**를 **실시간으로 모니터링**하고 알림 제공 |

> 📊 **Personal Health Dashboard**는
> **AWS 서비스 상태 변화가 내 계정 리소스에 미치는 영향**을
> **개인화된 형태로 표시**하여 빠른 대응을 지원합니다.

---

## 🔧 주요 특징

| 항목 | 설명 |
|------|------|
| **계정 맞춤형 이벤트 제공** | 서비스 장애, 유지보수 등 **내 리소스에 직접 영향 있는 이벤트만 표시** |
| **알림·이력 제공** | 현재·예정·과거 이벤트를 모두 확인 가능 |
| **AWS Health 연계** | Health API, EventBridge를 통해 자동화된 대응 가능 |
| **분류된 이벤트** | 운영 이벤트, 예정 유지보수, 보안/규정 준수 관련 알림 |

---

## 📦 이벤트 유형

1. **계정 이벤트(Account-Specific Events)**  
   - 내 계정의 EC2, RDS, S3 등 리소스에 직접적 영향
2. **예방적 알림(Proactive Notifications)**  
   - 유지보수, 인증서 갱신, 예정된 리소스 변경 등
3. **이력 조회(Event History)**  
   - 과거 이벤트와 조치 내역 확인 가능

---

## 🧪 활용 시나리오

- **장애 대응**
  - EC2 인스턴스 호스트 장애 발생 시 실시간 알림
- **유지보수 관리**
  - RDS 예정 패치, EC2 호스트 교체 계획 확인
- **보안·규정 준수 대응**
  - SSL 인증서 만료, 보안 권고 알림 확인

---

## ✅ 장점

- **맞춤형 알림 제공** → 내 계정/리소스에만 집중
- **운영 대응 속도 향상** → EventBridge·SNS 연계 자동화 가능
- **이력 기반 감사 지원** → 과거 이벤트 및 대응 조치 확인 가능
