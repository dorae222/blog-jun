## 🧩 Quick Overview

| 항목        | 설명                                                           |
| --------- | ------------------------------------------------------------ |
| **서비스명**  | AWS Trusted Advisor                                          |
| **유형**    | **AWS 리소스 최적화·보안·비용 관리 가이드 서비스**                             |
| **주요 목적** | AWS 계정의 **리소스 상태를 점검**하고 **비용 절감, 보안 강화, 성능·신뢰성 개선** 권장사항 제공 |

---

## 🔧 주요 특징

|항목|설명|
|---|---|
|**리소스 점검**|보안 설정, 서비스 한도, 비용 최적화 등 리소스 상태를 점검|
|**권장사항 제공**|비용 절감, 보안 강화, 성능 개선, 서비스 한도 초과 방지 등을 위한 구체적 권장사항 제시|
|**카테고리별 점검**|비용 최적화, 성능, 보안, 내결함성, 서비스 한도 등 카테고리별 점검 항목 제공|
|**대시보드 시각화**|점검 결과와 권장 조치의 상태를 대시보드로 시각화|
|**AWS Support 연계**|Business·Enterprise Support 플랜과 연계하면 전체 점검 항목을 확인 가능|

---

## 🧪 활용 시나리오

- **비용 절감**
    - 미사용 EC2·EBS·Elastic IP 식별 후 정리하여 비용 절감

- **보안 강화**
    - 퍼블릭으로 노출된 S3 버킷, 과도한 IAM 권한 등 보안 취약점 탐지

- **성능 최적화**
    - 로드밸런서와 오토스케일링 설정 개선 등 성능 관련 권장사항 제공

- **서비스 한도 모니터링**
    - vCPU, Elastic IP, RDS 인스턴스 등 서비스 한도(quotas) 확인 및 초과 방지

---

## ✅ 장점

- **자동 점검·권장 제공** → 운영 관리 효율성 향상
- **비용·보안·성능·신뢰성 통합 관리**로 전반적 리소스 상태 파악 용이
- **AWS Support 연계** 시 엔터프라이즈급 운영 최적화에 유리
- **실시간(또는 주기적) 대시보드 제공**으로 문제 식별과 우선순위 설정이 쉬움

---

## ⚠️ 유의사항

|항목|설명|
|---|---|
|**지원 범위 차등**|기본(무료) 계정은 핵심 점검만 제공하며, 전체 점검 항목은 Business·Enterprise Support가 필요함|
|**자동 수정 불가**|권장사항은 제안 형태로 제공되며, 실제 수정·적용은 수동으로 수행해야 함|
|**점검 주기 한계**|일부 항목은 실시간 점검이 아니며 주기적으로 업데이트됨|
