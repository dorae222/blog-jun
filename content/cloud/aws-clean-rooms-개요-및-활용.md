## 🧩 Quick Overview

|항목|설명|
|---|---|
|**서비스명**|AWS Clean Rooms|
|**유형**|**보안 데이터 협업(Privacy-Preserving Data Collaboration) 서비스**|
|**주요 목적**|여러 조직이 **민감 데이터를 직접 공유하지 않고**,|

```
                보호된 환경에서 안전하게 데이터 분석·조합 가능
```

---

## 🔧 주요 특징

|항목|설명|
|---|---|
|**데이터 비공개 협업**|실제 데이터 이동 없이 암호화·정책 기반으로 협업|
|**쿼리 기반 분석**|SQL 쿼리를 통해 교집합·집계·모델링 수행 가능|
|**정책 기반 제어**|열 단위 접근 제어, 집계 임계값 설정 등으로 개인정보 보호|
|**AWS 분석 서비스 연계**|Athena, Redshift, S3와 통합 가능|
|**규제·컴플라이언스 지원**|GDPR, CCPA 등 개인정보 보호 요구 충족 지원|

---

## 🧪 활용 시나리오

- **광고·마케팅 데이터 협업**
    - 두 회사가 고객 데이터 교집합만 분석해 캠페인 성과 측정
- **금융·헬스케어 데이터 분석**
    - 민감 정보는 보호하면서 통계·모델 학습 수행
- **파트너사 공동 데이터 모델링**
    - 원본 데이터 노출 없이 추천·세그먼트 분석

---

## ✅ 장점

- **데이터 보안 강화** → 원본 데이터 이동·복제 없이 협업
- **프라이버시 보호** → 식별 정보 노출 최소화
- **규제 준수 용이** → GDPR/CCPA 등 개인정보 보호 충족
- **AWS 생태계 통합** → S3·Athena·Redshift와 직접 연계

---

## ⚠️ 유의사항

|항목|설명|
|---|---|
|**쿼리 결과 제한**|소량 데이터 또는 식별 가능한 결과는 제한됨|
|**참여자 동의 필요**|협업 참여자 모두 Clean Rooms 정책 수립 필요|
|**고급 ML 분석 제한**|기본 SQL 집계·교집합 중심, 복잡한 ML은 추가 설계 필요|

## 🧾 요약

|항목|설명|
|---|---|
|**정의**|여러 조직이 데이터를 직접 공유하지 않고 **보호된 환경에서 안전하게 공동 분석**할 수 있는 서비스|
|**주요 기능**|비공개 데이터 협업, SQL 분석, 정책 기반 접근 제어, AWS 분석 서비스 연계|
|**활용 예**|마케팅 캠페인 분석, 금융/헬스케어 통계, 파트너 데이터 교집합 분석|
