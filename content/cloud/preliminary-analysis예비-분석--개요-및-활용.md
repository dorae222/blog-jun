## 🧩 Quick Overview

| 항목        | 설명                                                    |
| --------- | ----------------------------------------------------- |
| **용어**    | Preliminary Analysis (예비 분석, 사전 분석)                   |
| **유형**    | **데이터 분석·연구 초기 단계 활동**                                |
| **주요 목적** | **데이터·문제 정의·품질 상태를 초기 검토**하여 **본격적 분석·모델링 전략 수립**에 활용 |

---

## 🔧 주요 특징

|항목|설명|
|---|---|
|**데이터 탐색**|데이터 형태, 범위, 분포, 결측·이상치 확인|
|**품질 검증**|노이즈, 오류, 중복, 스케일 불일치 여부 확인|
|**기본 통계 분석**|평균·분산·상관관계 등 단순 기술통계 확인|
|**패턴·트렌드 탐색**|초기 시각화를 통해 패턴·클러스터·이상 징후 파악|
|**분석 전략 수립**|모델링·가설 검증·추가 데이터 필요성 판단|

---

## 🧪 활용 시나리오

- **머신러닝 프로젝트 초기**
    - 모델 학습 전 데이터 품질·분포·상관관계 확인
- **연구 설계 단계**
    - 실험 설계·가설 설정 전 사전 데이터 이해
- **데이터 마이그레이션/통합**
    - 신규 데이터셋 통합 전 구조·품질 점검
- **BI·리포팅 준비**
    - 대시보드 구성 전 주요 KPI·지표 초안 산출

---

## ✅ 장점

- **문제 정의 명확화** → 적절한 모델·분석 전략 수립 가능
- **데이터 품질 이슈 조기 식별** → 후속 분석 오류 최소화
- **시간·비용 절감** → 불필요한 복잡한 모델링 방지
- **가설 설계 지원** → 초기 패턴 발견 및 연구 방향성 제공

---

## ⚠️ 유의사항

|항목|설명|
|---|---|
|**정밀 분석 아님**|탐색적 단계에 불과, 통계적 결론 도출 불가|
|**샘플링 오류 가능**|일부 데이터만 보면 편향 위험|
|**후속 전처리 필수**|결측·이상치 처리, 정규화, 인코딩 필요|
