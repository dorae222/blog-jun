## 🧩 Quick Overview

| 항목        | 설명                                                        |
| --------- | --------------------------------------------------------- |
| **서비스명**  | AWS Cloud Map                                             |
| **유형**    | **서비스 검색(Service Discovery) 및 리소스 맵핑 서비스**                |
| **주요 목적** | 애플리케이션 리소스를 **사용자 정의 이름으로 등록·검색**하여 동적 서비스 검색과 트래픽 라우팅을 지원 |

---

## 🔧 주요 특징

|항목|설명|
|---|---|
|**서비스 등록**|EC2, ECS, EKS, Lambda 등 리소스를 서비스 이름으로 등록|
|**상태 체크 통합**|헬스체크 기반으로 정상 인스턴스만 검색 가능|
|**서비스 검색 API 제공**|애플리케이션이 동적으로 서비스 위치 조회|
|**Route 53 연계**|DNS 또는 API 기반 서비스 검색 지원|
|**동적 환경 지원**|컨테이너·마이크로서비스·서버리스 환경에 적합|

---

## 🧪 활용 시나리오

- **마이크로서비스 아키텍처**
  - ECS/EKS 서비스 간 동적 통신

- **컨테이너 오토스케일링 환경**
  - 새 인스턴스 등록/종료 시 서비스 목록이 자동으로 업데이트됨

- **서버리스/이벤트 기반 시스템**
  - Lambda 함수가 실행 시점에 동적으로 리소스 위치를 조회하여 연동

---

## ✅ 장점

- **자동 서비스 검색** → 수동 IP 관리 불필요

- **트래픽 안정성 확보** → 헬스체크 통합으로 정상 리소스만 라우팅

- **마이크로서비스 최적화** → 컨테이너·서버리스 환경과 자연스럽게 통합

---

## ⚠️ 유의사항

|항목|설명|
|---|---|
|**DNS 지연 고려**|DNS 기반 검색 시 TTL 영향이 있어 최신 상태 반영에 지연이 생길 수 있음|
|**리소스 관리 필요**|서비스 등록·해제 정책을 설계하여 불필요한 레코드 누적을 방지해야 함|
|**리전 종속성**|Cross-Region 서비스 검색은 별도 설계가 필요함|
