## 🧩 Quick Overview

|항목|설명|
|---|---|
|**개념**|Linear Least Squares Regression (선형 최소제곱 회귀)|
|**유형**|**통계적 회귀 분석 기법**|
|**주요 목적**|**관측값과 예측값 간 오차 제곱합(Residual Sum of Squares, RSS)**을 최소화하는 선형 모델을 학습|

---

## 🔧 주요 특징

| 항목                                          | 설명                                                         |
| ------------------------------------------- | ---------------------------------------------------------- |
| **모델 형태**                                   | $y=X \beta+\epsilon$ 형태의 선형 모델                             |
| **최적화 목표**                                  | $\min _\beta \sum\left(y_i-\hat{y}_i\right)^2$ → 잔차 제곱합 최소화 |
| **해석적 해법**                                  | 정규방정식(Normal Equation)을 이용해 계수를 계산                             |
| $\hat{\beta}=\left(X^T X\right)^{-1} X^T y$ |                                                            |
| **가정 조건**                                   | 선형성, 독립성, 등분산성, 정규성 등                                      |
| **용도**                                      | 회귀 분석, 트렌드 예측, 피처 중요도 해석                                   |

---

## 🧪 활용 시나리오

- **연속형 변수 예측**
    - 예: 매출, 주가, 온도, 집값 예측
- **피처 영향도 분석**
    - 각 변수 계수 → 결과에 대한 선형 영향력 해석
- **모델 해석 용이성 중요 시**
    - 계수 기반으로 변수 중요도·상관관계 쉽게 파악 가능

---

## ✅ 장점

- 계산이 단순하고 구현이 용이함
- 계수 해석 가능 → 피처 영향력을 직관적으로 이해할 수 있음
- 소규모 데이터셋에서도 안정적으로 학습 가능
