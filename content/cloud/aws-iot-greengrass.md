## 🧩 Quick Overview

| 항목              | 설명 |
|-------------------|------|
| **서비스명**       | AWS IoT Greengrass |
| **유형**           | **엣지 컴퓨팅 및 IoT 디바이스용 런타임/관리 서비스** |
| **주요 목적**       | **IoT 디바이스에서 로컬 데이터 처리, ML 추론, 메시징, 클라우드 동기화**를 지원

> 🌐 **AWS IoT Greengrass**는 클라우드 연결이 불안정하거나 지연이 긴 환경에서도
> **로컬에서 데이터 처리 및 디바이스 제어를 수행하고, 필요 시 클라우드와 동기화**할 수 있는 IoT 엣지 런타임입니다.

---

## 🔧 주요 특징

| 항목 | 설명 |
|------|------|
| **로컬 데이터 처리** | 디바이스에서 이벤트를 수집하고 클라우드 전송 전에 로컬에서 전처리할 수 있습니다 |
| **ML 추론 지원** | SageMaker, TensorFlow Lite 모델을 로컬에서 사용해 추론을 수행할 수 있습니다 |
| **오프라인 동작** | 네트워크가 끊겨도 로컬 처리와 저장을 계속하고 재연결 시 동기화합니다 |
| **Lambda 실행** | AWS Lambda 함수를 로컬 디바이스에서 실행할 수 있습니다 |
| **보안 통신** | AWS IoT Core와 TLS 기반의 안전한 통신을 제공합니다 |
| **디바이스 관리** | OTA(Over-The-Air) 업데이트와 원격 모니터링을 지원합니다 |

---

## 🧪 사용 예시

1. **스마트 공장**
   - IoT 센서 데이터를 로컬에서 필터링하고 중요 이벤트만 클라우드로 전송
2. **자율 주행·로봇**
   - 실시간 ML 추론을 로컬에서 실행해 저지연 제어 구현
3. **원격지 모니터링**
   - 네트워크가 불안정한 지역에서도 데이터를 로컬에 저장했다가 재전송
4. **보안 카메라**
   - 영상 분석 모델을 로컬에서 실행해 클라우드로 전송하는 데이터 최소화

## 📦 구성 요소

| 요소 | 설명 |
|------|------|
| **Greengrass Core** | 디바이스에서 실행되는 런타임으로 Lambda 실행, ML 추론, 메시징 등을 담당 |
| **Greengrass Components** | 배포 가능한 기능 단위(예: Lambda 함수, ML 모델, 커넥터 등) |
| **Greengrass Cloud Service** | 디바이스 등록, 배포, 모니터링 및 업데이트를 담당 |
| **IoT Core 연계** | 인증, 메시징, 디바이스 관리 등 보안 연동을 지원 |
