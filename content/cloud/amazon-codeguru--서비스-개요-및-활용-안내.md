## 🧩 빠른 개요

| 항목 | 설명 |
| --- | --- |
| **서비스명** | Amazon CodeGuru |
| **유형** | **AI 기반 코드 품질 분석 및 애플리케이션 성능 최적화 서비스** |
| **주요 목적** | **코드 리뷰와 런타임 분석을 통해 버그, 비효율 코드, 성능 병목을 식별하고 개선 권장 사항을 제공** |

---

## 🔧 주요 특징

| 항목 | 설명 |
| --- | --- |
| **CodeGuru Reviewer** | ML(머신러닝) 기반 코드 리뷰로 보안 취약점 및 코드 품질 문제를 감지합니다. |
| **CodeGuru Profiler** | 애플리케이션 런타임 성능을 분석하며 CPU·메모리 등의 병목 지점을 시각화합니다. |
| **자동 개선 권장** | 코드 최적화, 비용 절감, 보안 개선 등을 위한 권장사항을 제안합니다. |
| **CI/CD 통합 용이** | GitHub, CodeCommit, Bitbucket 등과 연동하여 자동화된 워크플로우에 통합할 수 있습니다. |
| **지원 언어** | 주로 Java, Python을 중심으로 지원하며, 추가 언어는 점진적으로 확장됩니다. |

---

## 🧪 활용 시나리오

- **코드 품질 및 보안 강화**
  - Pull Request 시 자동 코드 리뷰로 취약점과 품질 이슈를 감지합니다.

- **애플리케이션 성능 최적화**
  - CPU·메모리 사용의 병목 지점을 분석하고 원인 파악에 도움을 줍니다.

- **비용 절감**
  - 비효율적인 스레드 사용, DB 연결 패턴, 불필요한 API 호출 등을 개선하여 비용을 줄일 수 있습니다.

- **DevOps/CI 파이프라인 연계**
  - 배포 전 자동 리뷰를 통해 품질을 사전 확보할 수 있습니다.

---

## ✅ 장점

- **자동화된 코드 리뷰** → 수작업 리뷰 부담 감소

- **성능 및 비용 최적화** → 병목 지점 파악과 개선 권고 제공

- **보안 강화** → 코드 내 잠재적 취약점 탐지

- **AWS 서비스 연계 용이** → Lambda, EC2, Fargate 등과 통합 분석이 가능합니다
