**Amazon SageMaker Canvas**는 코드 작성 없이(no-code) 머신러닝 모델을 생성하고 예측을 수행할 수 있게 해주는 AWS의 시각적 인터페이스 기반 ML 도구입니다. 주로 비즈니스 분석가나 데이터 분석가가 기술적인 코드 지식 없이도 머신러닝을 활용할 수 있도록 설계되었습니다.

---

## 🧩 핵심 개요

|항목|내용|
|---|---|
|**서비스명**|Amazon SageMaker Canvas|
|**종류**|완전관리형 no-code 머신러닝 툴|
|**대상 사용자**|비개발자, 비데이터 과학자|
|**주요 기능**|데이터 탐색, 모델 생성, 예측 수행, 협업 지원|

---

## 🔍 주요 기능 설명

### 1. **데이터 불러오기**

- 다양한 소스에서 데이터 로드 가능:
    - CSV, Excel 업로드
    - Amazon S3
    - Redshift, Snowflake, Athena, SageMaker Feature Store 등과 연동
- 시각적으로 컬럼 탐색, 필터링, 클렌징 가능


### 2. **자동 ML (AutoML)**

- Amazon SageMaker의 **AutoML 기술을 기반**으로 모델을 자동으로 생성
- 사용자가 목표(예: 분류, 회귀, 예측)만 설정하면 나머지는 자동 수행
- 다수의 알고리즘을 자동 실험하고 최적 모델 선택


### 3. **예측 수행**

- 생성된 모델을 사용하여:
    - **배치 예측**: 다수의 레코드에 대해 예측
    - **단일 예측**: 특정 입력에 대한 실시간 예측
- 예측 결과는 시각화되며 CSV로도 다운로드 가능


### 4. **SageMaker Studio와 연계**

- 데이터 사이언티스트와 **협업** 가능:
    - 분석가가 Canvas에서 모델을 만든 후,
    - 데이터 과학자는 SageMaker Studio에서 코드로 상세 분석 및 최적화 가능
