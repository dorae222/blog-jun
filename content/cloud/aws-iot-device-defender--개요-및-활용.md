## 🧩 Quick Overview

| 항목        | 설명                                                              |
| --------- | --------------------------------------------------------------- |
| **서비스명**  | AWS IoT Device Defender                                         |
| **유형**    | **IoT 보안 모니터링 및 정책 관리 서비스**                                     |
| **주요 목적** | IoT 디바이스와 연결 인프라의 **보안 상태를 모니터링**하고 **이상 행위·취약점·정책 위반을 탐지**해 보호 |

---

## 🔧 주요 특징

|항목|설명|
|---|---|
|**보안 정책 관리**|디바이스 인증·권한·통신 암호화 등 보안 정책을 정의하고 적용할 수 있습니다.|
|**이상 행위 탐지**|디바이스의 트래픽 패턴을 분석해 비정상 동작을 탐지합니다.|
|**취약점·정책 감사(Audit)**|설정 오류, 약한 암호화, 과도한 권한 등 구성 상의 취약점을 식별합니다.|
|**실시간 경고**|CloudWatch, SNS 등과 연동해 탐지된 위협을 실시간으로 알립니다.|
|**자동화 대응 연계**|IoT Core, Lambda, Security Hub와 통합해 자동으로 대응 조치를 트리거할 수 있습니다.|

---

## 🧪 활용 시나리오

- **스마트 팩토리·산업 IoT 보안**
    - PLC·센서 통신의 이상 행위를 탐지하고 대응합니다.

- **스마트 홈·소비자 IoT**
    - 취약한 디바이스에 대해 정책 감사를 수행하고 알림을 전송합니다.

- **의료·공공 IoT 규제 준수**
    - HIPAA, ISO 등 규제·표준 기반의 정책 검증에 사용합니다.

- **대규모 IoT 플릿 관리**
    - 수천~수백만 디바이스의 보안 상태를 중앙에서 모니터링합니다.

---

## ✅ 장점

- **IoT 보안 강화** → 설정 오류, 과도한 권한, 이상 행위를 실시간으로 감지합니다.
- **규정 준수 지원** → 감사(Audit) 리포트를 자동으로 생성해 규정 준수를 도와줍니다.
- **자동화 대응 용이** → Lambda·Security Hub 등과 통합해 자동 조치를 구현하기 쉽습니다.
- **클라우드 관리형** → 별도 보안 인프라를 직접 구축할 필요가 없습니다.

---

## ⚠️ 유의사항

|항목|설명|
|---|---|
|**오탐/과탐 가능성**|정상 트래픽에서도 경고가 발생할 수 있으므로 정책 튜닝이 필요합니다.|
|**에이전트/정책 구성 필요**|플릿 규모에 따라 초기 설정 및 지속적인 운영 관리가 필요합니다.|
|**데이터 전송 비용**|클라우드로 모니터링 데이터를 전송할 경우 트래픽 비용을 고려해야 합니다.|
