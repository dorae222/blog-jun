## 🧩 Quick Overview

| 항목              | 설명 |
|-------------------|------|
| **개념명**         | 편향 드리프트 (Bias Drift) |
| **관련 분야**       | 머신러닝 모델 운영(MLOps), 공정성(Fairness), 모니터링 |
| **기본 개념**       | **모델이 학습 당시에는 공정했지만, 시간이 지나면서 특정 그룹에 대해 편향된 예측을 하게 되는 현상**

> 🧠 모델 배포 이후 현실 세계의 데이터 특성이 변하면서
> 예측 결과가 특정 인구 집단(예: 성별, 연령, 지역 등)에 대해 **불균형하게 작용**할 수 있습니다.
> 이를 **편향 드리프트**라고 부릅니다.

---

## 🎯 예시

| 시나리오 | 설명 |
|----------|------|
| 금융 모델 | 훈련 당시에는 성별/연령에 공정했지만, 최근 데이터에서는 여성 사용자에게 대출 거절률이 증가 |
| 채용 추천 | 시간이 지남에 따라 특정 인종 그룹이 추천에서 점차 배제됨 |
| 헬스케어 | 특정 연령대 환자에게 예측 정확도가 지속적으로 낮아짐

---

## 📊 측정 지표 예시

| 지표                          | 설명 |
|-------------------------------|------|
| **Demographic Parity**        | 모든 그룹에서 긍정 예측률이 유사한가 |
| **Equal Opportunity**         | 모든 그룹에서 실제 양성일 때의 True Positive Rate이 유사한가 |
| **Predictive Parity**         | 그룹별 Precision이 유사한가 |
| **False Positive Rate Parity**| 거짓 양성 예측률이 그룹 간 유사한가 |

이러한 지표들은 **SageMaker Clarify**를 통해 정량적으로 측정할 수 있으며,
시간에 따른 추세 변화를 비교해 **드리프트 존재 여부를 판단**할 수 있습니다.

## 🔎 SageMaker에서의 활용

| 항목 | 내용 |
|------|------|
| **툴** | Amazon SageMaker Clarify + Model Monitor |
| **대상** | 실시간 추론 엔드포인트의 로그 또는 Batch 추론 결과 |
| **방식** | 편향 측정 기준 설정 → 새로운 입력/예측 결과 수집 → 기준 대비 변화 분석 |
| **온디맨드 실행** | 수동 또는 이벤트 기반으로 주기적/즉시 실행 가능 |

## ⚠️ 유의사항

| 항목 | 설명 |
|------|------|
| **훈련 당시 기준 정의 필요** | 어떤 그룹/피처가 민감한지 명확히 지정해야 합니다. |
| **데이터 품질에 민감** | 잘못된 입력 값이나 샘플링 문제로 인해 잘못된 드리프트가 감지될 수 있습니다. |
| **드리프트 탐지 ≠ 차별 판정** | 지표는 현상을 수치화할 뿐, 정책적 판단과 조치는 별도로 필요합니다. |
