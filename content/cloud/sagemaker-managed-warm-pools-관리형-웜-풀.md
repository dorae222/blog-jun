## 🧩 Quick Overview

| 항목               | 설명 |
|--------------------|------|
| **기능명**          | SageMaker Managed Warm Pools (관리형 웜 풀) |
| **서비스 위치**      | Amazon SageMaker Training |
| **기능 목적**        | **모델 훈련 인스턴스를 미리 준비**해두어 빠르게 훈련을 시작할 수 있도록 대기 상태로 유지 |

> 🔥 **SageMaker 웜 풀**은 이전 훈련에서 사용한 인스턴스를 "따뜻한 상태"로 보관하여
> **다음 훈련 시 인프라 초기화 지연 없이 빠르게 시작**할 수 있도록 돕는 기능입니다.

---

## 🧠 동작 방식

1. 첫 번째 훈련이 종료되면 **웜 풀에 인스턴스가 보존**됩니다.
2. 이후 동일한 설정으로 재훈련할 경우, 해당 인스턴스를 **즉시 재사용**합니다.
3. 이때 **AMI, 스토리지, 프레임워크, 코드 상태** 등이 유지된 채 재사용됩니다.

---

## ✅ 장점

| 항목 | 설명 |
|------|------|
| **훈련 시작 시간 단축** | 인스턴스 프로비저닝에 소요되는 수 분 단위의 지연을 제거하여 빠르게 시작할 수 있습니다. |
| **비용 최적화** | 인스턴스는 중지된 상태로 보존되며 실제로 발생하는 비용은 주로 스토리지 수준에 한정됩니다. |
| **실험 반복에 유리** | 하이퍼파라미터 튜닝, 모델 버전 테스트 등 반복적 훈련 워크플로에 적합합니다. |
| **상태 유지 가능** | 컨테이너 상태나 설치된 패키지 등 훈련 환경의 상태를 유지할 수 있습니다. |

---

## 🛠️ 설정 방법 (예시)

```python
from sagemaker.estimator import Estimator

estimator = Estimator(
    ...
    keep_alive_period_in_seconds=3600  # 웜 풀 유지 시간 (최대 7일)
)

estimator.fit("s3://my-bucket/train-data")
````

- `keep_alive_period_in_seconds`: 훈련 종료 후 인스턴스를 몇 초 동안 유지할지 지정합니다 (최대 604800초 = 7일).
    

---

## ⚠️ 유의사항

|항목|설명|
|---|---|
|**지원 인스턴스 제한**|일부 인스턴스 유형만 지원됩니다 (예: `ml.p3`, `ml.p4` 등).|
|**자동 종료 없음**|사용자가 명시적으로 유지 시간을 설정해야 합니다.| 
|**추가 스토리지 요금 발생**|훈련 환경 상태를 저장하는 데 따른 추가 비용이 발생할 수 있습니다.|
