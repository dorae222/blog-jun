## 🧩 Quick Overview

|항목|설명|
|---|---|
|**서비스명**|AWS CloudShell|
|**유형**|**브라우저 기반 클라우드 셸 환경**|
|**주요 목적**|로컬 환경 설정 없이 **브라우저에서 AWS CLI·SDK·도구를 즉시 사용**할 수 있는 관리형 셸 환경 제공|

---

## 🔧 주요 특징

|항목|설명|
|---|---|
|**브라우저 기반 CLI**|AWS CLI, SDK, 기타 개발 도구가 사전 설치되어 제공됨|
|**관리형 환경**|EC2 기반 환경을 자동으로 프로비저닝하고, OS 및 패치를 자동으로 관리|
|**영구 스토리지 제공**|사용자별 1GB 홈 디렉터리의 영구 저장 공간 제공|
|**AWS 콘솔 통합**|AWS 콘솔에서 바로 CloudShell을 실행 가능|
|**보안 연계**|세션에서 사용자의 IAM 권한을 자동으로 상속하여 인증 연동|

---

## 🧪 활용 시나리오

- **AWS CLI 테스트 및 운영**
  - 로컬에 도구를 설치하지 않고 콘솔에서 바로 명령을 실행

- **빠른 관리 작업 수행**
  - S3 버킷 관리, Lambda 배포, IAM 설정 등 간단한 관리 작업 수행

- **교육·데모 환경**
  - 학습자에게 로컬 설치 없이 실습 환경을 제공하여 교육과 데모에 활용

- **임시 관리 환경 제공**
  - 보안상 로컬 설치가 어려운 환경에서 임시로 관리 작업을 수행할 때 사용

---

## ✅ 장점

- **로컬 설치 불필요** → 브라우저에서 즉시 사용 가능
- **관리형 환경** → 패치, 업데이트, 권한 상속 등이 자동화되어 운영 부담 감소
- **저비용·편의성** → 무료로 제공되며 기본 스토리지가 포함됨
- **보안 강화** → IAM과 직접 연계되어 키 관리를 별도로 하지 않아도 됨

## ⚠️ 유의사항

|항목|설명|
|---|---|
|**리소스 제한**|기본 CPU/메모리 제한이 있어 대규모 작업에는 부적합|
