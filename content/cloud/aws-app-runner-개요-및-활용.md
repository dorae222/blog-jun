## 🧩 Quick Overview

| 항목        | 설명                                                      |
| --------- | ------------------------------------------------------- |
| **서비스명**  | AWS App Runner                                          |
| **유형**    | **완전관리형 애플리케이션 배포·호스팅 서비스**                             |
| **주요 목적** | 컨테이너 또는 소스 코드 기반 애플리케이션을 서버 관리 없이 자동 배포·스케일링하여 웹 서비스 제공 |

> 🚀 **AWS App Runner**는 **인프라 관리 없이 웹 애플리케이션 또는 API를 바로 배포**하고,  
> 트래픽에 따라 **자동 확장(Auto Scaling)**되는 서버리스 앱 호스팅 서비스입니다.

---

## 🔧 동작 방식

1. **배포 소스 선택**  
   - GitHub, AWS CodeCommit, ECR(Elastic Container Registry) 등
2. **App Runner 서비스 생성**  
   - 런타임/빌드 자동 감지 또는 컨테이너 이미지 사용
3. **자동 빌드·배포**  
   - 코드 변경 시 CI/CD 자동 실행(옵션)
4. **실행 및 스케일링**  
   - 트래픽 증가에 따라 자동 확장하고, 유휴 시 축소

---

## 📦 주요 특징

| 항목 | 설명 |
|------|------|
| **서버리스 아키텍처** | EC2, ECS, Fargate 등 인프라를 직접 관리할 필요가 없음 |
| **자동 스케일링** | 요청 수에 따라 인스턴스 수를 자동으로 조정 |
| **HTTPS 기본 제공** | TLS 인증서를 자동으로 프로비저닝하여 HTTPS를 기본 제공 |
| **지속적 배포 지원** | 소스 코드 변경 시 자동 빌드·배포(CI/CD) 연동 가능 |
| **네트워크 통합** | VPC Connector를 통해 내부 DB나 서비스와 연동 가능 |

---

## 🧪 활용 예시

- **웹 애플리케이션 배포**  
  - Node.js, Python Flask/Django, Spring Boot 등
- **백엔드 API 서비스**  
  - REST API, GraphQL 서버 호스팅
- **머신러닝 추론 API**  
  - 컨테이너로 패키징한 모델을 손쉽게 호스팅
- **소규모 마이크로서비스**  
  - 별도의 ECS/EKS 관리 없이 빠른 프로토타이핑 가능

---

## ✅ 장점

- **인프라 관리 불필요** → 완전관리형 서버리스로 운영 부담 감소
- **자동 확장·축소** → 트래픽 패턴에 따른 탄력적 운영
- **보안 기본 제공** → HTTPS/TLS 자동화로 보안 설정 간소화
- **CI/CD 통합 용이** → GitHub, CodePipeline 등과 연계해 배포 자동화 가능

---

## ⚠️ 유의사항

| 항목 | 설명 |
|------|------|
| **컨테이너 기반 권장** | 복잡한 종속성이나 환경 설정이 필요한 경우 Docker 이미지 사용이 더 안정적 |
| **콜드 스타트 가능성** | 유휴 상태 후 첫 요청에서 지연(콜드 스타트)이 발생할 수 있음 |
| **VPC 통신 제한** | 내부 시스템 접근이 필요하면 VPC Connector 설정이 필요함 |
| **사용 요금 구조** | CPU·메모리 사용 시간과 요청 수 기반 과금 모델을 적용함 |
