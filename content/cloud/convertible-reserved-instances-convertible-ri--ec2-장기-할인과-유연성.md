## 🧩 Quick Overview

| 항목        | 설명                                                          |
| --------- | ----------------------------------------------------------- |
| **서비스명**  | Convertible Reserved Instances (Convertible RI)             |
| **유형**    | **EC2 요금 절감 예약 인스턴스 옵션**                                    |
| **주요 목적** | **장기간(1년·3년) 인스턴스 예약으로 요금 절감**하면서 **필요 시 인스턴스 유형·구성 변경 가능** |

> 💰 **Convertible RI**는 **Standard RI**와 달리,  
> **동일 또는 더 높은 가치의 RI로 교환(Convert)**이 가능해  
> 장기 사용 시 유연성과 절감 효과를 동시에 제공합니다.

---

## 🔧 주요 특징

| 항목 | 설명 |
|------|------|
| **긴 약정으로 할인** | 1년 또는 3년 약정 시 최대 54~66% 요금 절감 (온디맨드 대비) |
| **구성 변경 가능** | 인스턴스 패밀리, OS, 테넌시, 가용 영역(AZ) 등 변경 가능 |
| **동일·이상 가치 교환** | 교환 시 새 RI는 기존 RI와 동등 또는 높은 가치여야 함 |
| **결제 옵션** | 전액 선결제, 일부 선결제, 무선결제(No Upfront) 선택 가능 |
| **유연한 장기 운영** | 워크로드 변화에 따라 인스턴스 조정 가능 |

---

## 📦 Standard RI와 비교

| 구분 | Standard RI | Convertible RI |
|------|-------------|----------------|
| **할인율** | 최대 (높음) | 상대적으로 낮음 |
| **구성 변경** | 불가 (AZ 이동·스코프 변경만 가능) | 가능 (동일/이상 가치 RI 교환) |
| **유연성** | 낮음 | 높음 |
| **권장 사용** | 예측 가능한 장기 워크로드 | 장기 사용이지만 인스턴스 변경 가능성 있는 워크로드 |

---

## 🧪 활용 시나리오

- 장기적으로 EC2를 사용하지만 **인스턴스 패밀리 변경 가능성**이 있는 경우
- 초기에는 `m5.large`를 사용하다가, 이후 `m6i.large` 또는 더 높은 사양으로 교환
- 클라우드 마이그레이션 초기에 워크로드가 변동될 수 있는 환경

---

## ✅ 장점

- **온디맨드 대비 최대 50% 이상 절감**
- **유연성 제공** → 인스턴스 패밀리·OS·테넌시 변경 가능
- **장기 워크로드 안정화** → 비용 예측 용이

---

## ⚠️ 유의사항

| 항목 | 설명 |
|------|------|
| **교환은 동일·이상 가치만 가능** | 낮은 사양으로 다운그레이드는 불가 |
| **할인율은 Standard RI보다 낮음** | 유연성 대가로 할인률 일부 손실 |
| **Spot·Savings Plans 대체 검토 필요** | 일부 경우 Savings Plans가 더 유연함 |
