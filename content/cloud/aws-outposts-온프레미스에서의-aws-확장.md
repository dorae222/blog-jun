**AWS Outposts**는 AWS 인프라, 서비스, API 및 도구를 고객의 온프레미스 데이터센터나 코로케이션 환경에 물리적으로 설치하여 AWS 환경을 그대로 확장할 수 있게 해주는 하이브리드 클라우드 솔루션입니다.

즉, AWS에서 제공하는 서버 장비를 고객의 IDC에 설치해 로컬 환경에서 EC2, EBS, RDS, ECS, EKS 등을 AWS 리전과 동일한 방식으로 이용할 수 있도록 해주는 서비스입니다.

---

## 🏗️ 핵심 개념

| 항목         | 설명                                          |
| ---------- | ------------------------------------------- |
| **설치 위치**  | 고객의 데이터 센터 또는 콜로케이션 시설                      |
| **제공 방식**  | AWS가 **하드웨어를 공급**하고 관리 (as-a-Service)       |
| **제공 서비스** | EC2, EBS, ECS, EKS, RDS, S3 등 일부 AWS 서비스    |
| **관리 방식**  | **AWS Management Console, CLI, SDK** 그대로 사용 |
| **연결**     | AWS 리전에 연결된 상태에서 동기화 및 통합 관리                |

---

## 🚀 주요 특징

|기능|설명|
|---|---|
|✅ **완전관리형 AWS 하드웨어 제공**|서버, 스토리지, 네트워크 장비 포함한 랙 장비 제공|
|✅ **로컬 데이터 처리**|저지연이 필요한 로컬 워크로드 실행 가능|
|✅ **온프레미스에서 AWS API 사용**|기존 AWS 리전에서 쓰던 방식 그대로 개발/운영 가능|
|✅ **하이브리드 아키텍처**|온프레미스와 퍼블릭 클라우드를 유기적으로 통합|
|✅ **보안 및 컴플라이언스 유지**|AWS의 IAM, VPC, CloudWatch 등 동일하게 작동|

---

## 🧩 대표 사용 사례

|사용 사례|설명|
|---|---|
|🌍 **저지연 처리**|제조업, 병원, 금융기관 등 실시간 처리가 필요한 환경|
|🔐 **데이터 주권 요건 준수**|데이터가 물리적으로 국가를 벗어나면 안 되는 경우|
|☁️ **클라우드로의 점진적 이전**|클라우드로 마이그레이션 중인 기업의 중간 단계|
|🏭 **엣지 컴퓨팅**|공장/매장 등에서 AWS 서비스를 현장에 직접 적용 가능|

---

## 🔧 Outposts 서비스 예시

- **컴퓨팅**: EC2, ECS, EKS
    
- **스토리지**: EBS, S3 (Local 또는 Access Point 방식)
    
- **데이터베이스**: RDS (MySQL, PostgreSQL 등)
    
- **기타**: Load Balancer, VPC, IAM, CloudWatch 등
    

---

## 🔐 보안과 관리

- **하드웨어 보안**: AWS가 제공한 장비는 **암호화된 하드 디스크** 및 **자동 모니터링**을 내장합니다.
    
- **관리 인터페이스**: AWS 리전과 동일한 IAM 정책과 콘솔로 통합 관리할 수 있습니다.
    
- **모니터링**: Amazon CloudWatch 및 CloudTrail과 연동 가능합니다.
    

---

## 🆚 Outposts vs 다른 하이브리드 서비스

|항목|AWS Outposts|AWS Snow Family|AWS Local Zones|
|---|---|---|---|
|**형태**|랙 서버 (상주형)|이동형 어플라이언스|AWS 리전 확장 노드|
|**설치 위치**|고객 IDC|고객 현장|특정 도시 내 AWS 인프라|
|**연결 요구**|지속 연결 필요|연결 불필요 (일시적 전송용)|리전과 연결됨|
|**용도**|지속적인 온프레미스 AWS|대용량 데이터 전송|저지연 콘텐츠 제공|
