## 🧩 Quick Overview

| 항목        | 설명                                                               |
| --------- | ---------------------------------------------------------------- |
| **서비스명**  | AWS Application Composer                                         |
| **유형**    | **서버리스 애플리케이션 시각적 설계 도구**                                        |
| **주요 목적** | **드래그 앤 드롭 방식**으로 **서버리스 아키텍처를 설계·구성**하고 **코드·IaC 템플릿 자동 생성** 지원 |

---

## 🔧 주요 특징

|항목|설명|
|---|---|
|**시각적 설계**|S3, Lambda, DynamoDB 등 AWS 리소스를 드래그 앤 드롭으로 배치|
|**자동 IaC 생성**|AWS SAM 또는 CDK 기반 IaC 템플릿을 자동 생성|
|**서버리스 최적화**|이벤트 기반 Lambda·Step Functions·API Gateway 등 설계가 용이|
|**실시간 미리보기**|리소스 간 연결, 트리거, 종속성을 시각적으로 확인 가능|
|**로컬/클라우드 통합**|로컬 개발 환경과 AWS 계정 양쪽에서 설계 가능|

---

## 🧪 활용 시나리오

- **서버리스 애플리케이션 초기 설계**
  - 이벤트 드리븐 아키텍처 빠른 프로토타이핑

- **개발·배포 자동화**
  - SAM/CDK 템플릿 기반으로 CI/CD 파이프라인과 연계

- **교육·데모**
  - 시각화를 통해 아키텍처 구조를 직관적으로 설명

- **빠른 PoC(Proof of Concept)**
  - 코드 작성 전에 서버리스 아키텍처를 빠르게 검증

---

## ✅ 장점

- **코드 최소화** → 시각적 설계로 IaC 템플릿을 자동 생성하여 코드 작성 부담을 줄임
- **개발 생산성 향상** → 서버리스 설계와 배포 속도를 높임
- **AWS 서비스 통합 용이** → Lambda, S3, DynamoDB 등과 자연스럽게 연계 가능
- **교육·협업에 유리** → 시각화된 아키텍처를 통해 팀 간 공유와 이해가 쉬움

---

## ⚠️ 유의사항

|항목|설명|
|---|---|
|**서버리스 중심 제한**|EC2 등 전통적인 IaaS 리소스 설계에는 적합하지 않음|
|**고급 커스터마이징 필요**|복잡한 아키텍처는 SAM/CDK로 생성된 코드를 직접 수정해야 함|
|**정식 배포는 IaC 활용 필수**|Composer 자체는 실행 환경이 아니므로 배포 시 IaC 템플릿을 사용해야 함|
