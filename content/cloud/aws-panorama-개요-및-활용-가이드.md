## 🧩 Quick Overview

| 항목        | 설명                                                           |
| --------- | ------------------------------------------------------------ |
| **서비스명**  | AWS Panorama                                                 |
| **유형**    | **온프레미스 비전 애플리케이션 배포·관리 플랫폼**                                |
| **주요 목적** | **엣지 카메라 영상 스트림을 분석**해 실시간 컴퓨터 비전 모델을 **온프레미스 환경에 배포·운영** 가능 |

---

## 🔧 주요 특징

|항목|설명|
|---|---|
|**엣지 디바이스 지원**|Panorama Appliance 또는 Panorama SDK가 탑재된 장치에서 실행|
|**모델 배포·관리**|AWS에서 학습된 Vision 모델(객체 감지·분류 등)을 엣지로 자동 배포|
|**실시간 스트리밍 처리**|카메라 영상 입력 → 로컬에서 모델 추론 → 이벤트/메타데이터 전송|
|**AWS 통합**|SageMaker, S3, IoT Core, CloudWatch와 연계|
|**보안·오프라인 작동**|클라우드 연결 없이 로컬 처리 가능, 암호화된 모델 전송 지원|

---

## 🧪 활용 시나리오

- **제조·공장 자동화**
  - 생산 라인의 불량품 검출, 장비 이상 동작 감시

- **소매점 모니터링**
  - 고객 동선 분석, 제품 진열 상태 검사

- **교통·안전 감시**
  - 주차장 빈 공간 감지, 보안 카메라의 이상 행위 탐지

- **헬스케어 현장 적용**
  - 환자 낙상 감지, 멸균실 위생 상태 모니터링

---

## ✅ 장점

- **저지연 처리** → 영상 데이터를 로컬에서 즉시 분석

- **클라우드 부담 감소** → 네트워크 대역폭 및 비용 절감

- **중앙 집중 관리** → AWS 콘솔로 엣지 디바이스 및 모델 버전 관리

- **오프라인 보안 처리** → 민감한 영상 데이터를 클라우드에 전송하지 않고 로컬에서 처리

---

## ⚠️ 유의사항

|항목|설명|
|---|---|
|**하드웨어 의존**|Panorama Appliance 또는 SDK 호환 디바이스 필요|
|**모델 최적화 요구**|엣지 환경에 맞춘 경량화 및 추론 최적화 필수|
|**운영 모니터링 설계**|엣지 장애 및 네트워크 문제를 대비한 로컬 로깅·헬스체크 설계 필요|
