## 🧩 Quick Overview

| 항목              | 설명 |
|-------------------|------|
| **서비스명**       | AWS Glue DataBrew |
| **유형**           | 시각적 데이터 준비(전처리) 도구 |
| **핵심 기능**       | **코드 없이 GUI에서 데이터 클렌징, 변환, 프로파일링 수행**

> 🧪 **목적**: 데이터 과학자, 분석가 등이 **코드를 작성하지 않고도 데이터 전처리 및 품질 개선 작업을 시각적으로 처리**할 수 있도록 지원

---

## 🧬 주요 기능

| 기능 | 설명 |
|------|------|
| **데이터 프로파일링** | 데이터 통계, null 비율, 분포 등을 자동 시각화 |
| **클렌징 작업 250+개** | 누락값 처리, 형 변환, 텍스트 분리/병합, 날짜 처리 등 |
| **시각적 변환 워크플로우** | 드래그 앤 드롭 기반의 전처리 작업 정의 |
| **레시피(Recipe)** | 순차적 작업 내역을 저장한 재사용 가능한 전처리 스크립트 |
| **출력 연동** | S3, Redshift, RDS, Snowflake 등으로 저장 가능 |
| **Schedule 지원** | 반복 전처리 작업 자동 실행 스케줄링

---

## ✅ 장점

| 항목 | 설명 |
|------|------|
| **코드 불필요** | SQL, Python 없이도 고급 전처리 가능 |
| **시각화 중심 작업** | 데이터 품질 문제를 눈으로 보고 수정 가능 |
| **Glue, Athena 등 AWS 서비스 통합** | ETL 파이프라인으로 쉽게 연결 |
| **자동화 가능** | 레시피 + 스케줄 조합으로 반복 작업 자동화

---

## 🛠️ 사용 예시 흐름

1. **데이터셋 선택** (S3, Redshift 등에서 불러오기)
2. **프로파일링 자동 실행** (분포, 품질 이슈 시각화)
3. **전처리 작업 수행** (250+ 작업: trim, split, format 등)
4. **레시피 저장** → **스크립트화 + 자동 실행 설정**
5. **S3 또는 데이터 웨어하우스로 내보내기**

## ⚠️ 유의사항

| 항목 | 설명 |
|------|------|
| **복잡한 로직은 한계** | 커스텀 ML 로직/복잡한 조인은 지원되지 않음 |
| **대용량 처리 한계 있음** | Glue Job 대비 실행 성능은 다소 낮을 수 있음 |
| **데이터 위치 기반 과금** | 소스/타겟 간 이동 시 요금 주의
