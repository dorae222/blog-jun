## 🧩 Quick Overview

| 항목        | 설명                                                                     |
| --------- | ---------------------------------------------------------------------- |
| **서비스명**  | AWS Application Discovery Service                                      |
| **유형**    | **마이그레이션 준비·분석 도구**                                                    |
| **주요 목적** | 온프레미스 데이터센터의 **서버, 애플리케이션, 종속성**을 **자동으로 수집·분석**해 AWS 마이그레이션 계획 수립을 지원 |

> 🛰 **AWS Application Discovery Service(ADS)**는  
> 온프레미스 환경의 서버/워크로드 정보를 수집하여  
> **AWS Migration Hub 또는 MGN**과 연계해 **마이그레이션 전략**을 세우는 데 사용됩니다.

---

## 🔧 동작 방식

1. **Discovery Agent/Collector 설치**  
   - 온프레미스 서버에 Lightweight Agent를 설치  
   - 또는 네트워크 트래픽 수집용 Collector를 사용
2. **데이터 수집**  
   - 서버 사양(CPU, 메모리, 스토리지)  
   - 애플리케이션 목록 및 실행 중인 프로세스  
   - 네트워크 연결 정보 및 종속성 매핑
3. **AWS 전송 및 분석**  
   - 수집된 데이터는 암호화되어 ADS → AWS Migration Hub로 전송
4. **마이그레이션 계획 수립**  
   - 종속성 분석, TCO 산정, 적절한 AWS 서비스 매핑을 통해 계획 수립

---

## 📦 주요 기능

| 기능 | 설명 |
|------|------|
| **서버·앱 종속성 분석** | 마이그레이션 시 서버와 애플리케이션 간의 관계를 파악 |
| **리소스 프로파일링** | CPU, RAM, 디스크, 네트워크 사용량을 기록 |
| **네트워크 통신 매핑** | 포트·IP·프로세스 간의 연결을 파악 |
| **AWS Migration Hub 연동** | 수집된 데이터 기반으로 마이그레이션 진행 상태를 관리 |
| **보안 전송** | TLS 암호화 및 최소화된 데이터 전송

---

## 🧪 활용 시나리오

- **Lift-and-Shift 마이그레이션 사전 조사**
- **서버 종속성 시각화 후 단계적 마이그레이션 계획 수립**
- **TCO(총 소유 비용) 분석** → 인스턴스 크기 추천
- **규제 산업 마이그레이션 준비** → 종속성·트래픽 맵 필요 시

---

## ✅ 장점

- **자동화된 서버/앱 분석** → 사람의 실수나 누락을 줄임
- **종속성 기반 계획** → 위험을 최소화하고 점진적 이전 설계가 가능
- **Migration Hub 통합** → 마이그레이션 프로젝트를 단일 창에서 관리
- **TCO 분석 지원** → AWS 리소스 사이징에 도움

## ⚠️ 유의사항

| 항목 | 설명 |
|------|------|
| **에이전트 설치 필요** | 실시간 세부 데이터 수집을 위해서는 Agent 모드 설치 필요 |
| **네트워크 접근 권한 필요** | 방화벽/프록시 설정에서 접근 허용 필요 |
| **단순화된 데이터 제공** | 애플리케이션의 상세 비즈니스 로직까지는 수집하지 않음 |
| **정기적 점검 필요** | 최신 인프라 변경 사항 반영을 위해 정기적인 재스캔 권장 |
