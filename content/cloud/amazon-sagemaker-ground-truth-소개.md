**Amazon SageMaker Ground Truth**는 **머신러닝 학습용 데이터에 정확한 라벨을 자동 또는 수동으로 부여할 수 있는 데이터 라벨링 서비스**입니다. 대규모 데이터셋에 대해 **고품질의 레이블을 효율적이고 비용 효율적으로 생성**하도록 설계되었으며, **사람과 기계의 협업**을 통해 라벨링 품질을 지속적으로 향상시킵니다.

---

## 🧩 Ground Truth의 핵심 개념

|항목|설명|
|---|---|
|**서비스 이름**|Amazon SageMaker Ground Truth|
|**기능**|데이터 라벨링 (수동, 자동, 혼합 방식 지원)|
|**대상 데이터**|이미지, 텍스트, 동영상, 시계열, 문서 등|
|**라벨링 방식**|사람(휴먼 라벨러), 자동 ML 모델, 액티브 러닝 기반|

---

## 📦 주요 기능 설명

### 1. **수동 라벨링(Human Labeling)**

- **Amazon Mechanical Turk**, **SageMaker 라벨링 팀**, 또는 **자체 사용자 팀**을 통해 수작업 라벨링을 수행합니다.
- UI 제공: 박스, 분류, 세그멘테이션, 텍스트 주석 등 다양한 라벨링 도구를 내장하고 있습니다.
    

### 2. **자동 라벨링(Auto-labeling)**

- 일부 데이터만 사람이 라벨링하면, 나머지 데이터는 **자동 ML 모델**이 예측합니다.
- **액티브 러닝** 기술을 사용해 성능이 높은 예측만 자동 반영하도록 합니다.
    


### 3. **워크플로우 정의 및 관리**

- 라벨링 작업 유형을 선택하고, 데이터셋을 업로드하며, 작업자(사람 또는 팀)를 지정할 수 있습니다.
- **작업 상태, 품질, 비용**을 모니터링하는 기능을 제공합니다.
    


### 4. **출력 포맷**

- 라벨링 결과는 **JSON, Manifest file**, 또는 SageMaker용 TFRecord/RecordIO 등 형식으로 S3에 저장됩니다.

## 🔍 라벨링 가능한 데이터 유형

|데이터 유형|설명|
|---|---|
|**이미지**|객체 감지, 분류, 세그멘테이션, 키포인트|
|**텍스트**|감성 분석, 개체명 인식(NER), 요약|
|**동영상**|프레임별 객체 추적|
|**3D 포인트 클라우드**|LiDAR 데이터 라벨링 (자율주행 관련)|
|**문서**|OCR 결과에 대한 라벨링 (표, 문단, 필드 등)|

|---|---|
|**고품질 라벨링**|액티브 러닝과 인간 검수를 결합해 라벨 품질을 높입니다.|
|**비용 효율**|자동 라벨링을 통해 작업량과 비용을 절감할 수 있습니다.|

---

## ⚠️ 유의 사항

- 작업 단가를 설정할 때는 **작업 난이도와 예상 소요 시간**을 반드시 고려해야 합니다.
- 자동 라벨링의 정확도는 **초기 수작업 품질**에 크게 의존합니다.
- 복잡한 라벨링 워크플로우는 **Custom Task Template**이 필요할 수 있습니다.

---

## 🧪 사용 예시 (라벨링 워크플로우)

1. **S3에 데이터 업로드**
2. **Ground Truth 콘솔 또는 SDK로 라벨링 작업 생성**
3. **작업자 선택 (Mechanical Turk, 사내 팀 등)**
4. **작업 수행 및 자동 검수**
5. **결과는 S3에 저장 (라벨 포함된 Manifest 파일)**
    

---

## 📊 예시: 이미지 분류 작업 Manifest 출력

```json
{
  "source-ref": "s3://my-bucket/images/image1.jpg",
  "label": "cat",
  "label-metadata": {
    "confidence": 0.99,
    "human-annotated": "yes",
    "creation-date": "2025-07-29T12:00:00"
  }
}
```
