## 🧩 Quick Overview

| 항목        | 설명                                                                   |
| --------- | -------------------------------------------------------------------- |
| **서비스명**  | Service Quotas                                                       |
| **유형**    | **AWS 서비스별 한도(Quota) 관리 콘솔**                                         |
| **주요 목적** | **AWS 계정 내 서비스 사용 한도**를 확인하고 **증설 요청(Quota Increase)을 관리**할 수 있도록 지원 |

---

## 🔧 주요 특징

|항목|설명|
|---|---|
|**서비스 한도 확인**|EC2, VPC, S3 등 리소스별 기본/현재 한도 조회|
|**한도 증설 요청**|콘솔에서 직접 Quota Increase 요청 가능|
|**자동화 지원**|AWS CLI, SDK, CloudWatch와 연계해 한도 모니터링|
|**리전별 구분**|리전 단위 한도 확인 가능|
|**Organization 통합**|멀티 계정 환경에서 중앙 관리 가능|

---

## 🧪 활용 시나리오

- **EC2 인스턴스 한도 초과 방지**

    - 신규 인스턴스 생성 전 vCPU·인스턴스 패밀리 한도 확인

- **대규모 배포 계획**

    - S3 버킷, VPC, ENI 등 리소스 한도 사전 확인·증설

- **자동화된 한도 모니터링**

    - CloudWatch 알람으로 한도 근접 시 알림

---

## ✅ 장점

- **한도 가시성 확보** → 모든 서비스 한도를 중앙에서 확인할 수 있음

- **증설 간소화** → 콘솔·API로 직접 증설 요청 가능

- **자동화 용이** → CLI·SDK·CloudWatch와 연계하여 자동화 가능

- **리스크 예방** → 배포 중 한도 초과로 인한 장애를 사전에 방지

---

## ⚠️ 유의사항

|항목|설명|
|---|---|
|**모든 서비스 지원 아님**|일부 서비스는 여전히 Support Case 제출이 필요함|
|**리전별 별도 관리 필요**|글로벌 한도와 리전 한도를 구분해서 확인해야 함|
|**승인 시간 소요**|증설 요청은 수분에서 수시간까지 소요될 수 있음|
