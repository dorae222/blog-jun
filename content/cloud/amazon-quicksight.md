## 🧩 Quick Overview

| 항목              | 설명 |
|-------------------|------|
| **이름**           | Amazon QuickSight |
| **유형**           | **클라우드 기반 BI(Business Intelligence) 및 데이터 시각화 서비스** |
| **주요 목적**       | **서버리스 환경에서 대화형 대시보드와 시각화를 빠르게 생성**하고  
                       **조직 전반에 공유**하여 데이터 기반 의사결정을 지원 |

> 📊 **QuickSight**는 데이터 웨어하우스, 데이터 레이크, SaaS 애플리케이션 등  
> 다양한 소스의 데이터를 **서버리스로 분석 및 시각화**할 수 있는 AWS BI 솔루션입니다.

---

## 🔧 주요 특징

| 항목 | 설명 |
|------|------|
| **서버리스 & 자동 확장** | 인프라 관리가 필요 없으며, 사용자 수와 데이터 양에 따라 자동으로 확장됩니다. |
| **SPICE 엔진** | In-memory 캐시 엔진으로 대화형 쿼리 응답 속도를 개선합니다. |
| **다양한 데이터 소스 지원** | S3, Athena, Redshift, RDS, Aurora, Snowflake, SaaS 앱 등 여러 소스와 연동됩니다. |
| **대화형 대시보드** | 필터링, 드릴다운, 사용자 맞춤형 시각화 등 인터랙티브한 대시보드를 제공합니다. |
| **ML Insights 통합** | 이상치 탐지, 예측, 기여도 분석 등 AI/ML 기반 인사이트를 제공합니다. |
| **Embedded Analytics** | 애플리케이션이나 포털에 대시보드를 임베드하여 제공할 수 있습니다. |
| **Row-level Security** | 사용자별로 데이터 접근 권한을 세분화하여 제어할 수 있습니다. |

---

## 🧪 활용 예시

1. **경영 대시보드**  
   - 매출, KPI, 마케팅 성과를 실시간으로 시각화하여 의사결정에 활용
2. **운영 모니터링**  
   - IoT 센서나 로그 데이터의 실시간 집계 및 모니터링
3. **고객 분석**  
   - 구매 패턴 및 세그먼트별 전환율 분석
4. **임베디드 리포트**  
   - SaaS 제품 내에 분석 화면을 내장하여 사용자에게 제공

## ✅ 장점

- **서버리스 & 관리형**: 별도의 인프라 프로비저닝 없이 사용 가능
- **빠른 응답**: SPICE 엔진을 통해 대화형 쿼리 성능 향상
- **비용 효율적**: 세션 기반 및 사용자 기반 라이선스 모델로 유연한 비용 구조 제공
- **ML 통합 분석**: Anomaly Detection, Forecasting, Contribution Analysis 등을 지원
- **조직 공유 및 협업**: 대시보드 URL 공유 또는 임베딩으로 협업 가능

## ⚠️ 유의사항

| 항목 | 설명 |
|------|------|
| **SPICE 용량 제한** | 기본 10GB(엔터프라이즈 플랜에서 확장 가능) |
| **고급 시각화 한계** | 매우 복잡한 커스텀 시각화는 제한적일 수 있습니다. |
| **쿼리 비용** | 라이브 데이터 소스를 사용할 경우 원본 DB에서 발생하는 쿼리 비용이 추가될 수 있습니다. |
