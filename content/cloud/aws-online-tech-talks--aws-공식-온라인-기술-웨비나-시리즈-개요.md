## 🔧 주요 특징

|항목|설명|
|---|---|

## 🧪 활용 시나리오

- **AWS 신규 서비스 학습**
    - 예: Amazon Bedrock, Graviton, Clean Rooms 신기능 소개
- **아키텍처 모범 사례 습득**
    - Well-Architected Framework, 보안·비용 최적화 사례 학습
- **기술 심화 학습**
    - AI/ML, 컨테이너, DevOps, Serverless 등 심층 세션 참여
- **사내 교육 자료 활용**
    - 온디맨드 영상과 슬라이드 다운로드 후 내부 교육 자료로 활용

---

## ✅ 장점

- **무료 학습 기회** → AWS 계정 없이도 시청 가능
- **최신 정보 제공** → 서비스 출시나 업데이트를 신속히 반영
- **다양한 난이도·주제** → 입문자부터 전문가까지 커버
- **재시청 가능** → 온디맨드 영상·자료로 반복 학습 가능
