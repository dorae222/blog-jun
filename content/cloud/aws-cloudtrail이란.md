> **NOTE:**
> - API 활동을 기록하여 검토
> - AWS 계정에서 수행되는 작업(사용자, 역할 또는 AWS 서비스가 수행하는 작업)을 CloudTrail이 이벤트(로그)로 기록
> - 이벤트에는 AWS Management Console, AWS Command Line Interface, AWS SDK/API에서 수행되는 작업들이 포함
> - 누가 또는 무엇이 어떤 작업을 수행했는지, 어떤 리소스에 대해 조치가 취해졌는지, 언제 이벤트가 발생했는지 등 AWS 내 모든 계정 활동을 기록
> - AWS 계정의 거버넌스, 규정 준수, 운영 감사, 보안 조사에 활용
> - CloudTrail은 모든 계정에서 기본적으로 항상 활성화되어 있음
> - CloudTrail 로그 파일은 KMS로 암호화 가능
> - CloudTrail 로그 파일 무결성 검증 기능을 통해 CloudTrail이 로그 파일을 지정된 S3 버킷으로 전송한 이후 파일이 그대로 유지되었는지, 삭제되거나 수정되었는지 확인 가능


## 📌 **AWS CloudTrail이란?**

**AWS CloudTrail**은
👉 **AWS 계정 내에서 발생하는 모든 활동(API 호출, 콘솔 작업, 서비스 간 호출 등)을 이벤트로 기록하고, 이를 분석·추적할 수 있게 해주는 감사(Audit) 및 거버넌스 서비스**입니다.

쉽게 말해, **AWS에서 일어나는 일에 대한 로그를 자동으로 수집하고 저장해주는 서비스**입니다.

---

## ✨ **CloudTrail이 기록하는 주요 이벤트**

CloudTrail은 크게 세 가지 유형의 이벤트를 기록합니다.

### ✅ 1. 관리 이벤트 (Management Events)

- **AWS 리소스를 생성, 수정, 삭제하는 활동**을 기록합니다.

- 예:

    - EC2 인스턴스 시작/중지
    - S3 버킷 생성/삭제
    - IAM 정책 변경

- **기본적으로 활성화되어 있으며, 추가 비용 없이 이벤트 히스토리에서 최근 90일간 확인 가능**합니다.

---

### ✅ 2. 데이터 이벤트 (Data Events)

- S3 객체 수준 접근이나 Lambda 함수 호출처럼 **세부적인 리소스 접근을 기록**합니다.

- 예:

    - S3 `GetObject` / `PutObject`
    - Lambda `Invoke`

- **기본적으로 비활성화되어 있으며**, 원하는 버킷이나 함수에 대해 선택적으로 활성화할 수 있고(활성화 시 추가 비용 발생) 세밀한 감시가 가능합니다.

---

### ✅ 3. 인사이트 이벤트 (Insights Events)

- **비정상적인 API 사용 패턴을 자동으로 감지**합니다.

- 예:

    - 평소보다 갑자기 증가한 `TerminateInstances` 호출
    - 갑작스러운 권한 변경 API 호출 급증

- 보안 이상 탐지나 운영 모니터링에 유용합니다.

---

## 🛠️ **CloudTrail의 작동 방식**

1. **이벤트 수집:**
    AWS 계정에서 발생하는 API 호출을 자동으로 수집합니다.

2. **로그 저장:**

    - 기본적으로 최근 90일간은 CloudTrail 콘솔에서 조회할 수 있습니다.
    - 장기 보관이 필요하면 **Trail을 생성하여 S3 버킷에 로그 파일로 저장**하도록 설정합니다.

3. **분석 및 연계:**

    - **CloudWatch Logs**로 전송해 실시간 모니터링이 가능합니다.
    - **Athena**로 S3에 쌓인 로그를 SQL로 분석할 수 있습니다.
    - **Security Hub, GuardDuty** 등과 연계해 보안 대응을 강화할 수 있습니다.

---

## 🔧 **CloudTrail Trail(추적) 설정**

- **Trail이란?**
    CloudTrail 이벤트를 **지속적으로 S3 등으로 전달·보관하는 설정**입니다.

✅ **기본 이벤트 히스토리**

- 별도 Trail 없이도 최근 90일 동안의 관리 이벤트를 콘솔에서 바로 조회할 수 있습니다.

✅ **Trail을 만들면**

- S3 버킷에 장기적으로 모든 이벤트 로그를 저장합니다.
- 여러 리전에 걸친 통합 로그 수집이 가능합니다.
- KMS로 암호화하거나, SNS로 알림 전송 등 추가 설정을 할 수 있습니다.

---

## 🏗️ **주요 사용 사례**

✔ **보안 감사 및 규제 준수**

- “누가 이 S3 버킷을 삭제했지?”
- “이 계정에서 어떤 IAM 역할이 사용됐지?”

✔ **문제 해결 및 트러블슈팅**

- 특정 리소스가 왜 바뀌었는지, 언제 바뀌었는지 추적할 수 있습니다.

✔ **운영 모니터링**

- 서비스별 API 호출 패턴을 분석해 최적화 포인트를 찾을 수 있습니다.

✔ **사고 조사**

- 침해 사고 발생 시 악의적인 API 호출을 추적할 수 있습니다.

---

## 💡 **추가 기능 및 팁**

- **다중 계정 통합:**
    여러 계정을 운영 중이라면 조직(Organizations)을 통해 **모든 계정의 이벤트를 한 S3 버킷으로 모아 저장**할 수 있습니다.

- **KMS 암호화:**
    S3에 저장되는 로그를 KMS로 암호화해 보안을 강화할 수 있습니다.

- **SNS 알림 연계:**
    CloudTrail 로그가 S3에 도착하면 SNS로 알림을 발송하도록 설정할 수 있습니다.

- **비용 고려:**

    - 관리 이벤트 기본 90일 조회: 무료
    - S3 장기 보관, 데이터 이벤트, Insights 활성화 시: 추가 비용 발생
