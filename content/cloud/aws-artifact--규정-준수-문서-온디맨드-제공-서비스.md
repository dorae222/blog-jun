## 🧩 Quick Overview

| 항목              | 설명 |
|-------------------|------|
| **서비스명**       | AWS Artifact |
| **유형**           | **규정 준수(Compliance) 및 보안 관련 문서 제공 서비스** |
| **주요 목적**       | AWS 클라우드 사용 시 필요한 **감사·규정 준수 보고서 및 계약 문서**를  
                       온디맨드로 조회·다운로드할 수 있도록 지원

> 📝 **AWS Artifact**는 AWS에서 제공하는 **규정 준수 및 보안 관련 문서의 중앙 저장소**로,  
> **감사·보안팀·컴플라이언스 담당자**가 필요한 문서를 즉시 확인하고 내려받을 수 있도록 설계된 서비스입니다.

---

## 🔧 주요 기능

| 기능 | 설명 |
|------|------|
| **Artifact Reports** | SOC, ISO, PCI DSS 등 **감사 및 규정 준수 보고서** 조회/다운로드 |
| **Artifact Agreements** | HIPAA BAA, GDPR DPA 등 **규제 준수 계약 문서** 관리 |
| **Self-Service On-Demand** | 언제든지 AWS 콘솔에서 바로 접근 가능 |
| **문서 최신화 자동 반영** | AWS의 최신 인증/감사 결과를 즉시 제공 |

---

## 📦 제공 문서 예시

1. **감사/보안 보고서 (Reports)**
   - **SOC 1 / SOC 2 / SOC 3 보고서**
   - **ISO 27001 / ISO 27017 / ISO 27018 인증서**
   - **PCI DSS Attestation of Compliance (AOC)**
   - **FedRAMP 보고서**

2. **규정 준수 계약 (Agreements)**
   - **HIPAA Business Associate Addendum (BAA)**
   - **GDPR Data Processing Addendum (DPA)**
   - **NDA(Non-Disclosure Agreement)**

---

## 🧪 활용 시나리오

- **보안·감사 대응**
  - 내부 보안팀 또는 외부 감사 요청 시 SOC/ISO/PCI 보고서 제출
- **규제 산업 대응**
  - 의료(HIPAA), 금융(PCI), 공공(FedRAMP) 환경에서 계약서 관리
- **컴플라이언스 문서 중앙화**
  - 팀 단위 접근·다운로드로 감사 준비 시간 단축

---

## ✅ 장점

- **실시간 최신 문서 제공** → 별도 요청 없이 바로 다운로드 가능
- **감사 준비 효율화** → SOC/ISO/PCI 등 글로벌 인증 문서 확보 용이
- **규제 산업 대응 용이** → BAA/DPA 등 계약 문서 관리 가능
- **AWS 계정별 셀프서비스** → 콘솔 로그인만으로 접근 가능

## ⚠️ 유의사항

| 항목 | 설명 |
|------|------|
| **문서 접근 권한 필요** | AWS 계정 권한(IAM)이 있어야 접근할 수 있습니다. |
| **문서만 제공, 적용은 별도** | 보고서 제출·검토 후 실제 규정 준수 적용 및 책임은 고객에게 있습니다. |
| **지역별 문서 차이 존재** | 일부 인증·계약은 리전별로 상이할 수 있습니다. |
