## 🧩 Quick Overview

|항목|설명|
|---|---|
|**서비스명**|AWS Migration Evaluator|
|**유형**|**클라우드 마이그레이션 계획·비용 분석 도구**|
|**주요 목적**|온프레미스·클라우드 워크로드를 분석해 **AWS 마이그레이션 비용·TCO·권장 인프라** 산출|

---

## 🔧 주요 특징

|항목|설명|
|---|---|
|**자산 수집**|서버, CPU, 메모리, 스토리지, 네트워크 사용량을 자동으로 수집|
|**TCO 분석**|온프레미스 비용과 비교하여 AWS 사용 시의 총 소유 비용(TCO)을 산정|
|**권장 인스턴스 제안**|수집한 사용량 데이터에 기반해 최적의 EC2 인스턴스 및 스토리지 조합을 제시|
|**보고서 제공**|마이그레이션 시나리오별 예상 절감액 및 비용 시뮬레이션을 포함한 보고서 생성|
|**Agent/Agentless 지원**|경량 에이전트 설치 방식 또는 VM Import 등 에이전트리스 방식으로 데이터 수집 지원|

---

## 🧪 활용 시나리오

- 온프레미스 → AWS 마이그레이션 사전 비용 분석
- 워크로드별 적정 인스턴스·스토리지 선택
- 클라우드 이전 후 절감 효과(TCO) 시각화
- 경영진 보고용 마이그레이션 계획서 작성

---

## ✅ 장점

- **자동 데이터 수집** → 실사용량에 기반한 권장 인프라 산출로 신뢰성 향상
- **TCO 기반 의사결정 지원** → 마이그레이션의 ROI(투자수익률) 추정 가능
- **비용 절감 전략 도출** → 오버프로비저닝된 자산 식별로 비용 최적화 기회 제공

---

## ⚠️ 유의사항

|항목|설명|
|---|---|
|**데이터 수집 기간 필요**|정확한 분석을 위해 최소 2~4주간 모니터링 권장|
|**권장 결과는 시뮬레이션**|제안값은 시뮬레이션 결과로, 실제 워크로드 특성에 대한 검증이 필요|
|**보안 검토 필요**|온프레미스의 메타데이터 및 성능 정보가 전송되므로 보안 검토를 수행해야 함|
