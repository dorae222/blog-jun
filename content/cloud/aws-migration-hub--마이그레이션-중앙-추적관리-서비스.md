## 🧩 Quick Overview

| 항목        | 설명                                                                       |
| --------- | ------------------------------------------------------------------------ |
| **서비스명**  | AWS Migration Hub                                                        |
| **유형**    | **애플리케이션·서버 마이그레이션 통합 관리 서비스**                                           |
| **주요 목적** | 여러 마이그레이션 도구와 워크플로우를 **단일 콘솔에서 추적·관리**하고 **마이그레이션 진행 상황과 상태를 가시화**하는 서비스 |

> 🚚 **AWS Migration Hub**를 사용하면  
> **서버, DB, 애플리케이션 마이그레이션을 중앙에서 추적**하며  
> **여러 마이그레이션 툴(AWS/서드파티)과 통합**해 상태를 모니터링할 수 있습니다.

---

## 🔧 주요 특징

| 항목 | 설명 |
|------|------|
| **중앙 집중 관리** | 마이그레이션 대상 자산(서버, 앱)과 상태를 한 곳에서 확인할 수 있습니다. |
| **멀티 툴 통합** | AWS MGN, DMS, Application Migration Service, SMS 등 다양한 마이그레이션 서비스와 연계해 상태를 집계합니다. |
| **진행 상태 시각화** | 전체 마이그레이션의 단계별 진행률과 현황을 가시화하여 추적할 수 있습니다. |
| **자산 관리** | 마이그레이션 대상 서버·애플리케이션의 인벤토리를 관리할 수 있습니다. |
| **비용·시간 추적** | 예상 완료 시간과 단계별 진행도를 확인할 수 있습니다. |

---

## 📦 통합 가능한 도구 예시

1. **AWS Application Migration Service (AWS MGN)**  
   - 서버를 EC2로 리호스팅(Lift-and-Shift)
2. **AWS Database Migration Service (DMS)**  
   - 데이터베이스 마이그레이션·복제
3. **AWS Server Migration Service (SMS)** *(점진적 폐지)*
4. **서드파티 툴 연계**  
   - CloudEndure, RiverMeadow 등

---

## 🧪 활용 시나리오

- **온프레미스 → AWS 마이그레이션** 진행 현황을 중앙에서 관리
- **다수 서버·DB 동시 이전** 시 전체 진행률 모니터링
- **마이그레이션 중 리스크 관리** 및 완료 예상 시간 확인
- **조직 단위 보고용 대시보드**로 활용

---

## ✅ 장점

- **단일 콘솔**: 여러 마이그레이션 워크로드의 상태를 한곳에서 통합 관리 가능
- **멀티툴 호환성**: AWS와 서드파티 마이그레이션 툴의 작업을 모두 추적할 수 있음
- **가시성 확보**: 진행 상황, 리스크, 완료 시점 예측에 유용
- **리소스 식별 용이**: 서버·DB 자산 인벤토리를 효율적으로 관리

---

## ⚠️ 유의사항

| 항목 | 설명 |
|------|------|
| **실제 마이그레이션 수행은 아님** | Migration Hub는 **추적·관리** 도구로, 실제 마이그레이션은 연계된 툴이 수행합니다. |
| **통합 설정 필요** | 사용하려는 마이그레이션 툴을 Migration Hub에 연결해야 합니다. |
| **지원 리전 제한** | 모든 리전에서 동일한 가용성을 제공하지 않을 수 있습니다. |
