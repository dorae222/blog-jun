# Useful Scripts

독립 실행 유틸리티 스크립트. 1회성이지만 참고 가치가 있는 것들.

| 스크립트 | 용도 |
|---|---|
| `embedding_generator.py` | RAG용 포스트 임베딩 생성 (pgvector) |
| `build_post_links.py` | PostLink (관련 포스트) 자동 생성 |
| `extract_paper_figures.py` | 논문 PDF에서 figure 이미지 추출 |
| `enrich_content.py` | 기존 포스트 컨텐츠 보강 (GPT 활용) |
| `generate_figures_vllm.py` | vLLM 로컬 모델로 figure 생성 |
| `pdf_import.py` | PDF 파일을 포스트로 임포트 |
| `playwright_check.py` | Playwright 기반 렌더링 검증 |
