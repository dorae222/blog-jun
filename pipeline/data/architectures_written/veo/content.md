# Veo 2: 시네마틱 4K 비디오 생성 모델

**Google DeepMind** · **2024-05-14** · **Diffusion** · **Proprietary**

## 개요

Veo(현재 Veo 2)는 2024년 Google DeepMind가 발표한 고해상도 텍스트/이미지-비디오 생성 모델로, 최대 4K 해상도의 장편 비디오 생성 능력을 갖춘 최고 수준의 상업 비디오 생성 시스템이다. Google DeepMind는 영상 생성 분야에서 Imagen Video, Lumiere, VideoPoet, Phenaki 등 다수의 연구를 수행해 왔으며, Veo 2는 이러한 연구 성과들을 하나의 통합 시스템으로 결집한 결과물이다.

Veo 2는 Imagen 계열의 T5 텍스트 인코더 기반 Cascaded Diffusion 접근법을 영상으로 확장하였다. Cascaded Diffusion은 저해상도에서 비디오를 먼저 생성한 뒤, 초해상도(Super-Resolution) 확산 모델로 단계적으로 해상도를 높이는 다단계 생성 방식이다. 이 접근법은 한 번에 4K 영상을 생성하는 것보다 각 단계의 학습 난이도를 낮추고, 전체 품질을 높이는 효과가 있다.

Veo 2의 핵심 특징은 세 가지로 요약된다. 첫째, **시네마틱 카메라 동작 제어**: 달리(dolly), 팬(pan), 줌(zoom), 틸트(tilt), 크레인 샷 등 전문 영화 제작에서 사용하는 카메라 동작을 텍스트 프롬프트로 자연스럽게 제어할 수 있다. 둘째, **물리적으로 그럴듯한 상호작용**: 유체 역학, 물체 충돌, 중력 효과, 사람 동작의 정확한 표현이 가능하다. 셋째, **장편 비디오 생성**: 분 단위의 긴 비디오를 시간적 일관성을 유지하면서 생성할 수 있다. 특히 텍스트 프롬프트에서 지정한 카메라 앵글, 렌즈, 움직임을 정확히 제어하는 기능은 실제 영화 제작 워크플로우에서 활용될 수 있는 수준이다.

Veo 2는 YouTube Shorts 및 Google Workspace 통합, 전문 영화 제작사(예: 도널드 글로버의 Gilga 등)와의 협업을 통해 상업적 배포가 이루어졌다.

## 아키텍처 상세

### Cascaded Diffusion 파이프라인

Veo 2의 아키텍처는 공개된 정보가 제한적이나, 다음과 같은 다단계 파이프라인으로 구성된 것으로 알려져 있다:

1. **텍스트 인코딩**: T5-XXL(11B) 텍스트 인코더로 프롬프트를 풍부한 의미 임베딩으로 변환
2. **기본 비디오 생성**: 저해상도(예: 256x256) 시공간 확산 모델로 기본 비디오 구조 생성
3. **공간 초해상도**: 확산 기반 Super-Resolution 모델로 1080p → 4K까지 해상도 업스케일
4. **시간적 초해상도**: 프레임 보간 모델로 프레임 레이트 향상

확산 과정의 학습 목표는 각 단계에서 표준적인 노이즈 예측을 사용한다:

$$\mathcal{L} = \mathbb{E}_{t, \mathbf{z}_0, \boldsymbol{\epsilon}}\left[w(t)\|\boldsymbol{\epsilon} - \boldsymbol{\epsilon}_\theta(\mathbf{z}_t, t, c)\|^2\right]$$

여기서 $w(t)$는 SNR 기반 가중치이며, $c$는 텍스트 조건과 카메라 제어 조건을 포함한다.

#### 저해상도 → 고해상도 단계별 상세

Cascaded Diffusion의 각 단계는 독립적인 확산 모델로 구성되며, 이전 단계의 출력을 조건으로 받아 동작한다. 기본 비디오 생성(Base Model) 단계에서는 256x256 해상도의 비디오를 생성하는데, 이 단계에서 장면의 전체적인 구조, 객체 배치, 동작 궤적, 카메라 동작 등 영상의 근본적인 시각적 계획이 결정된다. 저해상도에서 작업함으로써 계산 비용을 크게 줄이면서도 시공간적 의미 구조를 효과적으로 학습할 수 있다.

공간 초해상도(Spatial Super-Resolution) 단계는 일반적으로 2~3개의 하위 단계로 세분화된다. 예를 들어 256x256 → 512x512 → 1080p → 4K와 같이 점진적으로 해상도를 높인다. 각 하위 단계의 확산 모델은 이전 단계의 출력 $\mathbf{z}_0^{(l)}$을 조건으로 받으며, 조건부 노이즈 예측을 수행한다:

$$\boldsymbol{\epsilon}_\theta^{(l+1)}(\mathbf{z}_t^{(l+1)}, t, c, \text{up}(\mathbf{z}_0^{(l)}))$$

여기서 $\text{up}(\cdot)$은 이전 단계 출력을 현재 해상도로 업샘플링하는 연산이다. 이 접근법의 핵심적인 장점은 각 단계가 상대적으로 간단한 작업(2배 업스케일 시 세부 디테일 추가)에만 집중하므로, 한 번에 256x256에서 4K로 도약하는 것보다 훨씬 안정적인 학습이 가능하다는 점이다.

#### 시간적 초해상도 (Temporal Super-Resolution)

시간적 초해상도 단계는 기본 비디오의 프레임 레이트를 높이는 역할을 한다. 기본 생성 모델이 예를 들어 8fps로 비디오를 생성하면, 시간적 초해상도 모델이 중간 프레임을 보간(interpolation)하여 24fps 또는 30fps로 향상시킨다. 이 과정에서 단순한 선형 보간이 아닌, 확산 기반의 조건부 프레임 생성을 사용한다. 인접한 키 프레임 $\mathbf{x}_{t_i}$와 $\mathbf{x}_{t_{i+1}}$을 조건으로 받아, 중간 시점 $t_m$의 프레임을 확산 모델로 생성한다:

$$\mathbf{x}_{t_m} = \text{Denoise}(\mathbf{z}_{t_m}^{(T)}, \mathbf{x}_{t_i}, \mathbf{x}_{t_{i+1}}, c)$$

이 방식은 단순 보간 대비 동작의 자연스러움을 크게 향상시키며, 빠르게 움직이는 객체나 복잡한 카메라 동작에서도 시각적 품질을 유지할 수 있다.

### 시공간 Transformer (DiT) 백본

기본 비디오 생성 모델은 시공간 Full Self-Attention을 사용하는 DiT 구조를 채택한다. 비디오 프레임은 잠재 공간에서 시공간 패치로 분할되어 토큰 시퀀스가 되며, Transformer 블록이 시공간 의존성을 포착한다.

긴 비디오 생성을 위해 Temporal Attention 또는 비디오 청크(chunk) 단위 처리 전략이 적용된다. 청크 간의 일관성은 이전 청크의 마지막 프레임들을 다음 청크의 조건으로 활용하는 오버랩 방식으로 유지된다.

#### Attention 메커니즘과 시간적 일관성

DiT 백본의 각 Transformer 블록은 시간적 일관성을 보장하기 위한 구조적 설계를 포함한다. 일반적으로 시공간 Attention은 두 가지 방식으로 구현될 수 있다. 첫째, **Factorized Attention** 방식으로 공간 Attention과 시간 Attention을 분리하여 순차적으로 적용한다. 공간 Attention은 각 프레임 내의 패치 간 관계를, 시간 Attention은 동일 공간 위치의 프레임 간 관계를 학습한다:

$$\text{SpatioTemporal}(\mathbf{X}) = \text{TemporalAttn}(\text{SpatialAttn}(\mathbf{X}))$$

둘째, **Full 3D Attention** 방식으로 모든 시공간 토큰 간의 관계를 한번에 계산한다. Veo 2는 Full Self-Attention을 채택한 것으로 알려져 있으나, 토큰 수가 매우 많아지는 고해상도 장면에서의 계산 비용 문제를 해결하기 위해 윈도우 기반 Attention이나 희소(Sparse) Attention 전략이 함께 적용되었을 가능성이 높다.

시간적 일관성 유지를 위해 인접 프레임 간의 Attention 가중치를 강화하는 시간적 인접성 바이어스(temporal proximity bias)가 적용된 것으로 추정된다. 이를 통해 먼 시점의 프레임보다 가까운 시점의 프레임에 더 높은 Attention 가중치를 부여하여, 프레임 간의 부드러운 전환과 동작의 연속성을 보장한다.

### 카메라 동작 제어

카메라 동작 제어를 위한 별도 조건 임베딩이 존재하는 것으로 추정된다. 카메라 파라미터(위치, 방향, 초점 거리)를 벡터로 인코딩하여 확산 과정의 조건으로 주입하면, 생성되는 비디오의 카메라 동작을 세밀하게 제어할 수 있다:

$$\boldsymbol{\epsilon}_\theta(\mathbf{z}_t, t, c_{\text{text}}, c_{\text{camera}})$$

#### 6DoF 카메라 제어의 기술적 구현

Veo 2의 카메라 제어는 6자유도(6DoF: Six Degrees of Freedom) 기반으로 동작하는 것으로 추정된다. 6DoF는 3차원 공간에서의 이동(Translation) 3축 $(x, y, z)$과 회전(Rotation) 3축 (Roll, Pitch, Yaw)을 포함하며, 이를 통해 현실 세계의 카메라 동작을 완전히 표현할 수 있다. 각 프레임 $i$에서의 카메라 상태는 다음과 같은 파라미터로 정의된다:

$$c_{\text{camera}}^{(i)} = [\mathbf{p}_i, \mathbf{r}_i, f_i]$$

여기서 $\mathbf{p}_i = (x_i, y_i, z_i)$는 카메라 위치, $\mathbf{r}_i = (\phi_i, \theta_i, \psi_i)$는 오일러 각도로 표현된 카메라 방향, $f_i$는 초점 거리(focal length)이다. 프레임 시퀀스에 걸친 카메라 궤적 $\{c_{\text{camera}}^{(1)}, ..., c_{\text{camera}}^{(N)}\}$은 MLP 또는 별도의 소형 Transformer를 통해 임베딩되어 메인 DiT 백본의 각 블록에 AdaLN(Adaptive Layer Normalization) 또는 Cross-Attention으로 주입된다.

텍스트 프롬프트에서 "dolly zoom", "crane shot", "tracking shot" 등의 전문 영화 용어가 입력되면, 텍스트 인코더가 이를 해석하고 해당하는 6DoF 카메라 궤적 패턴으로 매핑하는 과정이 학습 단계에서 이루어진 것으로 보인다. 이를 위해 대규모 영상 데이터에서 카메라 동작을 자동 추정(SfM, Structure from Motion 또는 학습 기반 카메라 포즈 추정)하여 카메라 궤적 라벨을 추출하고, 이를 학습 조건으로 활용하는 방식이 적용되었을 것으로 추정된다.

## 핵심 혁신

Veo 2의 핵심 혁신은 4K 해상도와 시네마틱 카메라 제어를 결합한 전문 영상 제작 수준의 비디오 생성이다. Cascaded Diffusion 접근법으로 각 단계의 생성 난이도를 분산시키면서 최종 품질을 극대화하였다. 카메라 동작 제어는 전문 영상 제작자가 AI 도구를 자연스럽게 워크플로우에 통합할 수 있게 하는 핵심 기능이다. Google의 대규모 인프라를 활용한 데이터 수집과 학습도 Veo 2의 품질을 뒷받침하는 중요한 요소이다.

## 학습

학습 데이터 및 모델 파라미터는 공개되지 않았다. Google 내부 대규모 비디오 데이터셋과 외부 라이선스 데이터를 활용한 것으로 알려져 있다. VideoFeedback 등 인간 선호도 데이터로 RLHF 유사 정렬 학습이 적용된 것으로 추정된다. Google의 TPU v5 클러스터를 활용한 대규모 학습이 이루어졌을 것으로 보인다. SynthID 워터마킹이 생성된 비디오에 자동으로 적용되어 AI 생성 콘텐츠 식별이 가능하다.

### 학습 방법론 상세

학습은 크게 세 단계로 구분되는 것으로 추정된다. **1단계: 사전학습(Pre-training)**에서는 대규모 비디오-텍스트 쌍 데이터셋으로 기본적인 시공간 생성 능력을 학습한다. YouTube를 포함한 Google 내부 비디오 데이터셋이 핵심 학습 데이터로 활용되었을 가능성이 높으며, 수억 개 이상의 비디오-텍스트 쌍이 사용된 것으로 추정된다. 텍스트 캡션은 자동 생성(예: Gemini 기반 비디오 캡셔닝)과 인간 어노테이션의 조합으로 구성되었을 것이다.

**2단계: 고품질 파인튜닝(High-Quality Fine-tuning)**에서는 전문 영상 제작자가 선별한 고품질 영화, 다큐멘터리, 광고 영상 데이터로 시각적 품질과 시네마틱 특성을 강화한다. 이 단계에서 카메라 동작 라벨링 데이터도 함께 학습에 포함되며, SfM 알고리즘으로 추출한 카메라 궤적 정보가 조건으로 활용된다.

**3단계: 정렬 학습(Alignment Training)**에서는 인간 선호도 데이터를 활용하여 생성 품질을 정렬한다. RLHF(Reinforcement Learning from Human Feedback) 또는 DPO(Direct Preference Optimization) 방식으로 인간이 선호하는 비디오 스타일, 동작 품질, 시각적 사실감 방향으로 모델을 미세조정한다. 이 과정에서 물리 법칙 준수, 얼굴/손 생성 품질, 시간적 일관성 등 비디오 생성에서 특히 중요한 항목에 대한 별도의 보상 모델(Reward Model)이 학습되었을 것으로 추정된다.

Cascaded Diffusion의 각 단계(기본 생성, 공간 초해상도, 시간적 초해상도)는 독립적으로 학습된 후, 전체 파이프라인으로 결합되어 엔드-투-엔드 미세조정이 이루어졌을 가능성이 있다.

## 한계 및 과제

Veo 2는 비디오 생성 분야에서 최고 수준의 성능을 보이지만, 여전히 해결해야 할 기술적 한계들이 존재한다.

**시간적 플리커링(Temporal Flickering)**: 장시간 비디오 생성 시 프레임 간 미세한 색상, 밝기, 텍스처의 불일치가 발생할 수 있다. 특히 정적인 배경이나 느리게 움직이는 장면에서 플리커링이 두드러지며, 이는 확산 과정의 확률적 특성에서 기인하는 근본적인 문제이다. 청크 기반 생성에서 청크 경계 부분의 불연속성도 플리커링의 원인 중 하나이다.

**복잡한 장면에서의 아티팩트**: 다수의 인물이 상호작용하거나, 세밀한 손가락 동작, 텍스트 렌더링이 포함된 장면에서 시각적 아티팩트가 발생한다. 물리적 상호작용이 복잡한 장면(예: 여러 물체가 동시에 충돌하는 장면)에서는 물리 법칙 위반이 관찰되기도 한다.

**제한적 공개 접근**: Veo 2는 Google의 독점 모델로, API 접근이 제한적이며 모델 가중치나 아키텍처 세부사항이 공개되지 않았다. 이는 학술 연구 커뮤니티에서의 재현성과 검증을 어렵게 만들며, 오픈소스 생태계와의 격차를 벌리는 요인이 된다.

**긴 비디오의 의미적 일관성**: 2분 이상의 장편 비디오에서 초반과 후반의 스토리 라인이나 시각적 스타일이 일관되게 유지되지 않는 경우가 있다. 현재의 청크 기반 생성 방식은 국소적 일관성은 유지하지만, 전역적 서사 구조를 일관되게 유지하는 데는 한계가 있다.

**생성 속도**: 4K 해상도의 장편 비디오 생성은 Cascaded Diffusion의 다단계 처리 특성상 상당한 시간이 소요된다. 실시간 또는 준실시간 생성은 현재로서는 불가능하며, 이는 인터랙티브 영상 제작 워크플로우에서의 활용을 제약하는 요인이다.

## 관련 모델

Veo 2는 Imagen에서 발전하였으며, Lumiere, VideoPoet 등 Google DeepMind의 영상 생성 연구를 통합한 모델이다. 후속 모델인 Veo 3(2025)는 네이티브 오디오-비디오 공동 생성 기능을 추가하였다.
