# GPT-5.5: 1M 컨텍스트와 동적 추론을 통합한 OpenAI의 차세대 플래그십

## 개요

GPT-5.5는 2026년 OpenAI가 공개한 GPT-5 계열의 후속 모델로, GPT-5.4를 직접 계승한다. 가장 큰 변화는 **컨텍스트 윈도우의 1M 토큰 확장**이며, **10개 주요 벤치마크 중 9개에서 GPT-5.4 대비 향상**을 기록하였다.

Artificial Analysis Intelligence Index 기준 **57점**으로 Claude Opus 4.7, Gemini 3.1 Pro와 함께 공동 1위에 올랐다. 가격은 GPT-5.4 대비 **2배로 인상**되었으나, 응답 지연(latency)은 동일하게 유지되어 사용자 경험의 일관성을 확보했다.

GPT-5.5의 가장 큰 변화는 단순한 능력 향상이 아니라 **추론 능력의 통합 방식**에 있다. o1, o3 시리즈에서 분리되어 있던 추론 전용 모델의 능력이 본 모델군에 자연스럽게 흡수되어, 별도의 모드 전환 없이 모델 내부에서 추론 깊이를 자동으로 조절한다.

## 아키텍처 상세

### 기본 구조

| 구성 요소 | 사양 |
|-----------|------|
| **아키텍처** | MoE Decoder-only Transformer (추정) |
| **어텐션** | Grouped-Query Attention (GQA) |
| **정규화** | RMSNorm |
| **활성화 함수** | SwiGLU |
| **위치 인코딩** | RoPE + YaRN 외삽 보정 |
| **컨텍스트 길이** | 1M 토큰 |
| **파라미터 수** | 미공개 |
| **가격** | GPT-5.4의 2배 |
| **Latency** | GPT-5.4와 동일 유지 |

세부 스펙은 OpenAI의 일관된 보안 정책에 따라 미공개이다.

### 1M 컨텍스트 활용 메커니즘

1M 토큰 컨텍스트의 실용성을 확보하기 위해 RoPE의 YaRN(Yet another RoPE extensioN) 또는 동등한 외삽 기법이 적용된 것으로 추정된다. YaRN은 주파수 대역별로 다른 보정 계수를 적용한다.

$$\theta'_i = \begin{cases} \theta_i & \text{if } i < N_h/2 \\ \theta_i \cdot s & \text{otherwise} \end{cases}$$

여기서 $s$는 컨텍스트 확장 비율에 비례하는 스케일링 계수이다. 또한 어텐션 시 `softmax`의 온도 보정을 추가하여 장문에서의 점수 분포 평탄화를 방지한다.

### 동적 Thinking 메커니즘

GPT-5.5는 별도의 추론 모드 토글 없이 모델 내부에서 자동으로 추론 깊이를 조절하는 동적 thinking 메커니즘을 도입하였다. 사용자는 다음 파라미터로 명시적 제어가 가능하다.

```json
{
  "model": "gpt-5.5",
  "reasoning_effort": "medium",
  "messages": [...]
}
```

`reasoning_effort`는 `minimal/low/medium/high` 4단계로, 어려운 문제에서는 자동으로 더 깊이 사고한다.

## 핵심 혁신

### 1. 1M 컨텍스트의 실용화

이전 세대의 100만 토큰 컨텍스트가 "이론상 가능"이었다면, GPT-5.5에서는 RULER, LongBench v2, BABILong 등 장문 평가에서 **후반부 토큰 활용도가 95% 이상**을 기록하며 실용성이 크게 개선되었다.

이는 다음과 같은 시나리오에서 RAG 의존도를 줄여준다.

- 단일 프롬프트 내 책 한 권(약 70만 토큰) 분석
- 대규모 코드베이스(20만~50만 라인) 일괄 이해
- 장편 회의록, 법률 문서, 의료 기록 통합 분석
- 멀티모달 비디오 + 자막의 장기 시퀀스 처리

### 2. 추론 능력의 통합

o1, o3 시리즈에서 분리되어 있던 추론 전용 모델의 능력이 GPT-5.5에 자연스럽게 통합되었다. 모델은 입력의 복잡도를 평가하여 자동으로 추론 깊이를 조절한다. 학습은 process reward model(PRM)과 outcome reward를 결합한 RL로 수행된 것으로 추정된다.

$$R_{\text{total}} = \lambda_p \cdot R_{\text{process}}(\text{steps}) + \lambda_o \cdot R_{\text{outcome}}(\text{answer})$$

여기서 $R_{\text{process}}$는 각 추론 단계의 정확성, $R_{\text{outcome}}$은 최종 답의 정답 여부를 평가한다.

### 3. 9/10 벤치마크 향상

GPT-5.5는 GPT-5.4 대비 다음 분야에서 향상을 기록하였다.

- **수학 추론**: AIME, MATH-500, Olympiad
- **과학 추론**: GPQA Diamond, MMLU-Pro
- **코딩**: SWE-bench Verified, LiveCodeBench
- **멀티모달**: MMMU, ChartQA
- **에이전트**: GAIA, AgentBench

미향상 1개 영역은 일반 채팅 선호도 평가로, 이미 GPT-5.4에서 충분히 높은 수준이었다.

## 한계 및 의의

### 한계

1. **가격 인상**: GPT-5.4 대비 2배로 인상되어, 단순 채팅 시나리오에서는 비용 효율이 떨어진다. 이를 보완하기 위해 GPT-5.5 mini, nano 변형이 함께 제공된다.
2. **완전 비공개**: 기술 보고서가 없으며 파라미터 수, 활성 파라미터, 전문가 수 등 핵심 수치가 모두 미공개이다.
3. **컨텍스트 왜곡 가능성**: 1M 토큰을 활용하더라도, 후반부 토큰의 정확도가 최대 5% 정도 손실되어 임계 시나리오에서는 RAG 보조가 권장된다.
4. **추론 비용 변동**: 동적 thinking으로 인해 동일 입력에서도 추론 시간과 비용이 가변적이며, 비용 예측이 어려워진다.

### 의의

GPT-5.5는 **추론과 대화의 통합**, **1M 컨텍스트의 실용화**, **지능 지표 공동 1위 진입**이라는 세 가지 의미를 지닌다. 첫째, 추론 모드와 일반 모드의 분리가 사라지면서 사용자 경험이 단순화되었다. 둘째, RAG 없이도 대규모 문서를 처리할 수 있게 되어, 엔터프라이즈 도입 시나리오에서 인프라 복잡도가 줄어든다. 셋째, Claude/Gemini와 함께 공동 1위에 올라 시장의 다극화가 더욱 뚜렷해졌다.

향후 GPT-6 세대에서는 Computer Use 능력의 통합, 멀티 에이전트 협업 프로토콜 표준화, 그리고 ASL-3급 안전성 평가의 강화가 핵심 방향이 될 것이다.
