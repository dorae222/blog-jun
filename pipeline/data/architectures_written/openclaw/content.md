# OpenClaw: 오픈소스 에이전틱 코딩 CLI

## 개요

OpenClaw는 [[claude-code|Claude Code]]에서 영감을 받아 개발된 오픈소스 에이전틱 코딩 CLI 도구다. Claude Code의 핵심 워크플로우(에이전틱 루프, 도구 시스템, 프로젝트 설정 파일)를 오픈소스로 재구현하여, 특정 LLM 벤더에 종속되지 않고 다양한 모델 백엔드와 함께 사용할 수 있도록 설계되었다.

자체 호스팅이 가능하여 데이터 주권이 중요한 기업 환경이나, 로컬 모델을 활용하고 싶은 개발자에게 적합하다.

---

## 아키텍처 상세

### 모델 추상화 레이어

OpenClaw의 핵심 설계 원칙은 **LLM 백엔드 독립성**이다. OpenAI API 호환 엔드포인트를 지원하는 모든 모델과 함께 동작한다:

- **클라우드 API**: OpenAI (GPT-4, o4-mini), Anthropic (Claude), Google (Gemini)
- **로컬 모델**: Ollama, vLLM, LM Studio 등
- **커스텀 엔드포인트**: 자체 호스팅 모델 서버

### 에이전틱 루프

Claude Code와 유사한 에이전틱 루프를 구현한다:

$$\text{입력 해석} \rightarrow \text{도구 선택} \rightarrow \text{실행} \rightarrow \text{결과 분석} \rightarrow \text{반복 또는 완료}$$

### 핵심 도구

| 도구 | 기능 |
|------|------|
| FileRead / FileWrite | 파일 읽기/쓰기 |
| Shell | 셸 명령 실행 |
| Search | 코드베이스 검색 (glob + grep) |
| WebFetch | URL 내용 가져오기 |

### 플러그인 시스템

커스텀 도구를 플러그인으로 추가할 수 있다. JSON 스키마 기반 도구 정의를 사용하여, 외부 API 연동이나 프로젝트 특화 작업을 자동화할 수 있다.

---

## 핵심 혁신

1. **LLM 벤더 독립**: 특정 모델에 종속되지 않고, OpenAI API 호환 엔드포인트를 지원하는 모든 모델 사용 가능
2. **자체 호스팅**: 프라이빗 환경에서 로컬 모델과 함께 운영 가능, 데이터가 외부로 유출되지 않음
3. **플러그인 확장**: 커스텀 도구를 JSON 스키마로 정의하여 무한히 확장
4. **경량 배포**: 단일 바이너리로 배포 가능, 설치 과정 최소화
5. **완전 오픈소스**: MIT 라이선스로 수정 및 재배포 자유

## 사용 시나리오

### 기업 환경 (데이터 주권)

- 소스 코드가 외부 API로 전송되는 것을 허용하지 않는 환경
- 사내 GPU 클러스터에 배포된 로컬 모델과 연동
- VPN 내부에서만 접근 가능한 환경

### 커스텀 워크플로우

- 사내 도구(Jira, Confluence 등)와 플러그인으로 연동
- CI/CD 파이프라인에 에이전틱 코딩 도구 통합
- 레거시 시스템 마이그레이션 자동화
