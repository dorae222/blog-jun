# Qwen2.5: 18T 토큰으로 달성한 오픈소스 최강 LLM

## 개요

Qwen2.5는 Alibaba Cloud가 2024년 9월 19일 공개한 Qwen2의 직접 후속 모델이다. 0.5B, 1.5B, 3B, 7B, 14B, 32B, 72B 총 일곱 가지 크기로 제공되며, '32B 이하 오픈 모델 중 최강'이라는 타이틀을 확보한 모델이다.

Qwen2에서 Qwen2.5로의 핵심 변화는 아키텍처 혁신이 아닌 데이터 스케일링이다. 학습 토큰을 7T에서 18T로 약 2.5배 늘리고, 수학과 코드 데이터의 비중을 대폭 강화했다. 이 전략은 놀라운 성과로 이어졌다: Qwen2.5-72B는 MMLU 86.1%로 Llama-3-405B(85.2%)를 능가했으며, 32B 모델은 GPT-4o에 근접하는 성능을 보여주었다.

## 아키텍처 상세

### 기본 구조

Qwen2.5의 아키텍처는 Qwen2와 동일하다. 핵심 변화는 학습 데이터와 정렬 파이프라인에 있다.

| 구성 요소 | Qwen2.5-7B | Qwen2.5-32B | Qwen2.5-72B |
|---|---|---|---|
| 파라미터 | 7B | 32B | 72B |
| Hidden Dimension | 3584 | 7168 | 8192 |
| 레이어 수 | 28 | 64 | 80 |
| Attention Head (Q) | 28 | 40 | 64 |
| 컨텍스트 길이 | 131,072 | 131,072 | 131,072 |
| 어휘 크기 | 151,936 | 151,936 | 151,936 |
| 위치 인코딩 | RoPE | RoPE | RoPE |
| 정규화 | RMSNorm | RMSNorm | RMSNorm |
| 활성화 함수 | SiLU (SwiGLU) | SiLU (SwiGLU) | SiLU (SwiGLU) |

### 2단계 학습 전략

Qwen2.5의 학습은 명확한 2단계로 구성된다:

**1단계: 대규모 일반 사전 학습**
- 18T 토큰의 대규모 다국어 데이터
- 웹 텍스트, 도서, 학술 논문, 코드, 수학 데이터 혼합
- 코사인 학습률 스케줄과 AdamW 옵티마이저

**2단계: 고품질 특화 파인튜닝**
- 수학(MATH, GSM8K 유형), 코드(HumanEval, MBPP 유형) 데이터 집중
- 지시 따르기(Instruction Following) 데이터 강화
- SFT + Online DPO 정렬

$$\mathcal{L}_{\text{total}} = \mathcal{L}_{\text{LM}} + \lambda_1 \mathcal{L}_{\text{SFT}} + \lambda_2 \mathcal{L}_{\text{DPO}}$$

### Online DPO 정렬

Qwen2에서 사용한 오프라인 DPO와 달리, Qwen2.5는 Online DPO를 채택했다. Online DPO는 학습 과정에서 모델 자체가 생성한 응답을 실시간으로 평가하여 선호도를 학습한다:

$$\mathcal{L}_{\text{Online DPO}} = -\mathbb{E}\left[\log \sigma\left(\beta \log \frac{\pi_\theta(y_w|x)}{\pi_{\text{ref}}(y_w|x)} - \beta \log \frac{\pi_\theta(y_l|x)}{\pi_{\text{ref}}(y_l|x)}\right)\right]$$

여기서 $y_w$, $y_l$은 각각 현재 모델이 생성한 좋은/나쁜 응답이다.

## 핵심 혁신

### 1. 데이터 스케일링의 위력

Qwen2 -> Qwen2.5의 핵심 교훈은 "아키텍처를 바꾸지 않아도, 더 많고 더 좋은 데이터로 큰 성능 향상이 가능하다"는 것이다:

| 벤치마크 | Qwen2-72B | Qwen2.5-72B | 변화 |
|---|---|---|---|
| MMLU | 84.2% | 86.1% | +1.9 |
| MATH | 69.0% | 83.1% | +14.1 |
| HumanEval | 64.6% | 86.6% | +22.0 |
| GSM8K | 89.5% | 91.6% | +2.1 |

특히 MATH +14.1, HumanEval +22.0이라는 극적인 향상은 수학/코드 데이터 강화의 효과를 명확히 보여준다.

### 2. 32B: 새로운 스위트 스폿

3B와 32B 크기가 새롭게 추가되었는데, 특히 32B는 A100 80GB 단일 GPU에서 FP16으로 실행 가능한 최대 크기이면서 GPT-4o에 근접하는 성능을 제공하여, 실무 배포의 "스위트 스폿"으로 자리잡았다.

### 3. 도메인 특화 모델 생태계

Qwen2.5와 함께 도메인 특화 모델이 출시되었다:
- **Qwen2.5-Coder**: 코드 생성/이해 특화
- **Qwen2.5-Math**: 수학 추론 특화

## 실무 활용

### 모델 크기 선택 가이드

| 크기 | 적합한 사용 사례 | VRAM 요구량 (FP16) |
|---|---|---|
| 0.5B/1.5B | 모바일, 엣지 디바이스 | 1~3GB |
| 3B | 가벼운 텍스트 처리 | 6GB |
| 7B | 범용 어시스턴트 | 14GB |
| 14B | 전문 분석 | 28GB |
| 32B | 프로덕션 서비스 | 64GB |
| 72B | 최고 품질 서비스 | 144GB |

### 활용 시나리오

1. **다국어 고객 지원**: 151K 어휘로 다양한 언어의 고객 질의 처리
2. **코드 리뷰/생성**: Qwen2.5-Coder로 개발 생산성 향상
3. **수학 교육**: Qwen2.5-Math로 수학 문제 풀이 및 설명
4. **RAG 시스템**: 128K 컨텍스트로 대량 문서 기반 질의응답

## 한계 및 전망

### 한계

1. **아키텍처 동일**: Qwen2와 동일한 아키텍처로, 구조적 혁신은 없음
2. **학습 데이터 비공개**: 18T 토큰의 상세 구성은 완전히 공개되지 않음
3. **영어/중국어 편향**: 29개 언어를 지원하나, 비주류 언어에서는 성능 저하
4. **추론 비용**: 72B Dense 모델의 추론 비용이 여전히 높음

### 전망

Qwen2.5는 "데이터가 왕이다(Data is King)"라는 명제를 다시 한번 입증한 모델이다. 동일 아키텍처에서 학습 데이터만 2.5배 늘려 MATH를 14% 포인트 향상시킨 결과는, 아키텍처 혁신만큼이나 데이터 스케일링과 품질이 중요하다는 것을 보여준다.

Qwen3에서는 하이브리드 추론(생각/비생각 모드), 대규모 MoE(235B-A22B), 36T 토큰 학습으로 또 한 단계 도약하며, Qwen 시리즈는 글로벌 오픈소스 LLM 생태계에서 Llama와 함께 양대 축을 형성하고 있다.
