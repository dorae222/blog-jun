# GLM-5.1: NVIDIA GPU 없이 학습된 중국 오픈 가중치 코딩 모델

## 개요

GLM-5.1은 2026년 3월 27일 중국 베이징 소재 Zhipu AI(智譜)가 공개한 5세대 General Language Model 계열의 1차 마이너 업데이트이다. GLM 시리즈는 칭화대 KEG 연구실의 GLM 130B 프로젝트(2022)에서 출발한 자체 사전학습 라인이며, 처음부터 중국어와 영어를 동시 지원하도록 설계된 양자 균형 코퍼스를 사용해온 것이 특징이다.

GLM-5.1의 가장 큰 화제성은 두 가지이다. 첫째, **NVIDIA GPU 없이 학습**되었다고 공식 발표되었다. 이는 2023년 10월 강화된 미국 첨단 반도체 수출 통제하에서도 중국 진영이 프런티어급 모델 학습 능력을 내재화했음을 보여준다. 둘째, 가중치를 공개(open-weights)하면서도 **코딩 벤치마크에서 Claude Opus 4.6 대비 94.6% 수준의 성능**을 달성하여, 오픈 가중치 진영의 새로운 상한선을 그었다.

GLM-5.1의 출시는 단순한 모델 업데이트를 넘어, 미국-중국 AI 패권 경쟁의 인프라 측면에서 의미 있는 변곡점이 되었다.

## 아키텍처 상세

### 기본 구조

| 구성 요소 | 사양 |
|-----------|------|
| **아키텍처** | Dense Decoder-only Transformer |
| **어텐션** | Grouped-Query Attention (GQA) |
| **정규화** | RMSNorm |
| **활성화 함수** | SwiGLU |
| **위치 인코딩** | RoPE (외삽 보정 적용) |
| **컨텍스트 길이** | 200K 토큰 |
| **파라미터 수** | 미공개 |
| **학습 인프라** | 중국 자체 가속기 클러스터 (NVIDIA 미사용) |

GLM-5.1은 GLM-4와 마찬가지로 표준 Decoder-only Transformer를 골격으로 하되, GQA를 도입하여 추론 시 KV 캐시 메모리를 절감하고 처리량을 향상시켰다.

### 자체 가속기 학습 환경

Zhipu AI는 구체적인 칩 종류를 명시하지 않았으나, 업계에서는 화웨이 Ascend 910B/910C 또는 Cambricon MLU 590 시리즈를 활용한 것으로 추정한다. 이러한 환경에서는 다음과 같은 기술적 장벽이 존재한다.

1. **통신 라이브러리**: NCCL이 NVIDIA 전용이므로, HCCL(화웨이) 또는 CNCL(Cambricon) 기반 분산 학습 스택이 필요하다.
2. **컴파일러 스택**: PyTorch + CUDA 의존성을 MindSpore 또는 자체 컴파일러로 대체해야 한다.
3. **혼합 정밀도**: BF16 지원 여부와 수치 안정성 확보가 관건이다.

이러한 도전을 해결하면서 GLM-5.1을 학습한 것은 중국 AI 인프라 자립의 의미 있는 진전이다.

### RoPE 외삽 보정

200K 토큰 컨텍스트를 안정적으로 지원하기 위해 RoPE에 외삽 보정 기법(YaRN 또는 NTK-aware scaling 계열)을 적용한 것으로 보인다. 기본 RoPE의 회전 행렬은 다음과 같다.

$$\text{RoPE}(x_m, m) = x_m \cdot e^{im\theta_i}, \quad \theta_i = 10000^{-2i/d}$$

장문 추론 시 $m$이 사전학습 범위를 벗어나면 어텐션 점수가 불안정해지는데, 주파수 $\theta_i$를 길이에 따라 보정하면 사전학습 길이의 수배까지 외삽이 가능하다.

## 핵심 혁신

### 1. 중국 자체 칩 기반 학습 검증

GLM-5.1은 미국이 첨단 GPU 수출을 통제한 2023년 이후 학습이 시작된 첫 번째 프런티어급 중국 모델이다. NVIDIA H100/H200 없이도 13조 토큰 이상의 학습이 가능함을 입증함으로써, 중국 AI 진영의 인프라 의존성에 관한 통념을 깨뜨렸다. 이는 향후 중국발 오픈 가중치 모델 라인의 지속 가능성에 중요한 의미를 갖는다.

### 2. 코딩 성능의 비약

GLM-5.1은 SWE-bench Verified, LiveCodeBench, BigCodeBench 등 주요 코딩 벤치마크에서 오픈 가중치 모델 중 최고 성능을 기록하였다. 후속 학습 단계에서 코드 실행 결과를 보상으로 사용하는 RLEF(RL from Execution Feedback) 기법을 적극 도입하였으며, 컴파일 통과 여부, 단위 테스트 통과율, 실제 GitHub 이슈 해결률을 다층적으로 보상에 반영하였다.

### 3. 양자 균형 사전학습

GLM 시리즈의 전통대로 중국어와 영어 데이터를 균형 있게 학습하여, 중영 코드 스위칭, 중국어 기반 코드 주석 처리 등에서 영어 단일 모델 대비 강점을 갖는다. 동시에 일본어, 한국어, 동남아 언어에서도 안정적인 성능을 보인다.

### 코딩 강화 보상 함수 (RLEF)

GLM-5.1의 코딩 능력 도약은 RLEF(RL from Execution Feedback) 기법에 크게 기인한다. 보상 함수는 다음과 같이 구성된 것으로 추정된다.

$$R(x, y) = \alpha R_{\text{compile}}(y) + \beta R_{\text{unit-test}}(y) + \gamma R_{\text{style}}(y)$$

- $R_{\text{compile}}$: 생성 코드의 컴파일 통과 여부
- $R_{\text{unit-test}}$: 단위 테스트 통과율
- $R_{\text{style}}$: 코드 스타일과 가독성 평가

이러한 다층 보상 구조는 모델이 단순히 그럴듯해 보이는 코드를 생성하는 것이 아니라, **실제로 동작하는 코드**를 생성하도록 유도한다.

### 에이전트 능력

GLM-5.1은 도구 호출, 멀티스텝 추론, 자율 계획 수립 등 에이전트 시나리오에서도 오픈 가중치 진영 최상위 성능을 보인다. ReAct, ToolBench, AgentBench 등 평가에서 Claude Opus 계열의 90% 수준에 접근하였으며, 자체 호스팅 환경에서 Computer Use 변형을 구축하려는 사용자들에게 매력적인 선택지가 되고 있다.

## 한계 및 의의

### 한계

1. **상세 스펙 비공개**: 파라미터 수, 레이어 구성, 학습 토큰 수 등 핵심 수치가 미공개되어 학술적 재현 검증이 어렵다.
2. **자체 칩 효율 검증 부족**: NVIDIA 대비 학습 효율(MFU, Model FLOPs Utilization)이 어느 수준인지 외부 평가가 부재하다.
3. **라이선스 제약**: 오픈 가중치이지만 상업적 이용에 일부 제약이 있는 Custom 라이선스로 공개되었다.
4. **장문 일관성**: 200K 토큰 후반부 정보 활용도(needle-in-a-haystack)는 Claude/Gemini 대비 다소 열위로 평가된다.

### 의의

GLM-5.1은 단순히 또 하나의 오픈 가중치 모델이 아니라, **AI 인프라 지형도의 변화를 상징하는 모델**이다. 첫째, 미국의 GPU 수출 통제가 중국 AI 발전을 저지하는 단기적 효과는 있을지 몰라도, 자체 가속기 생태계 구축을 가속화하는 부작용이 있음을 보여준다. 둘째, DeepSeek V3/V4와 함께 오픈 가중치 진영의 코딩 성능이 폐쇄형 최상위 모델의 95% 이상에 도달하면서, 기업의 모델 선택지가 다양화되었다. 셋째, 200K 컨텍스트와 RLEF 기반 코딩 강화는 향후 GLM-5.5/6 등 후속 모델에서 더 확장될 핵심 기법이 될 것이다.

향후 Zhipu AI는 멀티모달 확장(GLM-V), 추론 특화 모델(GLM-Z, R 계열), 에이전트 프레임워크와의 통합을 강화할 것으로 전망된다.
