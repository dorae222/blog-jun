# SmolLM3-3B: 데이터부터 코드까지 전부 공개한 풀 오픈 SLM

## 개요

SmolLM3는 Hugging Face가 2025년 7월 8일 공개한 3B 파라미터 규모의 소형 언어 모델(SLM, Small Language Model)이다. SmolLM(135M), SmolLM2(135M / 360M / 1.7B)의 계보를 잇는 후속작으로, 동일한 디자인 철학을 더 큰 규모(3B)로 확장한 것이다.

기존 SLM들과 SmolLM3를 가르는 가장 큰 차이는 **풀 오픈(fully open) 정책**이다. 가중치(weights)만 공개하는 일반적인 오픈 웨이트(open weight) 모델과 달리, SmolLM3는 학습 데이터(training data), 학습 코드(training code), 데이터 전처리 파이프라인, 평가 스크립트, 학습 로그까지 모두 공개되어 있어 동일한 모델을 처음부터 재현(reproduce)할 수 있다.

성능 측면에서도 동급 3B 모델 중 최고 수준이다. Llama 3.2 3B, Qwen2.5 3B를 종합 벤치마크에서 능가하며, Qwen3 4B에 근접하는 수치를 보인다. 6개 주요 유럽 언어(영어, 프랑스어, 스페인어, 독일어, 이탈리아어, 포르투갈어)를 지원하고, 64K 토큰의 긴 컨텍스트와 도구 호출(tool calling), 추론 모드(reasoning mode)까지 갖추어 단순 채팅을 넘어 에이전트(agent) 환경에서도 실용적이다.

## 아키텍처 상세

### 기본 구조

| 구성 요소 | 사양 |
|-----------|------|
| **아키텍처** | Dense Decoder-only Transformer |
| **파라미터 수** | 3.08B |
| **레이어 수** | 36 |
| **히든 차원** | 2,048 |
| **어텐션 헤드** | 16 (Q) / 4 (KV) |
| **어텐션** | Grouped Query Attention (GQA) |
| **정규화** | RMSNorm |
| **활성화 함수** | SwiGLU |
| **위치 인코딩** | RoPE + NoPE 하이브리드 (4:1) |
| **컨텍스트 길이** | 64K (YaRN 확장 시 128K) |
| **어휘 수** | 128,256 (Llama 3 토크나이저) |

### 1.7B에서 3B로의 스케일업

SmolLM2 1.7B의 24층 → SmolLM3 36층으로 깊이를 1.5배 확장하면서, 히든 차원은 2048로 유지하였다. 이는 폭(width)을 늘리는 대신 깊이(depth)를 우선시하는 전략으로, 추론 능력 향상에 더 유리한 것으로 알려져 있다. GQA의 KV 헤드를 4개로 줄여 KV 캐시 메모리를 1/4로 압축하여 64K 장문에서도 단일 GPU 추론이 가능하다.

## 핵심 혁신

### 1. 풀 오픈 학습 레시피

SmolLM3 공개 자료는 다음을 모두 포함한다.

- **사전 학습 코드**: nanotron (Hugging Face의 분산 학습 프레임워크)
- **데이터 전처리**: datatrove (대규모 텍스트 정제 파이프라인)
- **평가 도구**: lighteval (오픈 LLM 벤치마크)
- **데이터 카드**: FineWeb-Edu, Stack-Edu, FineMath, MultiLingual-CC 등 비율 명시
- **학습 로그**: 11.2T 토큰 전 과정의 loss curve, gradient norm
- **하이퍼파라미터**: lr schedule, batch size, optimizer states

이 정도의 공개는 EleutherAI의 Pythia, Allen AI의 OLMo 이후 가장 완전한 풀 오픈 사례로, 학계 재현 연구와 SLM 후속 개발의 표준 자료가 된다.

### 2. 듀얼 모드 추론 (Dual-Mode Reasoning)

SmolLM3는 시스템 프롬프트로 두 모드를 전환한다.

- **`/no_think` 모드**: 빠른 직접 응답 - 일반 채팅, 간단한 질의
- **`/think` 모드**: extended thinking 블록 생성 후 답변 - 수학, 코드, 논리

이는 Qwen3의 thinking mode와 유사한 설계 철학으로, 단일 모델이 사용 사례에 따라 latency와 정확도를 절충할 수 있다. 추론 모드 활성화 시 GSM8K, MATH 등 수학 벤치마크 점수가 평균 8-12% 향상된다.

### 3. NoPE-RoPE 하이브리드 위치 인코딩

긴 컨텍스트(long context) 외삽 안정성을 위해, 36개 레이어 중 4의 배수 레이어(4번째, 8번째, ...)는 NoPE(No Positional Encoding)를 사용하고 나머지는 RoPE를 사용한다. NoPE 레이어는 위치 정보를 명시적으로 주입하지 않아 외삽 시 분포 변화에 강건하며, 이는 64K 학습으로도 128K까지 부드럽게 확장 가능한 이유이다.

$$\text{Layer}_l(x) = \begin{cases} \text{Attn}_{\text{NoPE}}(x) & \text{if } l \mod 4 = 0 \\ \text{Attn}_{\text{RoPE}}(x) & \text{otherwise} \end{cases}$$

### 4. 도구 호출 (Tool Calling)

SmolLM3는 XML 기반 도구 호출 형식을 지원한다. SFT 단계에서 ToolACE, xLAM, ApiGen-MT 등의 합성 도구 사용 데이터로 학습되어, MCP(Model Context Protocol) 서버나 외부 API와의 연동이 가능하다. 3B 규모의 모델 중 가장 신뢰성 있는 도구 호출 능력을 보인다.

## 성능 비교

### 동급 SLM 종합 벤치마크

| 모델 | 파라미터 | MMLU | GSM8K | HumanEval | MATH | IFEval |
|------|---------|------|-------|-----------|------|--------|
| **SmolLM3-3B** | 3.08B | 61.2 | 76.8 | 56.7 | 38.4 | 64.1 |
| Llama 3.2 3B | 3.21B | 58.0 | 64.5 | 51.2 | 30.1 | 60.4 |
| Qwen2.5 3B | 3.09B | 65.6 | 79.1 | 61.6 | 42.6 | 58.2 |
| Phi-4-mini 3.8B | 3.84B | 67.3 | 88.6 | 74.4 | 64.0 | 70.1 |
| SmolLM2 1.7B | 1.71B | 50.3 | 31.0 | 23.4 | 11.2 | 38.5 |

SmolLM3는 동일 3B 클래스에서 Llama 3.2 3B를 종합 평균 5-7점 능가하며, Phi-4-mini와의 격차를 큰 폭으로 좁혔다. Phi-4-mini는 비공개 합성 데이터를 다량 사용한 반면 SmolLM3는 학습 데이터까지 모두 공개되었다는 점에서 의의가 있다.

### 다국어 성능 (MMLU 다국어 변형)

| 언어 | SmolLM3-3B | Qwen2.5 3B | Llama 3.2 3B |
|------|-----------|------------|--------------|
| 영어 (English) | 61.2 | 65.6 | 58.0 |
| 프랑스어 (French) | 54.3 | 51.0 | 49.7 |
| 독일어 (German) | 53.8 | 50.4 | 48.2 |
| 스페인어 (Spanish) | 55.1 | 52.8 | 50.1 |
| 이탈리아어 (Italian) | 53.6 | 50.2 | 47.9 |
| 포르투갈어 (Portuguese) | 54.0 | 51.5 | 49.4 |

유럽 6개 언어에서는 SmolLM3가 동급 모델 중 최고 점수를 기록한다. 단, 한국어, 일본어, 중국어 등 비유럽 언어는 학습 데이터에 포함되지 않아 약하다.

## 사용 사례

### 1. 엣지 디바이스 추론 (Edge / On-device)

3B 파라미터를 4bit 양자화(quantization)하면 약 2GB 메모리로 동작하여 노트북, 스마트폰, 라즈베리 파이 5와 같은 엣지 디바이스에서 실시간 추론이 가능하다. llama.cpp, MLX, ONNX Runtime 등 주요 추론 엔진과 호환되어 배포가 용이하다.

### 2. 비용 효율 자동화 파이프라인

GPT-4o-mini, Claude Haiku 대비 자체 호스팅 시 토큰당 비용이 1/10 이하이다. 대량 텍스트 분류, 요약, 데이터 라벨링 등 단순 반복 태스크에 적합하다. 64K 컨텍스트로 긴 문서 처리도 가능하다.

### 3. 온프레미스 챗봇

데이터 보안이 중요한 사내 챗봇, 법률·의료 도메인 AI에서 외부 API 호출 없이 자체 호스팅이 가능하다. Apache 2.0 라이선스로 라이선스 비용도 없다.

### 4. SLM 연구 베이스라인

학습 데이터와 코드가 모두 공개되어 있어, 데이터 큐레이션, 추론 SFT, 양자화, 증류(distillation) 등의 연구에서 통제된 베이스라인으로 활용된다.

### 5. 교육·재현성 연구

대학원, 학부 LLM 강의에서 "처음부터 학습 가능한" 유일한 3B 클래스 모델이다. 256 H100 약 24일이라는 계산 자원이 비교적 합리적이라 일부 연구실에서도 재현 가능하다.

## 한계 및 의의

### 한계

1. **비유럽 언어 약함**: 한국어, 일본어, 중국어, 아랍어 등은 학습 코퍼스에 거의 포함되지 않아 성능이 매우 낮다. 다국어 사용 시 유럽 6개 언어로 제한된다.
2. **순수 추론 능력의 한계**: 3B 규모의 한계로, 복잡한 다단계 추론에서는 7B 이상 모델 대비 명확한 격차가 있다. Phi-4-mini의 GSM8K 88.6%와 비교 시 76.8%로 약 12점 뒤처진다.
3. **코드 생성 한계**: HumanEval 56.7%로 Qwen2.5 3B(61.6%) 대비 약간 낮다. 대규모 합성 코드 데이터 부재의 영향이다.
4. **컨텍스트 외삽 정확도**: 64K 학습이지만 128K 외삽 시 needle-in-haystack 정확도가 약 80%대로 낮아진다.
5. **에이전틱 워크플로 미흡**: 도구 호출은 가능하나, Claude Haiku 수준의 멀티스텝 에이전트 안정성에는 미치지 못한다.

### 의의

SmolLM3는 "재현 가능한 SLM"의 새로운 기준점을 제시하였다. AI 연구의 투명성(transparency)이 점점 중요해지는 가운데, 가중치만이 아닌 데이터·코드·로그까지 공개한 사례로서 OLMo, Pythia와 함께 풀 오픈 LLM의 대표 주자로 자리잡았다.

또한 3B라는 규모에서 64K 컨텍스트, 듀얼 모드 추론, 도구 호출까지 갖춘 점은 "엣지 디바이스에서도 충분히 유용한 AI"의 가능성을 보여준다. 향후 SmolLM4 또는 SmolVLM(비전-언어) 확장이 예상되며, Hugging Face의 풀 오픈 정책은 학계와 산업계 양쪽에서 강력한 영향을 미칠 것이다.

특히 "Mistral Small이 24B인 시대"에 진정한 의미의 소형(small) 모델로서, on-device AI와 프라이버시 우선 AI의 핵심 빌딩 블록 역할을 할 전망이다.
