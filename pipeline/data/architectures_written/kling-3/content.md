# Kling 3: 멀티샷 캐릭터 일관성 비디오 생성

## 개요

Kling 3는 Kuaishou Technology가 개발한 Kling 시리즈의 세 번째 주요 세대로, 멀티샷 시퀀스 생성(multi-shot sequence generation)과 캐릭터 일관성(character consistency) 유지 능력이 이전 세대 대비 크게 향상된 모델이다. 단순한 단일 클립 생성을 넘어 실제 영화·광고 제작에 필요한 샷 연속성을 AI가 자동으로 관리할 수 있게 한다.

- **발표**: 2026년 초, Kuaishou Technology
- **라이선스**: Proprietary

### Kling 2.x 아키텍처 계승

Kling 3는 이전 세대의 핵심 아키텍처를 계승하면서 멀티샷 일관성에 특화된 개선을 추가하였다:

| 구성 요소 | Kling 2.x | Kling 3 |
|----------|----------|---------|
| 백본 | 3D Full Attention DiT | 3D Full Attention DiT (개선) |
| VAE | 3D Causal VAE | 3D Causal VAE |
| 위치 인코딩 | 3D RoPE | 3D RoPE |
| 캐릭터 일관성 | 제한적 | 멀티샷 지원 |
| 장면 연속성 | 단일 클립 | 멀티샷 시퀀스 |
| 어텐션 효율화 | 기본 | 장기 시퀀스 최적화 |

### 멀티샷 캐릭터 일관성 메커니즘

멀티샷 일관성의 핵심은 캐릭터의 시각적 정체성(visual identity)을 추출하고 여러 클립 생성에 재활용하는 것이다:

**추정되는 파이프라인:**

1. 참조 이미지에서 캐릭터 외형 임베딩 추출
2. IP-Adapter 유사 메커니즘으로 각 클립 생성 시 조건으로 주입
3. 서로 다른 앵글, 동작, 장면에서도 동일한 외형 유지

$$z_{\text{identity}} = \text{IdentityEncoder}(x_{\text{ref}})$$
$$\text{DiT}(z_T, c_{\text{text}}, z_{\text{identity}}) \to \text{Video Clip}$$

### 다중 캐릭터 일관성

장면 내 여러 인물이 등장할 때 각 캐릭터의 정체성이 유지되는 기능:

- 캐릭터 A의 참조 이미지 + 캐릭터 B의 참조 이미지
- 두 캐릭터가 상호작용하는 장면에서 각자의 외형 일관성 유지

### 장기 시퀀스 처리

장시간 비디오와 멀티샷 생성을 위한 어텐션 효율화:

- **Sliding Window Attention** 또는 **청크(chunk) 단위 처리**
- 이전 클립의 마지막 프레임 정보를 다음 클립의 조건으로 전달
- 장면 전환(scene transition) 시 자연스러운 연결 생성

## 핵심 혁신

1. **멀티샷 스토리텔링**: 복수의 연속 장면에서 동일 캐릭터의 외형·의상·표정을 일관되게 유지하면서 다양한 앵글과 동작을 표현할 수 있다.
2. **다중 캐릭터 관리**: 여러 인물이 등장하는 복잡한 장면에서 각 캐릭터의 정체성이 혼동되지 않도록 관리한다.
3. **영상 산업 통합**: 전문 영상 제작 워크플로우와의 통합을 위한 API 및 플러그인이 강화되었다.
4. **전반적 품질 향상**: 비디오 길이, 해상도, 스타일 제어 능력이 Kling 2.x 대비 향상되었다.

## 학습 상세

- **아키텍처**: Kling 2.x DiT 기반 개선 (세부 비공개)
- **데이터셋**: Kuaishou 내부 대규모 비디오 데이터 + 전문 제작 영상
- **캐릭터 학습**: 멀티샷 일관성을 위한 별도 캐릭터 참조 학습 단계 포함
- **서비스**: API 및 전문 플러그인 제공

## 실무 활용

### 1. 광고 및 마케팅 비디오 제작

동일 제품이나 브랜드 캐릭터가 여러 장면에 걸쳐 일관되게 등장하는 광고 비디오를 AI로 생성할 수 있다.

### 2. 단편 애니메이션/웹드라마

멀티샷 캐릭터 일관성으로 여러 장면을 연결한 스토리 비디오를 제작할 수 있다. 스토리보드 시각화에서 최종 영상 프로토타이핑까지 활용 가능하다.

### 3. e-commerce 제품 비디오

제품을 다양한 앵글과 환경에서 보여주는 멀티샷 비디오를 자동 생성하여 온라인 쇼핑 경험을 향상시킨다.

## 한계 및 전망

### 한계

1. **비공개 기술**: 아키텍처 세부 사항이 공개되지 않아 학술적 재현이 불가능하다.
2. **프로프라이어터리**: 자체 호스팅이 불가능하다.
3. **오디오 미지원**: Veo 3, Sora 2와 달리 비디오에 오디오가 포함되지 않는다.

### 후속 발전

- **AI 영화 제작**: 더 긴 시퀀스와 더 많은 캐릭터를 지원하는 방향으로 발전 예상
- **오디오-비디오 통합**: Veo 3의 네이티브 오디오 생성 기능과의 경쟁
- **실시간 인터랙티브**: Gen-4.5의 인터랙티브 비디오와 유사한 기능 확장 가능

Kling 3는 멀티샷 캐릭터 일관성이라는 핵심 과제를 실용적 수준으로 해결하여, AI 비디오 생성이 전문 영상 제작 도구로 진화하는 데 기여하였다.

### 기술적 의의

멀티샷 캐릭터 일관성은 AI 비디오 생성이 단편 클립 생성을 넘어 실제 영상 제작 도구가 되기 위한 핵심 과제이다. 기존의 단일 클립 생성은 각 클립마다 캐릭터 외형이 달라지는 문제가 있었으나, Kling 3는 시각적 정체성 임베딩을 통해 이 문제를 해결하였다. 이는 IP-Adapter, Reference-Only 어텐션 등의 이미지 생성 기법을 비디오 영역으로 확장한 것으로 볼 수 있으며, 비디오 생성의 제어 가능성을 크게 향상시킨다. Kling 3의 성공은 Runway Gen-4와 함께 "멀티샷 일관성"이 차세대 비디오 생성 모델의 핵심 경쟁 요소가 됨을 보여주며, 이 기능의 유무가 전문 영상 제작 시장에서의 채택 여부를 결정하는 핵심 기준이 되고 있다.
