# Gemini 3.1 Pro: GPQA 94.3%와 네이티브 멀티모달의 정점

## 개요

Gemini 3.1 Pro는 2026년 Google DeepMind가 공개한 Gemini 3 Pro의 후속 모델로, Google의 최신 플래그십 멀티모달 모델이다. 가장 큰 강점은 **GPQA Diamond 94.3%**(업계 1위)를 비롯한 과학적 추론 능력과, 처음부터 텍스트, 이미지, 비디오, 오디오를 단일 모델에서 네이티브로 처리하는 멀티모달 통합 설계이다.

SWE-bench Verified **78.80%**로 코딩 분야에서도 최상위권을 유지하며, Artificial Analysis Intelligence Index **57점**으로 Claude Opus 4.7, GPT-5.5와 함께 공동 1위에 올랐다. 학습 인프라는 Google의 7세대 **Ironwood TPU 클러스터** 기반으로, NVIDIA GPU 의존도 없이 자체 가속기로 프런티어급 모델 학습을 수행하는 대표 사례이다.

## 아키텍처 상세

### 기본 구조

| 구성 요소 | 사양 |
|-----------|------|
| **아키텍처** | MoE Decoder-only Transformer (추정) |
| **어텐션** | Grouped-Query Attention (GQA) |
| **정규화** | RMSNorm |
| **활성화 함수** | SwiGLU |
| **위치 인코딩** | RoPE |
| **컨텍스트 길이** | 1M 토큰 |
| **모달리티** | 텍스트, 이미지, 비디오, 오디오 (네이티브) |
| **학습 인프라** | Google 7세대 Ironwood TPU |
| **파라미터 수** | 미공개 |

세부 스펙은 비공개이지만, Pro 변형은 Ultra와 Flash 사이에서 균형 잡힌 성능과 비용을 제공한다.

### 네이티브 멀티모달 설계

Gemini의 가장 큰 차별점은 1세대부터 멀티모달 네이티브 설계를 채택해온 점이다. 모든 모달리티가 단일 토큰 시퀀스로 변환되어 동일 트랜스포머에서 처리된다.

- **이미지**: ViT 기반 패치 인코더로 토큰화
- **비디오**: 프레임 샘플링 + 시간적 축약 + 패치 토큰화
- **오디오**: 멜스펙트로그램 → 오디오 토큰
- **텍스트**: SentencePiece 토큰

이러한 통합 설계는 모달리티 간 교차 추론(cross-modal reasoning)에 자연스러운 강점을 제공한다.

### Ironwood TPU와 Pathways

Google의 7세대 Ironwood TPU는 BF16 기준 압도적인 처리량과 HBM 대역폭을 제공한다. JAX와 Pathways 라이브러리 결합으로 단일 모델을 다수의 TPU pod에 분산시키면서도 단일 프로그램으로 표현이 가능하다.

```python
import jax
mesh = jax.sharding.Mesh(devices, ('data', 'model'))
```

이러한 추상화는 학습 코드의 단순성과 효율성을 동시에 확보하며, NVIDIA GPU + Megatron 조합과 비교 시 학습 인프라 비용 우위를 가져온다.

## 핵심 혁신

### 1. 과학적 추론의 압도적 성능

GPQA Diamond에서 **94.3%**를 기록하여 업계 1위에 올랐다. 이는 박사급 과학자의 평가(약 65%)를 크게 상회하며, Claude Opus 4.7(약 90%), GPT-5.5(약 88%)를 모두 앞서는 수치이다.

GPQA는 박사 학위 보유자가 검수한 물리, 화학, 생물 분야의 어려운 문제로 구성되며, 단순 검색이 아닌 깊이 있는 도메인 지식과 논리적 추론을 요구한다. 이 영역에서의 1위는 Google DeepMind의 과학 분야 강점(AlphaFold, AlphaProof 계열)과 일관된 결과로 평가된다.

### 2. 멀티모달 네이티브의 정교화

3.1 세대에서는 모달리티 간 교차 추론이 한층 강화되었다. 비디오 프레임 시퀀스 + 오디오 트랙 + 화면 텍스트를 통합 분석하는 시나리오에서 다음과 같은 우위를 보인다.

- 회의 비디오 + 음성 + 화면 공유에서 결정사항 추출
- 의료 영상(CT/MRI) + 환자 기록의 통합 판독
- 스포츠 경기 비디오 + 해설 음성의 자동 분석
- 교육 콘텐츠의 자동 요약 + 다국어 자막 생성

### 3. 1M 컨텍스트와 멀티모달 결합

1M 토큰 컨텍스트는 단순히 텍스트만 담는 것이 아니라, 이미지/비디오/오디오 토큰까지 포함할 수 있다. 1시간 분량의 비디오는 약 100만 토큰 수준이므로, 단일 프롬프트에서 영화 한 편을 전체 분석할 수 있게 된다.

장문 처리에는 Ring Attention, FlashAttention 등 메모리 효율 기법이 결합된 것으로 추정된다.

$$\text{Attn}(Q, K, V) = \text{softmax}\left(\frac{QK^\top}{\sqrt{d_k}}\right)V$$

장문에서는 위 연산을 블록 단위로 분할하여 GPU/TPU 메모리에 들어가도록 한다.

## 한계 및 의의

### 한계

1. **코딩 성능 격차**: SWE-bench 78.80%는 우수하지만, Claude Opus 4.7(82.0%)이나 GPT-5.5(80.2%)에는 다소 밀린다.
2. **API 가격 변동**: Pro 가격이 시점에 따라 조정되며, 동일 모델 내 입력 토큰 길이별 차등 가격(예: 200K 초과 시 인상)이 적용된다.
3. **비공개 스펙**: 파라미터 수, 활성 파라미터, 전문가 수 등이 비공개이다.
4. **TPU 의존 인프라**: 외부 개발자 입장에서는 자체 환경 재현이 사실상 불가능하다.

### 의의

Gemini 3.1 Pro는 **과학적 추론 1위**, **네이티브 멀티모달의 정교화**, **자체 인프라(TPU)의 경쟁력 입증**이라는 세 가지 의미를 지닌다. 첫째, GPQA 94.3%는 일반 LLM이 박사급 전문가 수준의 과학 문제 해결 능력에 도달했음을 보여주는 이정표이다. 둘째, 비디오/오디오까지 포함한 1M 컨텍스트 활용은 콘텐츠 산업과 의료 영상 분야에서 새로운 응용을 열어준다. 셋째, NVIDIA GPU 없이 Ironwood TPU만으로 프런티어급 모델을 학습하는 능력은 Google의 인프라 전략의 정당성을 입증한다.

향후 Gemini 4 세대에서는 Computer Use 통합, 추론 시간 스케일링 강화, 그리고 Gemini Ultra 변형의 부활이 핵심 방향이 될 것으로 전망된다.
