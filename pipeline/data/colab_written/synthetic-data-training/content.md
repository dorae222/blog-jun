# 합성 데이터로 학습하기: 효과적인 경우와 한계

## 들어가며

LLM 학습에서 가장 비싼 자원은 무엇인가? GPU 시간도 중요하지만, 진정한 병목은 **고품질 학습 데이터**다. 인간이 작성한 고품질 데이터는 한정되어 있고, 수집 비용이 높다.

**합성 데이터(Synthetic Data)**는 이 문제에 대한 해법이다: 대형 모델(GPT-4, Claude 등)을 사용하여 학습용 데이터를 **자동 생성**하는 것이다. Microsoft Phi 시리즈의 "Textbooks Are All You Need", Meta의 Self-Instruct, [[openthoughts3-dataset|OpenThoughts3]]의 추론 데이터 등이 이 패러다임의 대표적 성공 사례다.

그러나 합성 데이터는 **만능이 아니다**. 언제 효과적이고 언제 실패하는지 이해하는 것이 핵심이다.

---

## 합성 데이터의 유형

### 1. 교과서 품질 텍스트 (Textbook-Quality)

Microsoft Phi 시리즈의 접근법. GPT-4에게 **특정 주제에 대한 교과서 수준의 설명**을 생성시킨다.

```
프롬프트: "Python의 리스트 컴프리헨션을 초보자에게 설명하는
교과서 한 챕터를 작성하라. 개념 설명, 예제, 연습 문제를 포함하라."

→ GPT-4가 구조화된 교육 콘텐츠 생성
→ Phi-1/2/3 학습에 활용
```

핵심은 **단순한 텍스트가 아니라 "교육적 구조"**를 갖춘 데이터라는 점이다. 설명 → 예제 → 점진적 복잡도 증가의 패턴이 학습 효율을 크게 높인다.

### 2. 추론 체인 (Reasoning Chains)

[[openthoughts3-dataset|OpenThoughts3]]의 접근법. 수학/과학/코드 문제에 대해 **긴 추론 과정(Chain-of-Thought)**을 포함한 풀이를 생성한다.

```
질문: "f(x) = x³ - 3x² + 2에서 극값을 구하라"

합성 풀이:
<think>
먼저 f'(x)를 구한다. f'(x) = 3x² - 6x.
f'(x) = 0이면 3x(x-2) = 0, x = 0 또는 x = 2.
f''(x) = 6x - 6.
f''(0) = -6 < 0이므로 x=0에서 극대.
f''(2) = 6 > 0이므로 x=2에서 극소.
f(0) = 2, f(2) = -2.
</think>

극대: (0, 2), 극소: (2, -2)
```

이 데이터로 학습한 소형 모델은 **추론 과정을 모방**하여, 스스로 단계적 추론을 생성할 수 있게 된다.

### 3. 지시 따르기 데이터 (Instruction-Following)

Self-Instruct(Wang et al., 2023)의 접근법. 소수의 시드 지시-응답 쌍에서 출발하여, LLM이 **새로운 지시와 응답을 자동 생성**한다.

- **Alpaca**: 175개 시드 → GPT-3.5로 52K 지시-응답 쌍 생성 → LLaMA-7B 파인튜닝
- **Evol-Instruct** (WizardLM): 기존 지시를 점진적으로 복잡하게 변형

### 4. 선호도 데이터 (Preference Data)

RLHF/DPO 학습을 위한 (chosen, rejected) 쌍을 합성한다:

- 같은 질문에 여러 응답 생성 → 품질 기준으로 선별
- [[deepseek-r1|DeepSeek-R1]]의 rejection sampling: RL 모델이 생성한 답변 중 정답만 선별

## 합성 데이터가 효과적인 경우

### 1. 검증 가능한 도메인

수학, 코드, 논리 퍼즐 등 **정답이 명확한** 분야에서 합성 데이터가 가장 효과적이다. 이유는 간단하다: 생성된 데이터의 **품질을 자동으로 검증**할 수 있기 때문이다.

```
합성 수학 풀이 → 정답 검증 → 정답인 것만 학습 데이터로 사용
합성 코드 → 테스트 케이스 실행 → 통과하는 것만 사용
```

[[openthoughts3-dataset|OpenThoughts3]]가 이 전략의 대표적 성공 사례다. 32개 소스에서 추출한 문제에 대해 추론 모델이 풀이를 생성하고, 정답인 풀이만 선별하여 1.2M개의 고품질 추론 데이터를 구축했다.

### 2. 포맷/스타일 학습

모델에게 **특정 출력 형식을 따르도록** 가르칠 때 합성 데이터가 효과적이다:

- JSON 형식의 구조화된 출력
- 특정 톤이나 길이의 응답
- `<think>...</think>` 형식의 추론 블록

이런 형식적 요구사항은 적은 양의 합성 데이터로도 빠르게 학습된다. LIMA의 **표면적 정렬 가설(Superficial Alignment Hypothesis)**이 이를 뒷받침한다: 형식과 스타일은 소량의 데이터로 충분히 학습되며, 핵심 지식은 사전학습에서 이미 습득되어 있다.

### 3. 증류 (Knowledge Distillation)

대형 모델 → 소형 모델로의 [[distillation-guide|증류]]는 본질적으로 합성 데이터 학습이다. 교사 모델이 생성한 응답을 학생 모델의 학습 데이터로 사용하는 것이다.

[[deepseek-r1|DeepSeek-R1]]의 증류 실험이 이를 잘 보여준다: 동일 크기의 모델에서 **직접 RL보다 R1 증류가 더 높은 성능**을 달성했다.

## 합성 데이터의 한계와 위험

### 1. 모델 붕괴 (Model Collapse)

합성 데이터의 가장 심각한 위험은 **모델 붕괴**다(Shumailov et al., 2024). 모델 A가 생성한 데이터로 모델 B를 학습하고, B의 데이터로 C를 학습하면... 세대를 거듭할수록 **다양성이 줄어들고 편향이 증폭**된다.

이유:
- 생성 모델은 확률이 높은 출력에 편향됨 → 롱테일 지식이 소실
- 각 세대에서 오류가 누적됨
- 결국 모든 출력이 비슷한 패턴으로 수렴

:::warning
**핵심 규칙**: 합성 데이터는 반드시 **원본 인간 데이터와 혼합**하여 사용해야 한다. 순수 합성 데이터만으로 학습하면 모델 붕괴 위험이 높다.
:::

### 2. 교사의 편향 상속

합성 데이터를 생성하는 교사 모델의 **편향, 오류, 스타일 quirk**가 그대로 학생 모델에 전이된다.

- GPT-4의 특유한 문체(과도한 리스트 사용, 특정 관용구)
- 교사 모델이 약한 분야의 오류가 학생에게도 반복
- 문화적/언어적 편향의 증폭

### 3. 다양성 부족

합성 데이터는 인간 생성 데이터에 비해 **다양성이 낮다**. 같은 모델이 같은 프롬프트로 생성한 데이터는 구조적으로 유사한 패턴을 반복한다.

해결 전략:
- **다양한 교사 모델** 사용 (GPT-4 + Claude + Gemini)
- **온도(temperature) 다양화**
- [[openthoughts3-dataset|OpenThoughts3]]의 접근: 32개 다른 소스에서 문제를 추출하여 다양성 확보

### 4. 법적/윤리적 문제

상용 API(GPT-4, Claude)의 출력을 경쟁 모델의 학습에 사용하는 것은 서비스 약관 위반일 수 있다. Phi 시리즈는 Microsoft 내부 모델을 사용하여 이 문제를 회피했고, 오픈소스 진영에서는 오픈 모델(Mixtral, LLaMA 등)로 생성한 데이터를 사용하는 추세다.

## 실전 가이드라인

### 합성 데이터 생성 시 체크리스트

1. **검증 메커니즘 확보**: 생성된 데이터의 품질을 자동으로 평가할 수 있는가?
2. **다양성 확보**: 프롬프트, 교사 모델, 온도를 다양화했는가?
3. **인간 데이터 혼합**: 합성 데이터와 인간 데이터의 적절한 비율을 설정했는가?
4. **편향 검사**: 교사 모델의 편향이 증폭되지 않았는가?
5. **라이선스 확인**: 교사 모델의 출력을 학습에 사용할 수 있는가?

### 효과적인 비율

연구에 따르면 **합성 데이터 70~80% + 인간 데이터 20~30%** 혼합이 효과적인 경우가 많다. 다만 이 비율은 도메인과 과제에 따라 크게 달라진다.

## 정리

| 효과적인 경우 | 주의가 필요한 경우 |
|--------------|------------------|
| 수학/코드 (정답 검증 가능) | 개방형 텍스트 생성 |
| 포맷/스타일 학습 | 사실 기반 지식 학습 |
| 증류 (교사→학생) | 다세대 재학습 (모델 붕괴) |
| 소량 인간 데이터 보강 | 순수 합성 데이터만 사용 |

합성 데이터는 **도구**다. 올바른 조건에서 올바른 방법으로 사용하면 학습 효율을 극적으로 높이지만, 맹목적으로 사용하면 모델 품질을 오히려 악화시킨다. **데이터 품질에 대한 감각**이 합성 데이터 활용의 핵심 역량이다.
