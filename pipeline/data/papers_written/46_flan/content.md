## 개요

GPT-3(Brown et al., 2020)의 등장은 대규모 언어 모델(LLM)이 소수의 예시만으로 새로운 태스크를 수행할 수 있다는 가능성을 보여주었습니다. 그러나 이러한 퓨샷(few-shot) 학습 능력에도 불구하고, 예시 없이 자연어 지시만으로 태스크를 수행하는 제로샷(zero-shot) 설정에서는 성능이 크게 떨어지는 한계가 있었습니다. 제로샷 성능의 저하는 사전 학습(pretraining) 과정에서 모델이 "지시를 따르는" 형식의 데이터를 충분히 경험하지 못했기 때문으로 분석됩니다.

Wei et al.(2021)은 이 문제를 근본적으로 해결하기 위해 **지시 기반 파인튜닝(instruction tuning)**이라는 새로운 패러다임을 제안합니다. 핵심 아이디어는 명확합니다. 다양한 NLP 태스크를 자연어 지시(instruction) 형태로 재구성한 뒤, 이 지시들을 따르도록 대규모 언어 모델을 파인튜닝하면 보이지 않은(unseen) 태스크에 대해서도 우수한 제로샷 일반화 능력을 획득할 수 있다는 것입니다. 이렇게 학습된 모델을 저자들은 **FLAN(Finetuned LAnguage Net)**이라 명명했으며, 이 연구는 ICLR 2022에서 발표되었습니다.

FLAN은 62개의 공개 NLP 데이터셋을 12개의 태스크 클러스터로 분류하고, 각 데이터셋에 대해 수작업으로 10개의 자연어 지시 템플릿을 작성하여 Google의 LaMDA-PT(137B 파라미터) 모델을 파인튜닝했습니다. 결과적으로 25개 평가 데이터셋 중 20개에서 GPT-3(175B)의 퓨샷 성능을 제로샷만으로 능가하는 놀라운 결과를 달성했습니다. 이후 FLAN은 FLAN-T5, FLAN-PaLM, FLAN-UL2 등으로 이어지는 중요한 연구 계보를 형성했으며, 오늘날 instruction tuning 패러다임의 시발점으로 널리 인정받고 있습니다.

## 배경 및 문제

### 사전 학습과 제로샷 학습의 간극

대규모 언어 모델의 사전 학습 목표는 다음 토큰 예측(next token prediction)입니다. 대규모 텍스트 코퍼스에서 이전 토큰들이 주어졌을 때 다음 토큰의 확률을 최대화하는 방식으로 학습합니다.

$$\mathcal{L}_{\text{pretrain}} = -\sum_{t=1}^{T} \log P(x_t \mid x_1, x_2, \ldots, x_{t-1}; \theta)$$

여기서 $x_t$는 $t$번째 토큰, $\theta$는 모델 파라미터입니다. 이 학습 방식은 언어의 일반적인 패턴과 지식을 효과적으로 포착하지만, 특정 태스크에 대한 "지시를 따르는" 능력을 직접적으로 학습하지는 않습니다.

GPT-3는 이 문제를 퓨샷 프롬프팅(few-shot prompting)으로 우회했습니다. 입력에 몇 개의 예시(demonstration)를 함께 제공하면 모델이 문맥 내 학습(in-context learning)을 통해 태스크를 파악합니다. 그러나 제로샷 설정에서는 이러한 예시가 없으므로, 모델은 오직 자연어 지시만으로 태스크의 의도를 이해해야 합니다. 사전 학습 데이터에 이러한 형식의 텍스트가 부족하기 때문에 제로샷 성능은 퓨샷 성능에 비해 크게 뒤처지게 됩니다.

### 기존 접근법의 한계

FLAN 이전에도 자연어 지시를 활용한 연구들이 있었습니다. NATML(McCann et al., 2018)은 10개의 NLP 태스크를 질의응답 형식으로 통합했으며, T0(Sanh et al., 2021)는 유사한 아이디어를 T5 모델에 적용했습니다. 그러나 이들 연구는 태스크의 다양성이 제한적이거나, 대규모 모델에서의 체계적 분석이 부족했습니다.

FLAN은 다음 세 가지 측면에서 기존 연구를 넘어섭니다.

1. **규모**: 62개 데이터셋, 12개 태스크 클러스터로 가장 광범위한 지시 파인튜닝 수행
2. **체계적 분석**: 모델 규모, 태스크 수, 템플릿 다양성 등 instruction tuning의 작동 조건을 종합적으로 규명
3. **엄밀한 제로샷 평가**: 평가 태스크와 동일한 클러스터의 데이터를 학습에서 완전히 제외하여 진정한 제로샷 일반화를 검증

## 핵심 아이디어

FLAN의 핵심 가설은 다음과 같이 요약됩니다.

> 충분히 다양한 NLP 태스크를 자연어 지시 형태로 변환하여 대규모 언어 모델을 파인튜닝하면, 학습 과정에서 한 번도 보지 못한 새로운 태스크에 대해서도 우수한 제로샷 성능을 달성할 수 있다.

이 가설은 두 가지 직관에 기반합니다. 첫째, 다양한 태스크의 지시를 따르는 경험을 통해 모델이 "지시 따르기"라는 메타 능력(meta-capability)을 획득한다는 것입니다. 둘째, 충분히 많은 종류의 태스크를 경험하면 새로운 태스크도 기존에 학습한 태스크들의 조합으로 해석할 수 있다는 것입니다.

이를 좀 더 형식적으로 표현하면, 태스크 공간 $\mathcal{T}$에서 학습 태스크 집합 $\mathcal{T}_{\text{train}} \subset \mathcal{T}$에 대해 instruction tuning을 수행했을 때, 새로운 태스크 $t \in \mathcal{T} \setminus \mathcal{T}_{\text{train}}$에 대한 제로샷 성능 $P_{\text{zero}}(t)$가 향상됩니다.

$$P_{\text{zero}}(t) \propto |\mathcal{T}_{\text{train}}| \cdot \text{diversity}(\mathcal{T}_{\text{train}}) \cdot \mathbb{1}[N > N_{\text{threshold}}]$$

여기서 $N$은 모델 파라미터 수, $N_{\text{threshold}}$는 instruction tuning이 효과를 발휘하기 시작하는 임계 규모입니다. 즉, instruction tuning의 효과는 학습 태스크의 수와 다양성, 그리고 모델 규모에 동시에 의존합니다.

### 지시 템플릿 설계

각 데이터셋에 대해 연구진은 수작업으로 10개의 서로 다른 자연어 지시 템플릿을 작성했습니다. 이러한 다양한 템플릿은 모델이 특정 문구에 과적합하지 않고 지시의 의도 자체를 학습하도록 유도합니다. 아래 그림은 자연어 추론(NLI) 태스크에 대한 실제 템플릿 예시를 보여줍니다.

![자연어 추론 태스크에 대한 다양한 지시 템플릿 예시](figures/fig_4.png)
*Figure 4: 자연어 추론 태스크에 대한 복수의 지시 템플릿 예시. 동일한 전제-가설 쌍을 다양한 자연어 표현으로 제시하여 모델이 특정 문구가 아닌 태스크의 본질적 구조를 학습하도록 유도한다. (Wei et al., 2021)*

위 그림에서 볼 수 있듯이, 동일한 NLI 인스턴스가 "Does this imply...", "Can we infer...", "Is it true that..." 등 여러 방식으로 표현됩니다. 구체적으로 다음과 같은 형식이 사용됩니다.

**템플릿 A (직접 질의형):**
```
전제: {premise}
가설: {hypothesis}
이 가설은 전제로부터 참, 거짓, 또는 판단 불가 중 무엇입니까?
```

**템플릿 B (함의 판단형):**
```
"{premise}"가 참이라면, "{hypothesis}"도 반드시 참입니까?
예 / 아니오 / 판단 불가로 답하세요.
```

**템플릿 C (역방향 추론형):**
```
"{hypothesis}"라는 문장을 읽었습니다.
이 문장이 참이 되려면 "{premise}"가 참이어야 합니까?
```

동일한 데이터 인스턴스를 다양한 방식으로 표현함으로써, 모델은 표면적 패턴이 아닌 태스크의 본질적 구조를 학습하게 됩니다. 또한 일부 템플릿은 의도적으로 옵션(options) 포함 여부를 달리하여, 분류형 태스크에서도 자유 생성과 보기 선택 모두에 대응할 수 있도록 설계했습니다.

### 학습 설정

FLAN은 Google의 **LaMDA-PT(137B 파라미터)** 모델을 기반으로 합니다. LaMDA-PT는 대화 데이터를 포함하지 않은 순수 언어 모델로, 웹 문서와 대화 데이터를 포함한 2.49T 토큰의 코퍼스로 사전 학습되었습니다.

instruction tuning 과정의 핵심 수학적 구조는 다음과 같습니다. 평가 대상 태스크 클러스터를 $c$라 하면, 학습 데이터는 해당 클러스터를 제외한 모든 데이터로 구성됩니다.

$$\mathcal{D}_{\text{train}} = \{(p_k(x_i), y_i) : \text{cluster}(x_i) \neq c, \; k \sim \text{Uniform}(1, K)\}$$

여기서 $x_i$는 원본 데이터 인스턴스, $y_i$는 정답, $p_k$는 $K$개의 템플릿 중 $k$번째 템플릿, $c$는 평가 대상 클러스터입니다. 학습 시 각 인스턴스에 대해 템플릿을 무작위로 선택하여 적용합니다.

학습 목표는 표준 조건부 언어 모델링 손실(conditional language modeling loss)입니다.

$$\mathcal{L}(\theta) = -\sum_{(x, y) \in \mathcal{D}_{\text{train}}} \sum_{t=1}^{|y|} \log P_{\theta}(y_t \mid p_k(x), y_1, \ldots, y_{t-1})$$

여기서 $\theta$는 모델 파라미터, $p_k(x)$는 입력 $x$에 템플릿 $p_k$를 적용한 지시문, $y_t$는 출력 시퀀스의 $t$번째 토큰입니다. 주의할 점은 손실이 오직 출력 부분($y$)에 대해서만 계산되며, 입력 지시문 부분은 손실 계산에서 제외된다는 것입니다.

주요 하이퍼파라미터는 다음과 같습니다.

| 하이퍼파라미터 | 값 |
|---------------|----|
| 기본 모델 | LaMDA-PT 137B |
| 학습률 (Learning Rate) | $3 \times 10^{-5}$ |
| 배치 크기 | 8,192 토큰 |
| 학습 에폭 | 30K 스텝 (약 2 에폭) |
| 입력 최대 길이 | 1,024 토큰 |
| 출력 최대 길이 | 256 토큰 |
| 옵티마이저 | Adafactor |
| 데이터 혼합 비율 | 균등 혼합 (데이터셋 크기 무관) |

특히 데이터 혼합 비율에서 각 데이터셋의 기여를 균등하게 유지하여, 규모가 큰 데이터셋이 학습을 지배하지 않도록 설계한 점이 주목할 만합니다.

### 평가 프로토콜

제로샷 평가 시, FLAN은 오직 자연어 지시만 제공받고 어떠한 예시(demonstration)도 받지 않습니다. 평가는 크게 두 가지 방식으로 수행됩니다.

1. **랭킹 분류(Rank Classification)**: 가능한 출력 후보들 중 로그 확률이 가장 높은 것을 선택합니다. 후보 $c_j$에 대해 정규화된 로그 확률을 계산합니다.

$$\text{score}(c_j) = \frac{1}{|c_j|} \sum_{t=1}^{|c_j|} \log P(c_{j,t} \mid \text{instruction}, c_{j,<t})$$

여기서 길이 정규화($1/|c_j|$)를 통해 짧은 후보가 부당하게 유리해지는 것을 방지합니다.

2. **자유 생성(Open-ended Generation)**: 요약, 번역 등 생성 태스크에서 모델이 자유롭게 출력을 생성하며, BLEU, ROUGE 등의 지표로 평가합니다.

### 절제 실험: 자연어 지시의 핵심 역할

FLAN의 성능 향상이 정말로 "자연어 지시" 덕분인지를 검증하기 위해, 저자들은 지시를 제거한 파인튜닝과의 절제 실험(ablation study)을 수행했습니다.

![파인튜닝 시 지시 포함 여부에 따른 제로샷 성능 절제 실험](figures/fig_8.png)
*Figure 8: 파인튜닝에서 지시를 제거한 모델과의 절제 실험. 지시 없이 파인튜닝한 모델(37.3)은 데이터셋 이름만 사용한 모델(46.6~47.0)보다도 낮으며, 자연어 지시를 포함한 FLAN(55.2)이 가장 높은 제로샷 성능을 달성한다. (Wei et al., 2021)*

이 결과는 단순히 다양한 데이터셋에 노출되는 것만으로는 충분하지 않으며, 자연어 형태의 지시가 제로샷 일반화의 핵심 요인임을 명확히 입증합니다. 지시 없이 파인튜닝한 모델(37.3)은 오히려 기본 모델보다 성능이 낮았고, 데이터셋 이름만 제공한 경우(46.6~47.0)에도 FLAN(55.2)에 크게 미치지 못했습니다.

### 기본 모델 대비 향상

instruction tuning이 기본 모델(LaMDA-PT) 대비 얼마나 향상을 가져오는지를 분석한 결과도 매우 인상적입니다. LaMDA-PT 137B의 제로샷 성능 대비 FLAN의 제로샷 성능을 비교하면, 대부분의 태스크 클러스터에서 큰 폭의 향상이 관찰됩니다.

$$\Delta_{\text{IT}} = \text{Acc}_{\text{FLAN}} - \text{Acc}_{\text{LaMDA-PT}}$$

평균적으로 $\Delta_{\text{IT}} \approx +14.7$이며, NLI 클러스터에서는 $\Delta_{\text{IT}} \approx +29.8$에 달합니다.

### 모델 규모의 임계 효과

FLAN 연구의 가장 중요한 발견 중 하나는 instruction tuning의 효과가 모델 규모에 따라 비선형적으로 변한다는 것입니다. 저자들은 422M, 2B, 8B, 68B, 137B 등 다양한 규모의 모델에 동일한 instruction tuning을 적용하여 비교했습니다. 아래 그림은 이 임계 효과를 시각적으로 보여줍니다. 소규모 모델에서는 instruction tuning이 오히려 성능을 저하시키지만, 일정 규모 이상에서는 극적인 향상을 가져옵니다.

![모델 규모에 따른 인스트럭션 튜닝 효과의 비선형적 변화](figures/fig_7.png)
*Figure 7: 인스트럭션 튜닝은 대규모 모델(68B 이상)에서만 제로샷 일반화를 향상시키며, 소규모 모델에서는 오히려 성능을 저하시킨다. 이는 소규모 모델의 용량이 다양한 태스크 지시를 동시에 학습하기에 부족하기 때문으로 분석된다. (Wei et al., 2021)*

| 모델 규모 | Instruction Tuning 전 | Instruction Tuning 후 | 효과 |
|-----------|----------------------|----------------------|------|
| 422M | 49.2 | 45.1 | -4.1 (악화) |
| 2B | 52.8 | 50.3 | -2.5 (악화) |
| 8B | 55.1 | 53.7 | -1.4 (미미한 악화) |
| 68B | 58.4 | 65.8 | +7.4 (개선) |
| 137B | 60.3 | 75.2 | +14.9 (대폭 개선) |

이 결과는 매우 중요한 시사점을 제공합니다.

- **8B 이하**: instruction tuning이 오히려 성능을 저하시킵니다. 이는 소규모 모델이 다양한 태스크의 지시를 동시에 학습하기에는 용량(capacity)이 부족하기 때문으로 해석됩니다.
- **68B**: instruction tuning의 효과가 처음으로 양의 방향으로 전환됩니다.
- **137B**: 가장 큰 향상이 관찰되며, instruction tuning의 효과가 모델 규모에 대해 초선형적(super-linear)으로 증가합니다.

이러한 임계 효과를 수학적으로 모델링하면 다음과 같이 표현할 수 있습니다.

$$\Delta(N) = \alpha \cdot \log(N / N_0)$$

여기서 $N$은 모델 파라미터 수, $N_0 \approx 10^{10}$ (약 10B)은 임계점, $\alpha$는 태스크 의존적 상수입니다. $N < N_0$일 때 $\Delta < 0$이 되어 instruction tuning이 오히려 해로워지며, $N > N_0$에서만 긍정적 효과가 나타납니다.

### 태스크 수와 다양성의 효과

저자들은 학습에 사용하는 태스크 클러스터의 수를 체계적으로 변화시키며 제로샷 성능을 측정했습니다. 아래 그림은 학습 클러스터 수가 증가할수록 홀드아웃 클러스터에 대한 제로샷 성능이 단조 증가하는 패턴을 명확히 보여줍니다.

![학습 태스크 클러스터 수에 따른 제로샷 성능 변화](figures/fig_6.png)

### 지시 템플릿 수의 영향

각 데이터셋당 사용하는 템플릿 수의 영향도 분석했습니다. 아래 그림은 클러스터당 데이터셋 수와 데이터셋당 템플릿 수가 성능에 미치는 영향을 비교한 결과입니다.

![클러스터당 데이터셋 수와 데이터셋당 템플릿 수가 제로샷 성능에 미치는 영향 비교](figures/fig_11.png)
*Figure 11: 클러스터당 데이터셋 수를 1개에서 4개로 늘리면 성능이 약 9%p 향상되지만(빨간 선), 데이터셋당 템플릿 수를 1개에서 10개로 늘려도 성능 향상은 미미하다(파란 선). 데이터셋 다양성이 템플릿 다양성보다 더 중요한 요인임을 보여준다. (Wei et al., 2021)*

흥미로운 점은 두 요인의 영향력 차이입니다. 클러스터당 데이터셋 수를 늘리는 것이 성능에 압도적으로 더 큰 영향을 미치며, 템플릿 수의 효과는 상대적으로 미미합니다. 다만 템플릿이 1개인 경우 대비 4개 이상의 템플릿을 사용하면 제로샷 성능이 유의미하게 향상됩니다.

$$\text{Acc}(K=10) - \text{Acc}(K=1) \approx +4.2$$

여기서 $K$는 데이터셋당 템플릿 수입니다. $K > 4$ 이후에는 수확 체감(diminishing returns)이 관찰되며, 충분한 데이터셋이 확보된 경우 템플릿 수의 효과는 거의 사라집니다.

### 분류 vs. 생성 포맷

저자들은 태스크의 출력 형식이 성능에 미치는 영향도 조사했습니다. 분류형 태스크(NLI, 감성 분석 등)에서 모델에게 "Yes/No" 등 고정 레이블 중 하나를 선택하도록 하는 방식과, 자유 형식으로 생성하도록 하는 방식을 비교한 결과, 분류형 출력이 약 $+2\sim5$% 높은 성능을 보였습니다. 이는 탐색 공간의 축소가 모델의 정확한 응답 생성에 도움이 됨을 시사합니다.

### 퓨샷 예시와의 보완 효과

FLAN은 제로샷 추론을 위해 설계되었지만, 퓨샷 예시를 추가하면 성능을 더욱 향상시킬 수 있습니다. 아래 그림은 제로샷 FLAN과 퓨샷 FLAN의 태스크 클러스터별 성능을 비교한 결과입니다.

![제로샷 FLAN과 퓨샷 FLAN의 태스크 클러스터별 성능 비교](figures/fig_9.png)
*Figure 9: 퓨샷 예시를 추가하면 인스트럭션 튜닝된 모델의 성능이 보완적으로 향상된다. 특히 번역(+2.0)과 구조-텍스트 변환(+10.2)에서 큰 향상이 관찰되며, 오렌지 막대는 템플릿 간 표준편차를 나타낸다. (Wei et al., 2021)*

이 결과는 인스트럭션 튜닝과 퓨샷 학습이 상호 배타적이 아닌 보완적 관계임을 보여줍니다. 인스트럭션 튜닝으로 "지시 따르기" 능력을 획득한 뒤, 퓨샷 예시를 통해 태스크의 구체적 형식을 추가로 명시하면 성능이 더욱 향상됩니다.

## 의의 및 한계

### 학술적 의의

**Instruction Tuning 패러다임의 확립.** FLAN은 "다양한 태스크를 자연어 지시로 표현하고, 이 지시를 따르도록 학습시키면 보이지 않은 태스크에도 일반화 가능하다"는 패러다임을 최초로 대규모로 검증한 연구입니다. 이 패러다임은 이후 NLP 분야의 지배적인 학습 방법론이 되었습니다.

**InstructGPT/ChatGPT의 이론적 기반.** OpenAI의 InstructGPT(Ouyang et al., 2022)와 ChatGPT는 FLAN의 instruction tuning 아이디어를 RLHF(Reinforcement Learning from Human Feedback)와 결합한 것으로 볼 수 있습니다. FLAN이 instruction tuning의 효과를 입증함으로써, 이후 인간 피드백을 추가하는 방향으로의 자연스러운 발전이 가능해졌습니다.

**효율적 규모 확장의 가능성.** 137B FLAN이 175B GPT-3를 능가한다는 결과는, 단순한 파라미터 수 증가보다 학습 방법론의 혁신이 더 효율적인 성능 향상 수단임을 실증했습니다. 이는 이후 Chinchilla(Hoffmann et al., 2022)의 compute-optimal scaling 연구와도 맥을 같이합니다.

**후속 연구 생태계의 형성.** FLAN 방법론은 FLAN-T5, FLAN-PaLM, FLAN-UL2로 직접 확장되었으며, 오픈소스 생태계에서도 Alpaca(Stanford), Vicuna(LMSYS), Dolly(Databricks) 등 수많은 instruction tuning 연구의 토대가 되었습니다.

### FLAN-T5와 이후 발전

원래 FLAN은 비공개 모델인 LaMDA-PT를 사용했지만, 이후 Google은 T5 모델 계열에 동일한 instruction tuning을 적용한 **FLAN-T5**(Chung et al., 2022)를 발표하여 한계를 크게 보완했습니다. FLAN-T5는 다음과 같은 특징을 가집니다.

- **오픈소스 공개**: 누구나 접근 가능한 공개 모델로 제공
- **대폭 확장된 학습 데이터**: 1,800개 이상의 태스크와 수천 개의 프롬프트 템플릿
- **Chain-of-Thought 데이터 포함**: 단계적 추론을 요구하는 CoT 프롬프팅 데이터 추가
- **다양한 모델 크기**: Small(80M)부터 XXL(11B)까지 다양한 규모 제공

나아가 FLAN-PaLM은 540B PaLM 모델에 FLAN 방식을 적용하여 당시 최고 성능을 달성했으며, 특히 MMLU, BBH 등의 벤치마크에서 괄목할 만한 성과를 보였습니다.

### 한계

**비공개 기본 모델.** LaMDA-PT는 Google 내부 모델로 공개되지 않아 연구의 재현이 어렵습니다. 동일한 규모의 공개 모델에서 instruction tuning의 효과가 동일하게 나타나는지 검증하기 어려운 한계가 있습니다. 이 한계는 이후 FLAN-T5와 같은 오픈소스 모델의 공개로 부분적으로 해소되었습니다.

**수작업 템플릿의 확장성 문제.** 각 데이터셋에 대해 10개의 지시 템플릿을 수작업으로 작성하는 것은 비용이 크고 확장이 어렵습니다. 62개 데이터셋에 대해 총 620개의 템플릿을 작성해야 했으며, 새로운 데이터셋을 추가할 때마다 추가 템플릿 작성이 필요합니다. 이후 연구들은 LLM 자체를 활용하여 지시 데이터를 자동 생성하는 방향(Self-Instruct, Alpaca 등)으로 발전했습니다.

**복잡한 추론 태스크의 한계.** 수학적 추론, 논리적 추론, 코드 생성 등 다단계 추론이 필요한 태스크에서는 instruction tuning만으로는 충분한 개선을 달성하기 어렵습니다. 이 한계는 이후 Chain-of-Thought 프롬프팅(Wei et al., 2022b)과 같은 추론 강화 기법의 연구로 이어졌습니다.

**인간 선호도 정렬의 부재.** FLAN은 순수한 instruction tuning만을 수행하며, RLHF와 같은 인간 선호도 정렬(alignment) 기법을 적용하지 않습니다. 이로 인해 모델이 지시를 따르더라도 안전하고 유용한 방식으로 응답하는 것을 보장하기 어렵습니다. InstructGPT는 FLAN의 instruction tuning 위에 RLHF를 추가하여 이 한계를 해결했습니다.

**평가의 제한성.** 제로샷 평가가 특정 벤치마크에 한정되어 있으며, 실제 사용자의 다양하고 복잡한 지시에 대한 일반화 능력은 충분히 검증되지 않았습니다. 또한 평가 메트릭이 정확도(accuracy) 중심이어서 생성 품질, 유창성, 안전성 등 다차원적 평가가 부족합니다.

### FLAN의 역사적 위치

FLAN은 사전 학습(pretraining) 이후의 학습 단계인 **post-training**의 중요성을 최초로 대규모로 입증한 연구로 평가됩니다. 현대 LLM 개발의 표준 파이프라인인 "Pretraining -> Supervised Fine-Tuning(SFT) -> RLHF" 중 SFT 단계의 이론적, 실험적 기반을 마련한 것이 바로 FLAN입니다. GPT-4, Claude, Gemini 등 오늘날의 최첨단 LLM들이 모두 instruction tuning을 핵심 학습 단계로 채택하고 있다는 사실은, FLAN이 제시한 패러다임의 영향력을 여실히 보여줍니다.
