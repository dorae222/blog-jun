## 개요

GPT-3의 등장 이후, 대규모 언어 모델(LLM)이 별도의 파인튜닝 없이도 새로운 태스크를 수행하는 **제로샷(zero-shot) 일반화** 능력이 큰 주목을 받았습니다. 그러나 GPT-3의 175B 파라미터라는 거대한 규모는 대부분의 연구자에게 접근이 불가능했으며, 제로샷 일반화가 순전히 모델 크기에서 비롯되는 것인지, 학습 방식의 개선으로도 달성 가능한 것인지에 대한 근본적 질문이 남아 있었습니다.

**"Multitask Prompted Training Enables Zero-Shot Task Generalization"** (Sanh et al., 2021; ICLR 2022)은 이 질문에 명쾌한 답을 제시합니다. 핵심 주장은 다음과 같습니다:

> 다양한 태스크에 대해 다양한 자연어 프롬프트 형식으로 멀티태스크 학습을 수행하면, 모델 규모와 무관하게 강력한 제로샷 일반화 능력을 획득할 수 있다.

T5-LM adapted(11B) 기반의 **T0** 모델은 GPT-3(175B)에 비해 16배 작지만, 다수의 제로샷 벤치마크에서 GPT-3를 능가합니다. BigScience 프로젝트의 일환으로 수행된 이 연구는 모델 가중치, 데이터셋, 프롬프트 풀, 프롬프트 작성 도구(PromptSource)를 모두 공개하여 후속 연구의 토대를 닦았습니다.

## 배경 및 문제

### 제로샷 일반화의 도전

전통적인 NLP 파이프라인에서는 각 태스크마다 별도의 학습 데이터를 수집하고 태스크별로 모델을 파인튜닝해야 했습니다. GPT-3(Brown et al., 2020)는 이 패러다임에 도전하여, 충분히 큰 언어 모델이 인-컨텍스트 학습(in-context learning)을 통해 새로운 태스크를 수행할 수 있음을 보였습니다. 그러나 GPT-3의 접근법에는 세 가지 근본적인 문제가 존재했습니다.

첫째, **규모 의존성**입니다. GPT-3의 제로샷 능력은 175B라는 거대한 파라미터 수에 크게 의존했습니다. 더 작은 GPT-3 변형(예: 6.7B)은 제로샷 성능이 현저히 낮아, 제로샷 일반화가 사실상 모델 규모의 부산물(emergent property)인지에 대한 의문을 제기했습니다.

둘째, **접근성**입니다. 175B 파라미터 모델의 학습과 서빙에는 수백 개의 GPU가 필요하며, API로만 접근 가능했기 때문에 내부 동작 연구가 제한되었습니다.

셋째, **프롬프트 민감성**입니다. GPT-3의 제로샷 성능은 프롬프트 문구의 미세한 변화에 크게 좌우되었으며, 동일 태스크에 대해서도 표현을 조금만 바꾸면 성능이 급격히 변동했습니다.

### 멀티태스크 학습과 선행 연구

멀티태스크 학습(multi-task learning) 자체는 NLP에서 오랜 역사를 가집니다. [[T5]](Raffel et al., 2020)는 다양한 NLP 태스크를 텍스트-투-텍스트(text-to-text) 형식으로 통합하여 학습시키는 접근법을 제안했으며, T0의 직접적인 기반이 됩니다. 그러나 T5의 멀티태스크 학습은 태스크별로 고정된 단일 형식을 사용했고 학습 데이터에 포함된 태스크에 대해서만 평가했다는 점에서 제로샷 일반화와는 거리가 있었습니다.

[[FLAN]](Wei et al., 2021)은 T0와 거의 동시에 독립적으로 발표된 연구로, 137B LaMDA 모델에 instruction tuning을 적용하여 유사한 결론에 도달했습니다. 두 연구의 핵심 발견은 일치합니다: **다양한 태스크를 자연어 지시(instruction) 형태로 학습시키면 제로샷 일반화가 크게 향상된다.** 다만 T0는 오픈소스 모델과 도구를 모두 공개했다는 점에서 FLAN과 구별됩니다.

### 문제 정의

형식적으로, 학습 태스크 집합 $\mathcal{T}_{\text{train}} = \{T_1, T_2, \ldots, T_N\}$이 주어졌을 때, 학습 단계에서 한 번도 본 적 없는 새로운 태스크 $T_{\text{new}} \notin \mathcal{T}_{\text{train}}$에 대해 학습 예시 없이(zero-shot) 높은 성능을 달성하는 것이 목표입니다.

핵심 가설은 다음과 같습니다: 각 학습 태스크 $T_i$에 대해 다양한 프롬프트 템플릿 $\{p_1^{(i)}, p_2^{(i)}, \ldots, p_{K_i}^{(i)}\}$를 사용하여 멀티태스크 학습을 수행하면, 모델이 태스크의 표면적 형식이 아닌 본질적 구조를 학습하게 되어, 새로운 태스크에 대한 자연어 지시도 올바르게 따를 수 있게 됩니다.

## 방법론

### T0의 설계 원칙

T0의 핵심 통찰은 **"규모보다 방법론"**이라는 명제에 있습니다. 기존의 제로샷 일반화 연구들이 더 큰 모델을 학습시키는 방향으로 진행되었다면, T0는 동일한 크기의 모델에 대해 학습 방식을 개선하는 것만으로 동등하거나 우월한 제로샷 성능을 달성할 수 있음을 보여줍니다. 이 설계 철학은 세 가지 원칙에 기반합니다.

- **태스크 다양성**: 감성 분석, 자연어 추론, 질문 응답, 요약, 상식 추론 등 가능한 한 많은 종류의 NLP 태스크를 학습 데이터에 포함시켜, 모델이 언어 이해의 다양한 측면을 학습하도록 합니다.
- **프롬프트 다양성**: 동일한 태스크에 대해 여러 가지 자연어 표현을 사용하여, 모델이 특정 프롬프트 형식에 과적합되는 것을 방지하고 태스크의 본질적 의미를 파악하도록 유도합니다.
- **커뮤니티 협업**: PromptSource라는 도구를 통해 다수의 기여자가 프롬프트 작성에 참여할 수 있도록 하여, 프롬프트의 다양성과 품질을 동시에 높입니다.

![T0 모델의 멀티태스크 프롬프트 학습 및 제로샷 추론 구조](figures/fig_1.png)
*T0 모델의 핵심 동작 원리. 다수의 NLP 태스크에 대해 다양한 자연어 프롬프트로 학습(위)한 뒤, 학습에 포함되지 않은 태스크에 대해 제로샷으로 추론(아래)을 수행한다. 이탤릭체는 원본 데이터에서 삽입된 필드를 나타낸다. (Sanh et al., 2021)*

### PromptSource와 P3 데이터베이스

이 연구의 기술적 기반은 **PromptSource**라는 협업 도구와 이를 통해 구축된 **P3(Public Pool of Prompts)** 데이터베이스입니다. PromptSource는 웹 기반 인터페이스로, 연구자들이 Hugging Face Datasets 라이브러리에 등록된 데이터셋에 대해 프롬프트 템플릿을 작성하고 검증할 수 있습니다. 각 프롬프트 템플릿은 Jinja2 구문을 사용하여 정의되며, 입력 필드를 자연어 지시로 변환하는 매핑 함수로 작동합니다.

P3에는 최종적으로 **170여 개 데이터셋에 대한 약 2,052개의 프롬프트 템플릿**이 포함되었습니다. 36명 이상의 기여자가 참여했으며, 각 데이터셋당 평균 11.7개의 프롬프트가 작성되었습니다. 구체적인 프롬프트 예시를 살펴보면, 자연어 추론 태스크(MNLI)의 경우:

- 템플릿 A: "Premise: {premise}\nHypothesis: {hypothesis}\nDoes the premise entail the hypothesis? Yes, No, or Maybe?"
- 템플릿 B: "Given that '{premise}', is it true that '{hypothesis}'? Please answer yes, no, or maybe."
- 템플릿 C: "Suppose {premise}. Can we conclude that {hypothesis}? Yes, no, or maybe?"
- 템플릿 D: "{premise}\nQuestion: {hypothesis} True, False, or Neither?"

각 템플릿은 동일한 NLI 태스크를 서로 다른 자연어 표현으로 제시합니다. 이러한 다양성 덕분에 모델은 특정 문구 패턴이 아닌 태스크의 논리적 구조 자체를 학습하게 됩니다.

### 태스크 클러스터링과 데이터 구성

![T0 학습에 사용된 데이터셋 분류 체계 및 태스크 클러스터 구조](figures/fig_2.png)
*T0 학습에 사용된 데이터셋과 태스크 분류 체계. 노란색은 학습 혼합에 포함된 데이터셋, 초록색은 제로샷 일반화 평가를 위해 학습에서 제외(held-out)된 데이터셋이다. 학습 태스크와 평가 태스크를 카테고리 단위로 완전히 분리하여 제로샷 일반화를 엄밀하게 측정한다. (Sanh et al., 2021)*

학습 데이터는 **태스크 카테고리(task cluster)**별로 체계적으로 조직됩니다. 논문에서 정의한 주요 태스크 카테고리는 다음과 같습니다:

| 카테고리 | 포함 태스크 유형 | 대표 데이터셋 | 데이터셋 수 |
|----------|------------------|---------------|-------------|
| Sentiment | 감성 분석 | SST-2, Yelp, IMDB | 6 |
| Topic Classification | 주제 분류 | AG News, DBpedia, TREC | 5 |
| NLI | 자연어 추론 | MNLI, SNLI, ANLI, CB | 7 |
| Paraphrase Detection | 패러프레이즈 검출 | QQP, MRPC, PAWS | 4 |
| Closed-book QA | 클로즈드북 질문 응답 | TriviaQA, Web Questions | 3 |
| Extractive QA | 추출형 질문 응답 | SQuAD, ROPES, AdversarialQA | 5 |
| Multiple-choice QA | 다지선다형 QA | RACE, ARC, OpenBookQA | 8 |
| Summarization | 요약 | CNN/DM, XSum, MultiNews | 5 |
| Struct-to-text | 구조화 데이터 변환 | CommonGen, DART, E2E | 6 |
| Translation | 번역 | WMT 일부 | 3 |
| Coreference | 상호참조 해결 | Winogrande, WSC | 3 |
| Word Sense | 단어 의미 | WiC | 2 |

제로샷 일반화를 엄밀하게 평가하기 위해, 평가에 사용되는 태스크는 학습 데이터에서 **완전히 제외**됩니다. 더 나아가, 평가 태스크와 동일한 카테고리에 속하는 모든 데이터셋도 학습에서 제외하는 "held-out task cluster" 실험도 수행합니다. 예를 들어, NLI 태스크에 대한 제로샷 성능을 평가할 때는 MNLI, SNLI, ANLI 등 모든 NLI 관련 데이터셋을 학습에서 제거합니다.

### 학습 절차

기본 모델로는 **T5-LM adapted** 체크포인트를 사용합니다. 이는 표준 T5 모델에 추가적인 언어 모델 적응(LM adaptation) 단계를 거친 버전으로, 프롬프트 기반 학습에 더 적합합니다. T5의 인코더-디코더 구조에서, 프롬프트가 적용된 입력은 인코더로, 정답 출력은 디코더의 타깃으로 들어갑니다.

학습 목표 함수는 표준 시퀀스-투-시퀀스 교차 엔트로피 손실입니다:

$$\mathcal{L}(\theta) = -\sum_{i=1}^{N} \sum_{k=1}^{K_i} \sum_{(x,y) \in T_i} \sum_{t=1}^{|y|} \log P_{\theta}(y_t \mid y_{<t}, p_k^{(i)}(x))$$

여기서 $\theta$는 모델 파라미터, $N$은 학습 태스크 수, $K_i$는 태스크 $T_i$에 대한 프롬프트 수, $p_k^{(i)}(x)$는 태스크 $T_i$의 $k$번째 프롬프트 템플릿을 입력 $x$에 적용한 결과, $y$는 정답 출력입니다.

학습 시 각 데이터셋에서 최대 500,000개의 예시를 샘플링하고, 데이터셋 크기에 비례하는 혼합 비율(proportional mixing)을 사용하여 데이터 불균형을 완화합니다. 학습은 $10^5$ 스텝 동안 진행되며, 배치 크기 1,024, 학습률 $1 \times 10^{-3}$을 사용합니다.

### T0 모델 변형

논문은 학습에 포함되는 태스크의 범위에 따라 세 가지 주요 변형을 제안합니다:

| 모델 | 기반 모델 | 파라미터 | 학습 태스크 범위 |
|------|-----------|----------|------------------|
| T0 | T5-LM (11B) | 11B | 기본 학습 태스크 (39개 데이터셋) |
| T0+ | T5-LM (11B) | 11B | 기본 + GPT-3 평가 태스크 일부 추가 |
| T0++ | T5-LM (11B) | 11B | 기본 + SuperGLUE 태스크 추가 |
| T0-3B | T5-LM (3B) | 3B | 기본 학습 태스크 (규모 축소 버전) |

T0++는 SuperGLUE 데이터셋을 학습에 포함시킨 버전으로, SuperGLUE 벤치마크에서의 성능은 높지만 엄밀한 의미의 제로샷은 아닙니다. 반면 T0는 SuperGLUE를 학습에 포함하지 않으므로, SuperGLUE에 대한 성능이 순수한 제로샷 일반화를 반영합니다.

### 추론 시 평가 방식

분류 태스크의 경우, 논문은 두 가지 평가 방식을 비교합니다:

1. **Rank Classification**: 각 선택지(예: "Yes", "No", "Maybe")에 대해 디코더의 로그 확률을 계산하고, 가장 높은 확률의 선택지를 정답으로 선택합니다.

$$\hat{y} = \arg\max_{c \in \mathcal{C}} \log P_{\theta}(c \mid p(x))$$

2. **길이 정규화(Length Normalization)**: 선택지의 토큰 길이에 따른 편향을 보정하기 위해, 로그 확률을 토큰 수로 나눕니다:

$$\hat{y} = \arg\max_{c \in \mathcal{C}} \frac{1}{|c|} \sum_{t=1}^{|c|} \log P_{\theta}(c_t \mid c_{<t}, p(x))$$

| T0+ | 11B | zero-shot | 82.5 | 78.6 | 92.0 | 80.0 | 89.9 | 82.3 | 57.7 | 68.3 | 78.9 |
| T0++ | 11B | zero-shot | 86.1 | 88.1 | 94.0 | 82.7 | 91.1 | 85.2 | 67.1 | 78.8 | 84.1 |

T0(11B, zero-shot)가 GPT-3(175B, few-shot)를 능가하는 결과는 매우 주목할 만합니다. 특히 RTE(자연어 추론)에서 80.1 vs 72.9, BoolQ(예/아니오 질문 응답)에서 81.5 vs 76.4로 두드러진 차이를 보입니다. 이는 적절한 멀티태스크 프롬프트 학습이 모델 규모의 16배 차이를 상쇄하고도 남을 수 있음을 입증합니다.

| 태스크 | GPT-3 (zero-shot) | GPT-3 (few-shot) | T0 (zero-shot) |

BIG-bench에서도 T0는 GPT-3 대비 일관되게 높은 성능을 보이며, 특히 상식 추론(Conceptual Combinations)과 메타인지(Known Unknowns) 태스크에서 강점을 나타냅니다.

### 프롬프트 다양성의 효과 분석

논문의 가장 중요한 ablation 중 하나는 **프롬프트 다양성이 제로샷 성능에 미치는 영향**입니다. 동일한 태스크 집합에 대해 데이터셋당 프롬프트 수를 0(T5+LM 기준), 1, 5.7, 8.03(T0)으로 변화시키며 성능을 비교합니다.

![데이터셋당 프롬프트 수 증가에 따른 제로샷 성능 변화](figures/fig_6.png)
*데이터셋당 학습 프롬프트 수 증가의 효과. p=0은 T5+LM 기준 모델, p=8.03은 T0 모델이다. 프롬프트 수가 늘어날수록 중위 성능(가로선)이 향상되고 사분위 범위(박스 크기)가 좁아져, 더 높고 안정적인 제로샷 성능을 달성한다. 특히 NLI와 Coreference Resolution 태스크에서 개선이 두드러진다. (Sanh et al., 2021)*

실험 결과, 다중 프롬프트 학습 시 평균 제로샷 성능이 약 **3~5%p** 향상되었습니다. 특히 주목할 패턴은 다음과 같습니다:

- 학습 태스크와 유사한 평가 태스크에서: 약 2~3%p 향상
- 학습 태스크와 다른 유형의 평가 태스크에서: 약 4~6%p 향상

후자에서 더 큰 향상이 관찰된다는 점은 매우 의미심장합니다. 프롬프트 다양성이 단순히 특정 태스크에 대한 견고성(robustness)을 높이는 것을 넘어, **태스크 간 전이 학습(cross-task transfer)**을 촉진한다는 것을 시사합니다.

### 태스크 수의 영향 (Scaling Analysis)

학습에 포함되는 태스크 수를 점진적으로 늘려가며 제로샷 성능의 변화를 관찰한 결과, 태스크 수가 증가함에 따라 성능이 **대수적(logarithmic)**으로 증가하는 패턴이 발견되었습니다:

$$\text{Performance} \approx \alpha \cdot \log(|\mathcal{T}_{\text{train}}|) + \beta$$

이 관계는 태스크 수를 늘리는 것이 항상 유익하지만, 한계 효용이 점차 감소한다는 것을 의미합니다. 동시에, 논문에서 사용한 39~62개의 태스크에서도 성능이 포화 상태에 도달하지 않아, 더 많은 태스크를 추가하면 추가적인 향상이 가능함을 시사합니다.

### 태스크 카테고리별 분석 (Held-out Cluster Experiment)

논문에서 가장 정교한 실험 중 하나는 **held-out task cluster** 분석입니다. 특정 태스크 카테고리 전체를 학습에서 제외하고, 해당 카테고리의 제로샷 성능을 측정하여 어떤 태스크 카테고리가 다른 카테고리의 제로샷 성능에 가장 큰 기여를 하는지 파악합니다.

주요 발견은 다음과 같습니다:

- **NLI 태스크의 중추적 역할**: NLI(자연어 추론)를 학습에 포함시키면, 거의 모든 다른 카테고리의 제로샷 성능이 향상됩니다. NLI가 textual entailment와 논리적 관계 파악이라는 자연어 이해의 핵심 역량을 학습시키기 때문입니다.
- **상호 보완적 카테고리**: 감성 분석과 주제 분류는 서로 보완적이며, 두 카테고리를 함께 학습하면 시너지 효과가 발생합니다.
- **전이가 어려운 카테고리**: 구조화 데이터 변환(struct-to-text) 태스크는 다른 카테고리로부터의 전이가 상대적으로 적었으며, 해당 태스크가 요구하는 기술이 다른 태스크와 이질적이기 때문입니다.

### 모델 규모의 영향

T0-3B(3B 파라미터)와의 비교는 모델 규모와 학습 방법론 사이의 상호작용에 대한 중요한 통찰을 제공합니다.

| 모델 | 파라미터 | SuperGLUE 평균 (zero-shot) |
|------|----------|----------------------------|
| GPT-3 | 175B | 61.1 |
| T0-3B | 3B | 60.5 |
| T0 | 11B | 78.6 |

T0-3B(3B)는 GPT-3(175B)와 거의 동등한 제로샷 성능을 보입니다. 이는 **58배 작은 모델**이 적절한 학습 방법론을 통해 거대 모델과 대등한 성능을 달성할 수 있음을 의미합니다. 3B에서 11B로의 규모 확대는 약 18%p의 성능 향상을 가져오며, 멀티태스크 프롬프트 학습의 효과가 모델 규모가 커질수록 더욱 증폭된다는 것을 시사합니다.

### 프롬프트 형식에 대한 견고성

각 평가 태스크에 대해 여러 프롬프트 템플릿으로 추론을 수행한 결과, T0는 GPT-3에 비해 프롬프트 선택에 대한 **분산이 현저히 낮았습니다**. 중위 성능(median performance) 기준으로 T0의 프롬프트 간 성능 분산은 GPT-3 대비 약 40~60% 낮았습니다. 이는 모델이 프롬프트의 표면적 형식이 아닌 의미적 내용에 기반하여 판단한다는 증거이며, 프롬프트 엔지니어링에 대한 의존도를 크게 낮추는 실용적으로 중요한 특성입니다.

## 의의 및 한계

### 학술적 의의

**Instruction Tuning 패러다임의 확립.** T0는 [[FLAN]]과 함께 instruction tuning이라는 새로운 학습 패러다임을 확립한 선구적 연구입니다. 이후 [[InstructGPT]], [[FLAN-T5]], [[Alpaca]], [[Vicuna]] 등 수많은 후속 연구가 이 패러다임 위에 구축되었으며, 현재의 ChatGPT, Claude 등 대화형 AI 시스템도 instruction tuning을 핵심 학습 단계로 포함하고 있습니다.

**효율적 스케일링에 대한 실증.** "올바른 방법론으로 학습된 작은 모델이 잘못 학습된 큰 모델을 능가할 수 있다"는 메시지는 이후의 연구 방향에 큰 영향을 미쳤으며, Chinchilla(Hoffmann et al., 2022)의 계산 최적 스케일링 법칙과도 맥을 같이합니다.

**오픈소스 생태계 기여.** 모델 가중치(Hugging Face Hub), 프롬프트 데이터베이스(P3), 프롬프트 작성 도구(PromptSource)를 모두 공개하여 후속 연구의 재현과 확장 기반을 마련했습니다. 이는 LaMDA 기반이라 모델이 비공개였던 FLAN과의 핵심적 차별점입니다.

**태스크 분류 체계의 확립.** 논문에서 제안한 태스크 카테고리 분류와 held-out cluster 실험 설계는 이후 멀티태스크 학습 연구의 표준적인 방법론으로 자리 잡았습니다.

### 한계

**생성 품질의 제약.** T5는 인코더-디코더 구조로 분류 및 추출 태스크에 강하지만, 긴 자유 형식 텍스트 생성에서는 GPT 계열의 디코더 전용 모델에 비해 약합니다. T5의 사전학습 목표(span corruption)가 긴 텍스트 생성에 최적화되어 있지 않기 때문입니다.

**복잡한 추론의 한계.** 수학 문제 풀이, 코드 생성, 다단계 논리적 추론 등 복잡한 추론이 필요한 태스크에서는 여전히 한계를 보이며, 이는 이후 [[chain-of-thought prompting]](Wei et al., 2022)이나 [[self-consistency]](Wang et al., 2022) 등의 연구에서 다루어지는 과제입니다.

**프롬프트 분포 의존성.** P3에 포함된 프롬프트 스타일에 의존하기 때문에, 학습 분포 밖의 완전히 새로운 프롬프트 형식(매우 비공식적인 구어체, 특수 도메인 전문 용어 등)에는 덜 견고할 수 있습니다.

**다국어 지원 미흡.** P3의 프롬프트는 주로 영어로 작성되어 있으며, T5 자체도 영어 중심으로 사전학습되었습니다. 이 한계는 이후 mT0(Muennighoff et al., 2022)에서 다국어로 확장되어 부분적으로 해소됩니다.

**RLHF와의 비교 부재.** T0는 supervised instruction tuning에 해당하며, 인간 피드백 기반 강화학습(RLHF)과의 결합은 이후 [[InstructGPT]]에서 도입되어 instruction following 성능을 한 단계 더 끌어올렸습니다.

### 후속 연구와의 연결

T0의 연구 결과는 다음과 같은 후속 연구로 이어졌습니다:

- **[[FLAN-T5]]** (Chung et al., 2022): T0와 FLAN의 아이디어를 통합하여, 1,800개 이상의 태스크로 확장된 instruction tuning을 수행합니다.
- **mT0** (Muennighoff et al., 2022): T0의 접근법을 다국어로 확장하여 46개 언어에 대한 제로샷 일반화를 달성합니다.
- **[[InstructGPT]]** (Ouyang et al., 2022): instruction tuning에 RLHF를 추가하여 인간의 선호도에 더 잘 맞는 응답을 생성합니다.
- **Self-Instruct** (Wang et al., 2023): 모델 자체가 instruction 데이터를 생성하는 자기 지시 학습 방법론을 제안합니다.

이러한 발전 경로를 통해, T0에서 시작된 instruction tuning 패러다임은 현재의 대화형 AI 시스템(ChatGPT, Claude, Gemini 등)의 핵심 기술로 자리 잡았습니다.
