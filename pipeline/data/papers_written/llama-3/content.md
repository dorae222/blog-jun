## 개요

"The Llama 3 Herd of Models"(Meta, 2024)는 8B, 70B, 405B 파라미터 규모의 오픈 웨이트(open-weight) 대규모 언어 모델 시리즈를 소개한 논문입니다. 특히 405B 모델은 GPT-4(2023년 3월 버전)와 동등하거나 그 이상의 성능을 달성하여, 오픈소스 LLM이 클로즈드 소스 모델과 대등한 수준에 도달할 수 있음을 최초로 실증했습니다.

Llama 3의 핵심 철학은 "단순하지만 고품질의 학습"입니다. 복잡한 아키텍처 혁신보다는 **데이터 품질**, **스케일링 법칙에 기반한 체계적 확장**, 그리고 **엄격한 사후 학습 파이프라인**에 집중했습니다. 이 접근은 상대적으로 단순한 표준 Transformer 아키텍처로도 최고 수준의 성능을 달성할 수 있음을 보여줍니다.

또한 이 논문은 단순한 언어 모델 소개를 넘어, 멀티모달(이미지, 비디오, 음성) 확장, 다국어 지원, 도구 사용, 코드 생성 등 포괄적인 능력을 다루는 **종합 기술 보고서**의 성격을 지닙니다. 총 92페이지에 달하는 분량은 오픈 웨이트 모델의 개발 과정을 가장 상세하게 기술한 문헌 중 하나입니다.

## 배경 및 동기

### 오픈소스 LLM의 진화

2023년 이후 LLM 생태계는 크게 두 진영으로 나뉘어 발전해 왔습니다. OpenAI의 GPT-4([[gpt-4]]), Google의 Gemini([[gemini]]), Anthropic의 Claude 등 클로즈드 소스 모델과, Meta의 Llama 시리즈, Mistral([[mistral-7b]]), Qwen([[qwen2-5]]) 등 오픈 웨이트 모델입니다.

| 세대 | 모델 | 파라미터 | 학습 토큰 | 핵심 특징 |
|------|------|---------|----------|----------|
| Llama 1 | Llama | 7B~65B | 1.4T | 오픈 웨이트 패러다임 시작 |
| Llama 2 | Llama 2 | 7B~70B | 2T | Chat 최적화, RLHF 도입 |
| Llama 3 | Llama 3 | 8B~405B | 15.6T | 데이터 품질 혁신, GPT-4급 성능 |

Llama 1([[llama]])이 2023년 2월에 등장하면서 오픈소스 LLM 생태계가 폭발적으로 성장했습니다. Llama 2([[llama-2]])는 RLHF를 적용한 Chat 모델을 제공하며 실용적 채팅봇의 기반을 마련했습니다. 그러나 이 두 세대 모두 GPT-4와는 상당한 성능 격차가 있었습니다.

### 스케일링의 재발견

Llama 3의 개발 철학은 Chinchilla 스케일링 법칙([[chinchilla]])에 대한 재해석에서 시작됩니다. Chinchilla는 "주어진 연산 예산에서 최적의 학습을 위해서는 모델 크기와 학습 데이터를 균형 있게 늘려야 한다"고 주장했습니다. 그러나 Meta는 여기서 한 걸음 더 나아가, **추론 시 연산 비용**까지 고려하면 Chinchilla 최적 비율보다 더 많은 데이터로 더 작은 모델을 학습하는 것이 효율적임을 발견했습니다.

이는 실용적으로 매우 중요한 통찰입니다. 학습은 한 번이지만 추론은 수백만 번 수행되므로, 추론 비용을 최소화하는 것이 총비용 관점에서 유리합니다. 이 원칙에 따라 Llama 3 8B 모델은 Chinchilla 최적(~200B 토큰)보다 75배 이상 많은 15.6T 토큰으로 학습되었습니다.

### 데이터 품질의 결정적 역할

Llama 3 프로젝트에서 가장 많은 자원이 투입된 영역은 **학습 데이터의 품질 관리**입니다. Meta는 이전 세대의 경험을 통해 모델 아키텍처나 학습 알고리즘의 혁신보다 **데이터 품질의 개선이 최종 성능에 더 큰 영향**을 미친다는 것을 확인했습니다.

:::info
"모델 아키텍처를 바꾸는 것보다 학습 데이터를 개선하는 것이 성능 향상에 더 효과적이다"라는 Meta의 결론은 DeepSeek-V2([[deepseek-v2]])와 Qwen 2.5([[qwen2-5]]) 등 이후 모델들에서도 반복적으로 확인되는 교훈입니다.
:::

## 핵심 아이디어

### 단순한 아키텍처, 극대화된 데이터

Llama 3의 아키텍처는 의도적으로 **표준 Dense Transformer**를 채택했습니다. MoE(Mixture of Experts)나 새로운 어텐션 메커니즘 같은 구조적 혁신을 도입하지 않았습니다. 대신 다음과 같은 검증된 기술들을 조합했습니다:

- **GQA (Grouped Query Attention)**: 효율적인 추론을 위해 KV 캐시를 그룹화하여 메모리 사용량을 줄입니다 ([[gqa]])
- **RoPE (Rotary Position Embedding)**: 상대적 위치 인코딩으로 길이 일반화를 개선합니다 ([[roformer-rope]])
- **SwiGLU 활성화 함수**: FFN 레이어에서 SwiGLU를 사용하여 표현력을 높입니다
- **RMSNorm**: Pre-normalization에 RMSNorm을 적용하여 학습 안정성을 확보합니다
- **128K 어휘(vocabulary)**: tiktoken 기반의 대규모 어휘로 토큰화 효율을 개선합니다

![Llama 3의 전체 개발 파이프라인](figures/p01_fig01.png)

*Figure 1: Llama 3의 전체 개발 파이프라인. 사전 학습(Pre-training), 사후 학습(Post-training), 안전성 평가(Safety)의 세 단계로 구성되며, 각 단계의 핵심 요소들을 보여준다. (Meta AI, 2024)*

### 데이터 파이프라인

Llama 3의 학습 데이터 처리 파이프라인은 다단계 필터링과 품질 평가로 구성됩니다:

**1단계: 웹 크롤링 데이터 수집**

대규모 웹 크롤링 데이터에서 출발하여, URL 수준, 문서 수준, 줄 수준의 다단계 필터링을 적용합니다.

**2단계: 중복 제거 (Deduplication)**

- **URL 수준**: 동일 URL의 중복 문서 제거
- **문서 수준**: MinHash 기반의 근사 중복 검출
- **줄 수준**: 반복되는 상용구(boilerplate) 텍스트 제거

**3단계: 품질 분류 (Quality Classification)**

Llama 2를 활용하여 각 문서의 품질을 자동으로 평가합니다. 고품질 텍스트(위키피디아, 도서, 학술 논문 등)를 기준 데이터로 사용하여 이진 분류기를 학습합니다.

**4단계: 도메인 혼합 (Domain Mixing)**

최종 학습 데이터의 도메인 비율을 실험적으로 최적화합니다. 일반 웹 텍스트, 코드, 수학, 다국어 텍스트 등의 비율을 소규모 실험을 통해 결정합니다.

![Llama 3의 학습 데이터 분류 및 필터링](figures/p21_fig01.png)

*Figure 2: Llama 3의 학습 데이터 품질 분류. Llama 2를 활용한 품질 분류기를 통해 웹 크롤링 데이터에서 고품질 텍스트를 선별한다. fasttext 기반의 효율적인 분류 파이프라인을 구축했다. (Meta AI, 2024)*

### 대규모 학습 인프라

Llama 3 405B 모델의 학습은 **16,384개의 H100 GPU**를 사용하여 수행되었습니다. 이 규모의 학습을 안정적으로 수행하기 위한 인프라 기술은 그 자체로 중요한 기여입니다.

| 항목 | 세부사항 |
|------|---------|
| GPU 수 | 16,384 H100 |
| 학습 토큰 | 15.6T |
| 컨텍스트 길이 | 8K → 128K (단계적 확장) |
| 배치 크기 | 16M 토큰 (단계적 증가) |
| 학습률 | 8×10⁻⁵ (피크) |
| 학습 기간 | ~54일 |

학습 안정성을 위해 다음과 같은 기법들이 적용되었습니다:

- **3D 병렬화**: 텐서 병렬(TP), 파이프라인 병렬(PP), 데이터 병렬(DP)의 조합
- **손실 스파이크 처리**: 학습 중 발생하는 손실 급등(loss spike)을 감지하고, 해당 배치를 건너뛰는 메커니즘
- **체크포인팅**: 하드웨어 장애에 대비한 주기적 모델 저장

:::warning
16,384 GPU 규모의 학습에서는 단일 GPU 장애 확률이 무시할 수 없는 수준이 됩니다. Meta에 따르면 학습 기간 동안 약 **466건의 작업 중단**이 발생했으며, 그 중 약 78%가 하드웨어 문제로 인한 것이었습니다. 이를 처리하기 위한 자동 복구 시스템이 필수적입니다.
:::

## 방법론

### 사전 학습 (Pre-training)

Llama 3의 사전 학습은 표준적인 자기회귀(autoregressive) 언어 모델링 목적 함수를 사용합니다:

$$\mathcal{L} = -\sum_{t=1}^{T} \log P(x_t | x_{<t}; \theta)$$

여기서 $x_t$는 $t$ 번째 토큰, $x_{<t}$는 이전 토큰들의 시퀀스, $\theta$는 모델 파라미터입니다.

학습은 세 단계로 나뉩니다:

**1단계: 초기 사전 학습 (8K 컨텍스트)**

15.6T 토큰의 대부분을 8K 컨텍스트 길이로 학습합니다. 배치 크기는 4M 토큰에서 시작하여 16M 토큰까지 점진적으로 증가시킵니다.

**2단계: 장문맥 학습 (128K 컨텍스트)**

컨텍스트 길이를 8K에서 128K로 단계적으로 확장합니다. 이 과정에서 RoPE의 주파수 파라미터를 조정하여 긴 시퀀스에서의 위치 인코딩을 적응시킵니다. 전체 학습 토큰의 약 0.1%만 이 단계에 사용됩니다.

**3단계: 어닐링 (Annealing)**

학습의 마지막 단계에서 학습률을 0으로 점진적으로 감소시키면서, 고품질 데이터의 비율을 높입니다. 이 단계에서 소량의 벤치마크 관련 데이터를 추가하여 특정 능력을 강화합니다.

### 사후 학습 (Post-training)

Llama 3의 사후 학습은 기존의 단순한 SFT + RLHF 파이프라인을 넘어, 여러 라운드의 반복적 개선을 수행합니다.

![Llama 3 사후 학습의 보상 모델 학습](figures/p27_fig01.png)

*Figure 3: Llama 3 사후 학습 과정에서의 보상 모델 학습. 인간 선호도 데이터를 기반으로 보상 모델을 학습하고, 이를 DPO(Direct Preference Optimization)에 활용한다. (Meta AI, 2024)*

**라운드 1: 초기 SFT (Supervised Fine-Tuning)**

고품질의 인간 작성 프롬프트-응답 쌍으로 초기 지시 사항 따르기 능력을 학습합니다.

**라운드 2-6: 반복적 DPO (Direct Preference Optimization)**

각 라운드에서:
1. 현재 모델로 응답을 생성합니다
2. 인간 평가자가 응답 쌍을 비교하여 선호도를 표시합니다
3. 이 데이터로 보상 모델을 학습합니다
4. DPO를 사용하여 모델을 업데이트합니다

이 과정에서 **거부 샘플링(Rejection Sampling)**이 핵심적인 역할을 합니다. 각 프롬프트에 대해 여러 응답을 생성한 후, 보상 모델의 점수가 가장 높은 응답만 선택하여 SFT 데이터로 사용합니다.

### 특화 능력 학습

Llama 3는 코드 생성, 수학적 추론, 도구 사용 등의 특화 능력을 위한 별도의 학습 과정을 포함합니다:

**코드 능력**:
- 실행 기반 피드백을 활용한 코드 품질 향상
- 단위 테스트 생성 및 자동 검증을 통한 데이터 필터링
- 프로그래밍 경시대회 문제를 활용한 난이도 높은 학습 데이터

**수학적 추론**:
- 단계별 풀이(Chain-of-Thought) 데이터 생성
- 풀이 검증을 위한 Outcome-based Reward Model 학습
- 수학 경시대회 문제를 포함한 고난도 학습 데이터

**도구 사용**:
- 검색 엔진, 코드 인터프리터, 수학 엔진 등의 외부 도구 호출 학습
- 제로샷 도구 사용 능력을 위한 시스템 프롬프트 설계
- 다단계 도구 사용 시나리오에 대한 학습

### 멀티모달 확장

Llama 3는 텍스트 전용 모델을 기반으로 이미지, 비디오, 음성 이해 능력을 추가했습니다. 멀티모달 확장의 핵심 전략은 **어댑터(adapter) 기반 접근**입니다.

이미지 이해를 위한 아키텍처:
- **이미지 인코더**: ViT-H/14 기반, 6.3B 파라미터
- **어댑터**: Cross-attention 기반의 이미지-텍스트 융합 레이어
- **학습 전략**: 인코더 → 어댑터 → 전체 미세 조정의 단계적 학습

음성 이해를 위한 아키텍처:
- **음성 인코더**: 별도의 음성 표현 학습 모델
- **어댑터**: 음성 토큰을 텍스트 토큰 공간에 매핑
- **학습 전략**: ASR(음성 인식) 데이터를 기반으로 초기 학습 후 멀티턴 대화 데이터로 미세 조정

Llama 3는 세 가지 크기(8B, 70B, 405B)의 모델을 통해 스케일링 효과를 체계적으로 분석했습니다.

![Llama 3의 스케일링 분석](figures/p54_fig01.png)

*Figure 5: Llama 3의 스케일링 분석. 모델 크기에 따른 벤치마크 성능 변화를 보여준다. 대부분의 벤치마크에서 로그-선형적 스케일링이 관찰되며, 일부 태스크에서는 특정 규모 이상에서 급격한 성능 향상(emergence)이 나타난다. (Meta AI, 2024)*

핵심 관찰 결과:

- **대부분의 벤치마크**: 모델 크기에 대해 로그-선형적 스케일링이 유지됩니다
- **수학적 추론**: 8B → 70B에서의 성능 향상이 70B → 405B보다 상대적으로 큽니다
- **코드 생성**: 규모 확대에 따른 성능 향상이 가장 일관적입니다
- **다국어**: 영어 외 언어에서의 성능 향상률이 영어보다 높아, 스케일링이 다국어 일반화에 특히 효과적임을 보여줍니다

### 안전성 평가

Llama 3는 포괄적인 안전성 평가를 수행했습니다:

- **바이올렉트(Violation) 비율**: 유해 콘텐츠 생성 비율이 Llama 2 대비 크게 감소
- **편향 평가**: 성별, 인종, 종교 등에 대한 편향 벤치마크에서 개선
- **개인정보 보호**: PII(개인 식별 정보) 노출 위험을 최소화하기 위한 필터링

## 한계 및 의의

### 한계

**1. 다국어 성능의 불균형**

Llama 3는 영어 중심으로 학습되어, 저자원 언어에서는 여전히 성능 격차가 존재합니다. 학습 데이터의 약 95%가 영어이며, 이는 비영어 사용자에게 불리한 구조입니다.

**2. 오픈 "웨이트"의 한계**

Llama 3는 모델 가중치를 공개했지만, 학습 데이터, 학습 코드, 데이터 파이프라인은 공개하지 않았습니다. 이는 완전한 오픈소스와는 차이가 있으며, 재현성의 한계를 만듭니다.

**3. 라이선스 제한**

Llama 3의 라이선스는 상업적 사용을 허용하지만, 월간 활성 사용자가 7억 명을 초과하는 서비스에서의 사용에는 Meta의 별도 승인이 필요합니다. 이는 완전한 자유 소프트웨어와는 거리가 있습니다.

**4. 추론 비용**

405B 모델은 뛰어난 성능을 보이지만, 추론에 상당한 하드웨어 자원이 필요합니다. FP16 추론 시 약 810GB의 GPU 메모리가 필요하여, 일반적인 연구 환경에서는 접근이 제한적입니다.

**5. 환각 (Hallucination)**

GPT-4와 마찬가지로 Llama 3도 환각 문제에서 완전히 자유롭지 않습니다. 특히 장문 생성이나 전문 지식 영역에서 사실과 다른 내용을 자신감 있게 생성하는 경우가 관찰됩니다.

### 의의

**1. 오픈소스 LLM의 새로운 기준**

Llama 3 405B가 GPT-4급 성능을 달성한 것은 오픈 웨이트 모델의 역사에서 중요한 이정표입니다. 이는 오픈소스 커뮤니티가 클로즈드 소스 모델과 대등한 수준에 도달할 수 있음을 실증했습니다.

**2. 데이터 중심 AI의 실증**

Llama 3는 "복잡한 아키텍처 혁신보다 데이터 품질이 중요하다"는 데이터 중심 AI(Data-Centric AI)의 철학을 대규모로 입증했습니다. 표준 Transformer 아키텍처로도 데이터를 잘 관리하면 최고 수준의 성능을 달성할 수 있습니다.

**3. 체계적인 스케일링 방법론**

학습 데이터 혼합 비율, 컨텍스트 길이 확장, 배치 크기 조정 등을 소규모 실험에서 체계적으로 결정하는 방법론은 이후 대규모 모델 개발의 모범 사례가 됩니다.

**4. 사후 학습 파이프라인의 고도화**

다중 라운드의 반복적 DPO와 거부 샘플링을 결합한 사후 학습 파이프라인은 단순한 SFT + RLHF를 넘어서는 정교한 정렬 방법론을 제시합니다.

**5. 생태계 활성화**

Llama 3의 오픈 웨이트 공개는 수천 개의 파생 모델, 미세 조정 레시피, 양자화 기법, 배포 도구 등으로 이어지며 오픈소스 LLM 생태계를 크게 활성화했습니다.

## 결론

Llama 3는 오픈 웨이트 LLM의 패러다임을 새로운 단계로 끌어올린 중요한 연구입니다. 표준적인 Dense Transformer 아키텍처에 15.6T 토큰의 고품질 학습 데이터를 결합하여 GPT-4급 성능을 달성했으며, 이를 오픈 웨이트로 공개함으로써 AI 민주화에 기여했습니다.

핵심 교훈은 세 가지로 요약됩니다. 첫째, **데이터 품질이 아키텍처 혁신보다 중요합니다**. 둘째, **추론 비용까지 고려한 스케일링 최적화**가 실용적으로 의미 있습니다. 셋째, **반복적이고 체계적인 사후 학습**이 최종 사용자 경험의 질을 결정합니다.

향후 이 방향의 발전은 더 효율적인 학습(MoE 아키텍처의 도입), 더 넓은 다국어 지원, 그리고 멀티모달 능력의 심화로 이어질 것으로 예상됩니다. Llama 3는 오픈소스 AI의 미래가 클로즈드 소스와 동등하거나 그 이상일 수 있다는 가능성을 열어놓았습니다.
