## 개요

"BLIP-2: Bootstrapping Language-Image Pre-training with Frozen Image Encoders and Large Language Models" (Li et al., 2023)는 Salesforce Research의 Junnan Li, Dongxu Li, Silvio Savarese, Steven Hoi가 ICML 2023에서 발표한 논문입니다. 이 연구는 **동결된(frozen) 이미지 인코더와 LLM 사이에 경량 Q-Former 모듈을 삽입**하여, 시각-언어 정렬을 효율적으로 달성하는 프레임워크를 제안합니다.

핵심 아이디어는 이미 강력한 성능을 갖춘 시각 모델(ViT)과 언어 모델(OPT, FlanT5)을 **동결한 채로**, 이 둘을 연결하는 경량 **Q-Former(Querying Transformer)**만을 학습하는 것입니다. 이를 통해 전체 파라미터의 극히 일부만 학습하면서도, 이미지 캡셔닝, 시각 질의응답(VQA), 이미지-텍스트 검색 등 다양한 시각-언어 태스크에서 기존 모델을 능가하는 성능을 달성합니다.

BLIP-2는 기존 대비 **54배 적은 학습 파라미터**로 SOTA를 달성하며, 특히 zero-shot 이미지-텍스트 생성에서 LLM의 in-context learning 능력을 시각 도메인으로 확장하는 데 성공합니다. 이 논문은 이후 InstructBLIP, MiniGPT-4, LLaVA 등 멀티모달 LLM 연구의 핵심 기반이 되었습니다.

## 배경 및 동기

### 비전-언어 사전학습의 비용 문제

2022년 시점에서, 비전-언어 사전학습(VLP: Vision-Language Pre-training) 모델의 규모는 급격히 커지고 있었습니다. CoCa(Yu et al., 2022)는 23억 파라미터, Flamingo(Alayrac et al., 2022)는 800억 파라미터에 달하며, 이러한 모델의 학습에는 수천 GPU-일의 컴퓨팅이 필요했습니다.

동시에, 단일 모달리티(vision-only, language-only) 모델들은 각각 빠르게 발전하고 있었습니다.

**비전 모델의 발전**:
- [[clip]] ViT-L/14: 76.2% ImageNet zero-shot
- ViT-G (EVA-CLIP): 78.5% ImageNet zero-shot
- ViT-e: 대규모 사전학습된 범용 시각 인코더

**언어 모델의 발전**:
- GPT-3 (175B): 강력한 few-shot 학습
- OPT (66B): 공개 대규모 언어 모델
- FlanT5 (11B): 명령어 튜닝된 효율적 LLM
- ChatGPT/GPT-4: 대화형 AI

이러한 상황에서 핵심 질문이 제기됩니다. **이미 강력한 비전 모델과 언어 모델이 존재하는데, 이 둘을 연결하는 경량 모듈만 학습하면 되지 않을까?**

### 기존 접근법의 한계

이전 연구들이 시도한 비전-언어 연결 방식과 그 한계를 살펴보겠습니다.

**1. End-to-End 학습 (CLIP, BLIP-1 등)**: 이미지 인코더와 텍스트 인코더를 처음부터 함께 학습합니다. 효과적이지만, 대규모 모델의 전체 파라미터를 학습하는 비용이 막대합니다.

**2. 선형 투영 (Linear Projection)**: 이미지 인코더의 출력을 단순 선형 변환으로 LLM의 입력 공간에 매핑합니다. 비용은 저렴하지만, 시각 정보의 풍부한 표현을 충분히 전달하지 못합니다.

**3. 크로스 어텐션 삽입 (Flamingo)**: LLM의 각 레이어에 크로스 어텐션 모듈을 삽입하여 시각 정보를 주입합니다. 효과적이지만, LLM 아키텍처를 수정해야 하며, LLM이 업데이트되면 재학습이 필요합니다.

BLIP-2는 이 모든 한계를 극복합니다. 비전 모델과 언어 모델 모두 **동결**한 채로, 그 사이에 경량 Q-Former만 학습합니다.

### 모달리티 갭(Modality Gap) 문제

비전 인코더와 LLM을 연결할 때의 근본적 도전은 **모달리티 갭**입니다. 비전 인코더(ViT)와 LLM(OPT, FlanT5)은 완전히 다른 데이터, 다른 목적함수, 다른 아키텍처로 학습되었기 때문에, 이들의 표현 공간은 서로 호환되지 않습니다.

비전 인코더의 출력은 이미지의 공간적 특성(spatial features)을 포함하는 고차원 벡터이고, LLM의 입력은 어휘의 의미적 임베딩(semantic embeddings)입니다. 이 두 표현 공간을 정렬(align)하는 것이 BLIP-2의 핵심 과제입니다.

## 핵심 아이디어

### Q-Former: 비전-언어 브리지

BLIP-2의 핵심 기여는 **Q-Former(Querying Transformer)**라는 경량 모듈입니다. Q-Former는 동결된 비전 인코더에서 **태스크에 관련된 시각 정보만을 추출**하여 LLM이 이해할 수 있는 형태로 변환하는 역할을 합니다.

Q-Former의 구조는 다음과 같습니다.

**학습 가능한 쿼리(Learned Queries)**: 32개의 학습 가능한 쿼리 토큰 $\{q_1, q_2, \ldots, q_{32}\}$가 Q-Former의 입력으로 사용됩니다. 각 쿼리는 768 차원의 벡터로, 학습 과정에서 "어떤 시각 정보를 추출할 것인가"를 자동으로 학습합니다.

**이중 어텐션 구조**: Q-Former는 BERT 기반 Transformer로, 두 종류의 어텐션을 수행합니다.
1. **자기 어텐션(Self-Attention)**: 쿼리 토큰 간, 또는 쿼리 토큰과 텍스트 토큰 간의 어텐션
2. **크로스 어텐션(Cross-Attention)**: 쿼리 토큰이 동결된 비전 인코더의 출력에 어텐드하여 시각 정보를 추출

**출력**: 32개의 쿼리에 대응하는 32개의 출력 임베딩. 이 임베딩이 LLM의 입력으로 전달되어 시각 정보를 전달합니다.

:::info
Q-Former의 핵심 설계 원리는 **정보 병목(information bottleneck)**입니다. 비전 인코더의 출력은 수백 개의 패치 토큰(ViT-L의 경우 257개)이지만, Q-Former는 이를 **32개의 쿼리로 압축**합니다. 이 압축 과정에서 태스크에 불필요한 시각 정보(배경, 노이즈 등)는 제거되고, 핵심적인 시각 정보만 보존됩니다.
:::

### 2단계 부트스트래핑 학습 전략

BLIP-2의 학습은 **2단계 부트스트래핑** 전략으로 이루어집니다. 모달리티 갭을 한 번에 해소하기 어려우므로, 단계적으로 접근합니다.

#### 1단계: 비전-언어 표현 학습 (Representation Learning)

1단계에서는 Q-Former가 비전 인코더에서 텍스트와 관련된 시각 정보를 추출하는 방법을 학습합니다. LLM은 아직 사용하지 않습니다.

세 가지 사전학습 목적함수를 동시에 사용합니다.

**1. Image-Text Contrastive Learning (ITC)**: [[clip]]과 유사한 대조 학습입니다. 쿼리 출력과 텍스트 출력의 유사도를 계산하여, 올바른 이미지-텍스트 쌍의 유사도를 최대화합니다.

$$\mathcal{L}_{\text{ITC}} = -\log \frac{\exp(\text{sim}(q, t) / \tau)}{\sum_{j} \exp(\text{sim}(q, t_j) / \tau)}$$

이 단계에서 쿼리 토큰은 텍스트 토큰에 어텐드할 수 **없습니다** (unimodal self-attention mask). 이는 쿼리가 텍스트 정보를 "커닝"하지 않고, 순수하게 시각 정보만으로 텍스트와 매칭되는 표현을 학습하도록 합니다.

**2. Image-grounded Text Generation (ITG)**: 이미지가 주어졌을 때 관련 텍스트를 생성하는 생성 태스크입니다. Q-Former가 시각 정보를 바탕으로 텍스트를 자기회귀적으로 생성합니다.

이 단계에서는 쿼리 토큰이 텍스트 토큰에 어텐드할 수 있지만, **causal attention mask**를 사용하여 현재 토큰이 미래 텍스트 토큰을 볼 수 없도록 합니다.

**3. Image-Text Matching (ITM)**: 이미지-텍스트 쌍이 올바른 매칭인지를 이진 분류하는 태스크입니다. Q-Former가 멀티모달 표현을 학습하는 데 도움이 됩니다.

이 단계에서는 쿼리 토큰과 텍스트 토큰이 서로 자유롭게 어텐드할 수 있습니다 (bi-directional self-attention mask).

세 목적함수는 **어텐션 마스킹 전략**으로 구분됩니다. 같은 아키텍처를 사용하지만, self-attention mask를 다르게 설정하여 각 목적함수에 적합한 정보 흐름을 구현합니다.

#### 2단계: 비전-언어 생성 학습 (Generative Learning)

2단계에서는 1단계에서 학습된 Q-Former를 동결된 LLM에 연결합니다. Q-Former의 출력(32개의 임베딩)을 선형 투영(linear projection)하여 LLM의 임베딩 차원에 맞추고, 이를 LLM의 소프트 비주얼 프롬프트(soft visual prompt)로 사용합니다.

$$h = \text{LinearProj}(\text{Q-Former}(q, \text{ViT}(I)))$$

$$P(\text{text} \mid I) = \text{LLM}([h; \text{text\_tokens}])$$

여기서 $[h; \text{text\_tokens}]$는 시각 임베딩과 텍스트 토큰의 연결(concatenation)입니다.

두 종류의 LLM에 따라 학습 전략이 달라집니다.

**디코더 기반 LLM (OPT)**: 언어 모델링 목적함수를 사용합니다. 시각 프롬프트 뒤에 텍스트를 이어붙여, 모델이 시각 정보를 조건으로 텍스트를 생성하도록 합니다.

**인코더-디코더 기반 LLM (FlanT5)**: 접두사 언어 모델링(prefix language modeling)을 사용합니다. 시각 프롬프트와 텍스트 접두사를 인코더에 입력하고, 디코더에서 나머지 텍스트를 생성합니다.

### 아키텍처의 모듈성

BLIP-2의 설계에서 가장 우아한 점은 **모듈성(modularity)**입니다. 비전 인코더, Q-Former, LLM이 각각 독립적으로 교체 가능합니다.

| 비전 인코더 | Q-Former | LLM |
|------------|---------|-----|
| ViT-L/14 (CLIP) | 32 queries, 188M params | OPT-2.7B |
| ViT-g (EVA-CLIP) | 32 queries, 188M params | OPT-6.7B |
| | | FlanT5-XL (3B) |
| | | FlanT5-XXL (11B) |

Q-Former의 파라미터는 약 **188M**으로, 수십~수백억 파라미터의 비전 인코더나 LLM에 비해 극히 작습니다. 전체 학습 파라미터 중 Q-Former + 선형 투영 레이어만 학습하므로, 학습 비용이 크게 절감됩니다.

## 실험 결과

### 이미지 캡셔닝

BLIP-2는 이미지 캡셔닝에서 기존 모델을 크게 능가합니다.

**COCO Caption (Karpathy test split)**:

| 모델 | 학습 파라미터 | CIDEr |
|------|-------------|-------|
| BLIP | 446M | 136.7 |
| Flamingo (80B) | 10.2B | 84.3 |
| CoCa | 2.1B | 143.6 |
| **BLIP-2 (ViT-g + FlanT5-XXL)** | **188M** | **145.8** |

BLIP-2는 CoCa(2.1B 학습 파라미터)를 **188M 파라미터만으로** 능가합니다. 이는 학습 파라미터 수가 약 **11배 적으면서도** 더 높은 성능을 달성한 것입니다.

**NoCaps (도메인 외 캡셔닝)**:

NoCaps는 학습 데이터에 포함되지 않은 새로운 객체에 대한 캡셔닝을 평가합니다. BLIP-2는 NoCaps에서도 SOTA를 달성하여, Q-Former가 학습하지 않은 새로운 시각 개념도 효과적으로 전달할 수 있음을 보여줍니다.

### 시각 질의응답 (VQA)

**VQAv2**:

| 모델 | 학습 파라미터 | 정확도 |
|------|-------------|--------|
| Flamingo (80B) | 10.2B | 82.0 |
| BLIP | 446M | 78.3 |
| **BLIP-2 (ViT-g + FlanT5-XXL)** | **188M** | **82.2** |

BLIP-2는 Flamingo(80B)의 82.0%를 188M 파라미터로 능가하는 **82.2%**를 달성합니다. Flamingo 대비 약 **54배 적은 학습 파라미터**로 더 높은 성능을 보여줍니다.

### 이미지-텍스트 검색

COCO와 Flickr30K에서의 이미지-텍스트 검색(retrieval) 성능입니다.

**COCO (5K test set)**:

| 모델 | TR@1 | IR@1 | 평균 Recall |
|------|------|------|-----------|
| CLIP (ViT-L/14) | 58.4 | 37.8 | - |
| BLIP | 82.4 | 65.1 | - |
| **BLIP-2 (ViT-L)** | **82.6** | **66.4** | - |
| **BLIP-2 (ViT-g)** | **85.2** | **68.1** | - |

Q-Former가 1단계에서 대조 학습을 수행하므로, 이미지-텍스트 검색에서도 강력한 성능을 보입니다.

### Zero-shot 이미지-텍스트 생성

BLIP-2의 가장 인상적인 능력 중 하나는 **LLM의 in-context learning 능력을 시각 도메인으로 확장**하는 것입니다. Q-Former의 출력이 LLM의 소프트 프롬프트 역할을 하므로, LLM이 텍스트에 대해 보여주는 다양한 능력(추론, 대화, 지식 활용 등)을 이미지 입력에 대해서도 발휘할 수 있습니다.

**Zero-shot VQA 예시**:
- 질문: "이 건물은 어느 도시에 있나요?"
- BLIP-2: "파리입니다. 에펠탑이 보이기 때문입니다."

**시각적 추론**:
- 질문: "이 사진에서 비정상적인 점은 무엇인가요?"
- BLIP-2: "강아지가 선글라스를 쓰고 있습니다. 이는 비정상적입니다."

**시각 대화**:
- 사용자: "이 이미지를 설명해주세요."
- BLIP-2: "해변에서 일몰을 보고 있는 커플의 사진입니다."
- 사용자: "그들의 기분은 어떨까요?"
- BLIP-2: "로맨틱하고 평화로운 분위기로 보아 행복할 것 같습니다."

:::warning
BLIP-2의 zero-shot 생성은 LLM의 능력에 크게 의존합니다. FlanT5를 사용하면 명령어 기반의 구조적 응답이, OPT를 사용하면 자유로운 텍스트 생성이 특화됩니다. LLM의 한계(환각, 편향 등)가 시각-언어 태스크에도 그대로 전이될 수 있습니다.
:::

### LLM 선택에 따른 성능 비교

| LLM | VQAv2 | 캡셔닝 (CIDEr) | 파라미터 |
|-----|-------|---------------|---------|
| OPT-2.7B | 74.3 | 130.1 | 2.7B + 188M |
| OPT-6.7B | 75.7 | 132.8 | 6.7B + 188M |
| FlanT5-XL (3B) | 79.1 | 139.2 | 3B + 188M |
| **FlanT5-XXL (11B)** | **82.2** | **145.8** | **11B + 188M** |

FlanT5 계열이 OPT 계열보다 일관적으로 높은 성능을 보입니다. 이는 FlanT5의 명령어 튜닝(instruction tuning)이 시각-언어 태스크에서도 유용한 추론 능력을 부여하기 때문입니다. 또한 LLM의 크기가 커질수록 성능이 향상되는 스케일링 경향이 관찰됩니다.

## 방법론 상세 분석

### Q-Former의 어텐션 마스킹 전략

1단계 학습에서 Q-Former의 세 가지 목적함수는 **동일한 아키텍처**를 공유하지만, 어텐션 마스킹으로 정보 흐름을 제어합니다. 이는 매우 우아한 설계입니다.

| 목적함수 | 쿼리↔텍스트 어텐션 | 쿼리→비전 어텐션 |
|---------|-------------------|----------------|
| ITC (대조 학습) | 차단 (Unimodal) | O |
| ITG (텍스트 생성) | Causal (왼쪽→오른쪽) | O |
| ITM (매칭) | 양방향 (Bi-directional) | O |

**ITC에서 차단하는 이유**: 쿼리가 텍스트를 볼 수 있으면, 시각 정보 없이도 텍스트만으로 매칭을 학습할 수 있습니다. 차단함으로써 쿼리가 **순수하게 시각 정보만으로** 텍스트와 매칭되는 표현을 학습하도록 강제합니다.

**ITG에서 Causal인 이유**: 텍스트 생성은 자기회귀적이므로, 현재 토큰이 미래 토큰을 볼 수 없어야 합니다. 동시에 쿼리에는 접근할 수 있어 시각 정보를 활용합니다.

**ITM에서 양방향인 이유**: 매칭 판단은 이미지와 텍스트의 전체적 관계를 파악해야 하므로, 모든 정보에 양방향으로 접근합니다.

### 왜 32개의 쿼리인가?

Q-Former의 쿼리 수(32개)는 중요한 설계 선택입니다. 쿼리 수와 성능/효율성의 관계를 분석하면 다음과 같습니다.

**적은 쿼리 (< 16)**: 시각 정보의 손실이 커서 성능 저하
**32개 쿼리**: 최적의 성능-효율성 균형점
**많은 쿼리 (> 64)**: 성능 향상이 미미하면서 LLM 입력 길이 증가로 비용 상승

32개의 쿼리는 ViT의 수백 개 패치 토큰을 약 1/8로 압축합니다. 이 압축은 LLM에 전달되는 시각 토큰 수를 줄여 추론 비용을 절감하는 동시에, 불필요한 시각 정보(배경, 노이즈)를 필터링하는 효과도 있습니다.

### 학습 설정 상세

**1단계 학습**:
- 데이터: COCO, Visual Genome, CC3M, CC12M, SBU, LAION400M (총 약 1.29억 쌍)
- 에포크: 30
- 배치 크기: 2,320 (16 x A100 GPU)
- 이미지 해상도: 224x224
- 학습 시간: 약 6일 (16 A100)

**2단계 학습**:
- 동일한 데이터셋 사용
- 에포크: 10
- 이미지 해상도: 224x224
- 학습 시간: 약 3일 (16 A100)

총 학습 비용은 약 9일 x 16 A100으로, Flamingo(~1,536 TPUv4-일)에 비해 **수십 배 저렴**합니다.

### 동결(Freezing)의 이점

비전 인코더와 LLM을 동결하는 것의 이점은 단순한 비용 절감 이상입니다.

**1. 지식 보존**: ViT와 LLM이 대규모 데이터에서 학습한 풍부한 지식이 보존됩니다. 파인튜닝 시 발생할 수 있는 catastrophic forgetting을 방지합니다.

**2. 모듈 교체 용이**: 새로운, 더 강력한 비전 인코더나 LLM이 출시되면, Q-Former만 재학습하여 성능을 업그레이드할 수 있습니다.

**3. LLM 능력 활용**: LLM의 in-context learning, 추론, 지식 활용 능력이 그대로 유지되어, 시각 도메인에서도 이 능력들을 활용할 수 있습니다.

## 한계 및 의의

### 한계

1. **LLM의 한계 상속**: LLM의 환각(hallucination), 편향, 최신 지식 부족 등의 문제가 시각-언어 태스크에도 그대로 전이됩니다. 예를 들어, 이미지에 없는 내용을 생성하는 시각적 환각이 발생할 수 있습니다.

2. **세밀한 시각 이해의 한계**: 32개 쿼리로의 정보 압축 과정에서 세밀한 시각 정보(작은 객체, 텍스트, 세부 패턴 등)가 손실될 수 있습니다.

3. **해상도 제한**: 224x224 또는 364x364의 비교적 낮은 입력 해상도를 사용하여, 고해상도 이미지의 세부 정보를 충분히 활용하지 못합니다.

4. **비디오/다중 이미지 처리 한계**: BLIP-2는 단일 이미지 입력에 최적화되어 있으며, 비디오나 다중 이미지 입력을 직접 처리하기 어렵습니다.

5. **Q-Former의 학습 복잡도**: 세 가지 목적함수와 어텐션 마스킹 전략의 조합이 구현과 하이퍼파라미터 튜닝을 복잡하게 합니다.

### 학술적 의의

1. **효율적 멀티모달 학습 패러다임**: 동결된 기반 모델(foundation model)을 경량 어댑터로 연결하는 패러다임을 확립했습니다. 이는 [[lora]]가 LLM 파인튜닝에서 보여준 효율성과 유사한 패러다임 전환입니다.

2. **부트스트래핑 학습 전략**: 모달리티 갭을 단계적으로 해소하는 2단계 학습 전략은 이후 다양한 멀티모달 연구에서 채택됩니다.

3. **정보 병목 원리의 시각-언어 적용**: Q-Former의 쿼리를 통한 정보 병목은, 시각 정보를 언어 모델에 효율적으로 전달하는 원리적 방법을 제시합니다.

4. **LLM의 멀티모달 확장**: 텍스트 전용 LLM을 수정 없이 멀티모달로 확장할 수 있음을 보여주어, 이후 GPT-4V, Gemini 등의 멀티모달 LLM 연구에 영감을 제공합니다.

### 후속 연구

BLIP-2는 다음과 같은 후속 연구의 기반이 되었습니다.

- **InstructBLIP**: BLIP-2에 명령어 튜닝을 적용하여 다양한 시각-언어 태스크를 자연어 명령으로 수행
- **MiniGPT-4**: Q-Former와 유사한 구조로 GPT-4 수준의 시각 이해를 소규모 모델로 구현
- **LLaVA**: Q-Former 대신 단순 선형 투영을 사용하여 더 단순한 멀티모달 아키텍처 제안
- **Qwen-VL**: Q-Former를 확장하여 다국어 멀티모달 모델 구축
- **Video-BLIP**: BLIP-2를 비디오 도메인으로 확장

## 결론

BLIP-2는 "강력한 모델을 처음부터 학습하는 것이 아니라, 이미 존재하는 강력한 모델들을 효율적으로 연결한다"는 원리를 구현한 논문입니다. 동결된 비전 인코더와 LLM 사이에 188M 파라미터의 Q-Former만을 학습함으로써, 수십억 파라미터의 end-to-end 모델과 동등하거나 우수한 성능을 달성합니다.

이 논문의 핵심 통찰은 **모달리티 간의 연결(bridging)**이 각 모달리티의 내부 능력 자체보다 더 중요한 병목이라는 것입니다. 비전 인코더와 LLM은 이미 각각의 모달리티에서 충분히 강력합니다. 부족한 것은 이 둘 사이의 "번역"이며, Q-Former가 바로 그 번역기 역할을 합니다.

BLIP-2가 제시한 "동결 + 경량 브리지" 패러다임은 멀티모달 AI의 표준적 접근법이 되었으며, 이후 GPT-4V, Gemini Pro Vision, Claude 3 등 현대 멀티모달 시스템의 설계에도 핵심적인 영향을 미치고 있습니다.
